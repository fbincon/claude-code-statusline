# 只读任务详情

[English](TASK_DETAILS.md) | **简体中文**

查看已有任务的计时、清单、代理及来源证据。选择原生窗格、独立终端查看器或非交互 CLI；这些入口都不启动采集。

## 打开任务报告

安装原生编辑器后，在受支持的 Claude Code 终端运行 `/statusline-task`。如果焦点仍在聊天输入框，按 **Ctrl+X 再按 Tab** 将焦点移至窗格，或点击控件；点击报告正文后可使用报告阅读键。

独立终端查看器不依赖 Native 窗格或已安装的配置编辑器：

```sh
claude-statusline task view --session-id SESSION_ID
claude-statusline --language zh-CN task view --session-id SESSION_ID --prompt-id PROMPT_ID --config-dir "/path/to/config"
```

外部配置编辑器的“设置”页也提供“任务详情”。输入会话 ID 和可选 prompt ID，Tab 切换字段，Enter 读取；返回时保留显示草稿、编辑目标及未决保存状态。独立 `task view` 需要交互终端；非交互文本／JSON 使用：

```sh
claude-statusline task show --session-id SESSION_ID
claude-statusline task show --session-id SESSION_ID --prompt-id PROMPT_ID --json
claude-statusline task show --session-id SESSION_ID --config-dir "/path/to/config"
```

会话和 prompt ID 来自你提供的状态栏输入或已有会话元数据。请显式传入 `--session-id`；CLI 不读取状态栏 stdin，也不搜索其他会话来猜测身份。省略 `--prompt-id` 时，只使用既有状态中的明确当前任务指针；指针冲突、任务缺失和别名归属不明确时保持不可用。

命令描述与首次标题使用已读取的界面语言，任务读取失败仍保持该语言。刷新／重开重新读取偏好；原生窗格和交互式 `task view` 在偏好不可读时提示并回退英文，`task show` 则直接返回英文且不提示。两种情况都不阻止任务读取。高窗格会缩小可见页以满足宿主容量，完整报告仍可翻页。

## 阅读控件

| 操作 | 原生窗格控件 | 报告正文／独立终端查看器 |
| --- | --- | --- |
| 搜索名称／ID | G，或在默认搜索按钮获得焦点时按 Enter | `/` |
| 状态筛选 | F | F |
| 显示／隐藏证据 | E | E |
| 编辑会话／prompt 身份 | S | S；Tab 切换字段 |
| 选择上／下一行 | P／N | ↑／↓；Home／End 跳至首／末行 |
| 向上／下翻页 | K／J | Page Up／Down 或 K／J |
| 展开／折叠代理 | Z | ←／→ 或 Enter |
| 重读已发布状态 | R | R |
| 关闭 | Q；Esc 将焦点交还 Claude | Q；非编辑状态按 Esc 或 Ctrl+G 关闭，编辑字段时按 Esc 或 Ctrl+G 取消输入 |

原生字母控件需要窗格焦点；报告阅读键需要正文焦点。打开原生文本框后，点击字段或按 Ctrl+X 再按 Tab；看到 ⏎ 提交提示后输入或粘贴完整值，包括空格，按 Enter 确认。Tab 移到“取消”按钮后按 Enter 可恢复原值。字段输入期间快捷键由字段处理。

刷新由用户触发。prompt 字段留空使用已发布当前任务指针。默认显示摘要及全部状态；搜索不区分大小写，匹配子节点保留父级上下文。外部查看器不会推测仅 Native 宿主提供的名称。

矮窗格为选中的报告行预留空间，翻页使用实际正文高度；标题缩短时用 S 查看完整身份。刷新和缩放保留仍存在的选中行。切换任务重置任务专属阅读状态；刷新失败保留上次报告及其采集时间。

## 理解证据

- **任务总耗时**复用现有生命周期计时和终态冻结值。
- **活跃耗时**仅在原生执行及等待覆盖足够时显示；缺少开始事件、等待不完整或时钟不可靠都不会转换成零。
- **清单完成数／总数**，例如 `3/5`，表示已完成清单任务数量，不是代理比例或耗时百分比。
- **代理**只展示能归属当前任务的身份；显示已知父子关系，明确说明父节点缺失或循环关系。
- **证据**逐项标记来源、作用域、观测时间和新鲜度；不会用窗格读取时间替代来源观测时间。

原生窗格可按需从宿主读取当前代理名称，只与已经确认归属的 ID 关联，标记为提供的快照且不持久化。因此，CLI 可能只显示 ID，而原生窗格显示名称。陈旧状态仍明确标记为陈旧；其他任务的心跳不会刷新旧的运行记录，也不会让旧记录的耗时继续累加。已完成任务保留冻结时长。出现终态也不代表完整观测了所有历史事件。

心跳明确标注为会话范围。代理和清单证据保留各自的观测时间及新鲜度，未来清单观测的数量保持不可用。未来的原生 prompt 或 turn 观测不能提供当前状态或刷新任务计时，独立有效的历史冻结值仍然可用。已观察到的代理终态事件优先于代理列表快照。

响应是现有任务和运行状态存储的只读模型；当前版本见[协议与 schema 版本](reference/cli.zh-CN.md#协议与-schema-版本)。来源文件是独立快照，不能视为跨文件原子快照或完整历史。既有有界存储已裁剪的数据不会在这里重建。

## 边界与排查

检查只读取已知文件，且有大小限制。不扫描 transcript、不协调或修复存储、不查询网络、不调用模型、不启用采集，也不改变计时及归属规则。既有采集关闭选择继续有效；采集关闭或缺失时，部分详情可能不可用。

升级后重新安装以注册新增原生命令。原生编辑器已关闭或宿主无法显示窗格时，请使用 CLI。原生界面按固定终端宿主分别验证，不据此宣称 web、移动端或其他 Claude 客户端受支持。

渲染可见性及输入关联问题请使用[真实输入诊断](DIAGNOSTICS.zh-CN.md)；`task show` 的状态与原因码见[CLI 任务输出](reference/cli.zh-CN.md#task-show)及[实时状态视图](development/live.zh-CN.md#状态视图)；显示方案及项目选择请参阅[方案管理](PROFILES.zh-CN.md)。
