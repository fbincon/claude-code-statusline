# Setup and scheme capture provenance

**English** | [简体中文](README.zh-CN.md)

[Complete schemes](../../SCHEMES.md) use fixed samples from the production renderer. Captures are generated from an isolated installed package, with the source commit, package digest, language, dimensions, color mode and input scenario recorded alongside them. Terminal-cell reconstructions are not desktop screenshots or human platform acceptance.

Use the installed editor capture runner for six-language Quick setup and appearance controls. The setup/appearance capture runner additionally exercises the first-use wizard and renders each scheme at 80/120 columns in light, dark and terminal colors, plus no-agent, running/completed/failed and complete/missing/expired quota cases. Raw ANSI, payloads, cell matrices and full receipts stay in the ignored validation directory; selected images and their final-package provenance are attached with the delivery evidence.
