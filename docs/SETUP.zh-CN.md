# 首次设置向导

[English](SETUP.md) | **简体中文**

安装 npm 包后运行：

```sh
claude-statusline setup --dry-run
claude-statusline setup
```

向导检查环境，允许保留当前显示或选择[完整方案](SCHEMES.zh-CN.md)，预览候选配置，并在保存前审阅变更。已有配置默认选中**保留**；首次安装推荐**日常开发**。方向键选择、Enter 继续、退格返回、Page Up/Down 滚动详情、Tab 切换快速配置中的主栏／子代理预览、Esc 取消。终端至少需要 64 列 × 18 行，调整窗口尺寸保留草稿。

可用 `claude-statusline --language zh-CN setup` 临时指定界面语言；向导中的 L 键会明确切换并立即保存界面语言。显示语言仍随显示草稿保存。全部六种语言均可使用。

## 首次入口与 npm 持久安装

在交互终端运行 `npx @fbincon/claude-code-statusline`，或无子命令运行已安装的 `claude-statusline`。入口检查公开包身份、Node/npm、实际 registry 和全局 prefix，展示精确版本及位置，输入 `yes` 后才安装。最初 npx 下载有 npm 自己的确认步骤。

同版本持久安装会复用，包括只读的系统安装。遇到其他版本、PATH／集成 prefix 冲突或未完成的包操作时停止。使用 `--prefix PATH` 明确位置，目标必须位于 npm 缓存之外。不会提权或登录账户；源码检出和工程候选包继续使用明确命令。

验证后，由全局 Node/JS 入口运行既有 setup。流程退出后删除临时 npx 缓存，不会移除持久入口及 Claude 绑定。包安装、显示保存和 Claude 集成仍是独立阶段；取消 setup 会保留已完成的包安装。npm 失败或结果不确定会保留操作记录，不能盲目重试。

无参数非 TTY 入口直接退出 2，不改变安装或配置。明确使用 `--dry-run` 可检查 npm 位置并打印审核内容，不改变目标。`--config-dir PATH` 为后续 setup 选择相同的隔离配置目录。

## 检查与编辑目标

`setup --dry-run` 无需 TTY。它检查 Node、检测到的 Claude 版本、配置可读性／权限、资源归属与待恢复事务，然后打印步骤。它不会选择方案、创建配置目录或锁文件、写入探针、安装插件或恢复事务。普通非 TTY `setup` 以退出码 2 结束，并打印现有分步命令；dry-run 可接入时退出码为 0，检查阻止接入时为 1。

```sh
claude-statusline setup --config-dir '/包含空格的路径/claude'
```

编辑目标固定为**用户默认**。向导显示已有方案、项目绑定及当前项目绑定的方案，不替换绑定。之后可用 `configure --profile NAME`、`configure --project PATH` 或编辑器中的方案管理修改这些目标。

向导接入需要检测到至少 2.1.205 的 Claude。这是基础接入门槛，不表示该宿主支持所有可选字段或编辑器；既有能力检查仍会暂停不支持的功能。缺少／未知／过旧的 Claude 或第三方接入冲突时，仍可能允许**仅保存显示**。显示、设置或方案文件损坏，以及存在待恢复事务时，会阻止保存。请检查报告的文件，或先运行 `claude-statusline recover --dry-run` 再明确执行恢复；向导不重置损坏文件、不强制接管资源。

只读权限检查不能保证之后的磁盘写入一定成功。提交前还会再次检查修订与资源归属。

## 应用与恢复

最终审阅提供**保存显示并接入**、**仅保存显示**、**取消**。页面展示显示变更、计划写入的文件资源、保留的编辑器／采集选项，以及独立的官方插件阶段；详情可以滚动查看。

显示保存与接入是两个独立的持久化提交，各自保留备份。安装前也可以仅保存显示，该操作不应用 Claude 宿主偏好。接入复用现有安装器与插件恢复日志。选择方案不会启用原生计时或实时指标；已保存的关闭选项继续有效。

应用前取消不改变显示与接入；明确保存的界面语言仍然保留。如果后续阶段失败，结果说明显示是否已保存，打印可用备份位置，并提供 `doctor`／`recover` 指引，不承诺整个流程自动回滚。重试前应检查待恢复事务；并发变化需要重新审阅。

检查成功只确认写入资源。请重启 Claude 并观察实际状态栏，以确认会话加载。固定预览不能证明已观测到真实数据，也不能证明重启成功。之后可用 `/statusline-config` 或 `claude-statusline configure --user` 继续编辑，用 `doctor` 检查安装。

`install`、`doctor`、`configure` 和配置 CLI 保持可用。向导不下载／升级包、不安装字体、不登录账号、不改变独立的 Claude 偏好。参见[安装与回退](USER_GUIDE.zh-CN.md)及[外观兼容说明](APPEARANCE.zh-CN.md#配置兼容与恢复)。
