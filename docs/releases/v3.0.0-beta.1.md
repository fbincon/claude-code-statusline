# v3.0.0-beta.1 — TypeScript preview

[English](#english) | [简体中文](#简体中文)

<a id="english"></a>

The first public TypeScript preview moves normal runtime, installation, build and tests to Node. It is a new major distribution: npm replaces Python/pipx for the preview, while Python v2.0.0 remains the stable and rollback release.

- Requires Node 24.21.0; validated tooling uses npm 11.19.0. One offline package bundles Linux x64, Windows x64, macOS x64/ARM64 native dependencies. Windows ARM uses x64 Node emulation.
- Both compatible editors default on, respecting saved disablement; advanced live metrics stay opt-in. Configuration and protocol formats remain compatible.
- Isolated prefix/configuration installation, ownership-aware upgrades, explicit recovery and Python rollback are documented in the [preview guide](../PREVIEW.md).
- npm: `npm install --prefix <preview-prefix> --ignore-scripts @fbincon/claude-code-statusline@beta`; use `@3.0.0-beta.1` for a fixed version. Review the guide before switching an existing Claude configuration. No installation lifecycle script is needed.
- Assets: `fbincon-claude-code-statusline-3.0.0-beta.1.tgz`, `claude-code-statusline-3.0.0-beta.1-source.tar.gz`, `build-manifest.json`, `SHA256SUMS`. Verify hashes before installing a local tgz with `--offline --ignore-scripts`.

**Still unverified:** physical macOS sleep/resume, macOS 14 Intel desktop/power, Windows 10 desktop, WSL desktop/popup and remaining target-specific human/power coverage. These remain stable-release gates. CI, PTY and screenshots do not satisfy those checks. The macOS Client may need a click to focus. Claude 2.1.296 declarations remain unavailable; official Mod tests and 2.1.294 type checks are separate evidence.

D06 remains **FAIL: 104 pass / 60 fail / 28 inconclusive**. PERF-01 follows migration; this release makes no performance improvement claim. Functional failures still block acceptance. The full source commit and package digests are in the delivered manifest; [CI](https://github.com/fbincon/claude-code-statusline/actions), [TS-06 evidence](../development/typescript-migration/ts-06/README.md) and [validation tracker #96](https://github.com/fbincon/claude-code-statusline/issues/96) distinguish completed checks from gaps.

Use the [feedback form](https://github.com/fbincon/claude-code-statusline/issues/new?template=preview-feedback.yml) with exact versions, environment, reproduction and sanitized evidence. This preview does not close TS-06 or replace the latest stable release.

首个公开 TypeScript 预览版将正常运行、安装、构建和测试迁移至 Node。本次采用新的主版本分发：预览版使用 npm，Python v2.0.0 保持稳定版与回退版本。

- 需要 Node 24.21.0，验证工具链为 npm 11.19.0。一个离线包包含 Linux x64、Windows x64、macOS x64/ARM64 原生依赖；Windows ARM 使用模拟 x64 Node。
- 兼容宿主双编辑器默认开启，保留已保存的停用设置，高级 live metrics 仍显式启用。配置及协议格式保持兼容。
- [试用指南](../PREVIEW.zh-CN.md)提供隔离安装、所有权检查、显式恢复和 Python 回退步骤。
- npm 使用 `npm install --prefix <preview-prefix> --ignore-scripts @fbincon/claude-code-statusline@beta`，固定复现用 `@3.0.0-beta.1`。切换已有 Claude 配置前先阅读指南。无需安装生命周期脚本。
- 四项附件为安装 tgz、可重建源码 tar.gz、`build-manifest.json` 和 `SHA256SUMS`；校验后用 `--offline --ignore-scripts` 安装本地包。

**仍未验证：** macOS 实机休眠恢复、macOS 14 Intel 桌面/电源、Windows 10 桌面、WSL 桌面/弹窗及其他目标人工/电源覆盖。这些仍是正式版门槛，CI、PTY 和截图不能替代。macOS Client 可能需要点击聚焦；Claude 2.1.296 声明仍不可用，官方 Mod 测试与 2.1.294 类型检查分别记录。

D06 保持 **FAIL：104 pass / 60 fail / 28 inconclusive**，PERF-01 后续处理，本次不宣称性能提升。功能失败仍阻塞验收。完整源码 SHA 和包摘要见附件清单；[CI](https://github.com/fbincon/claude-code-statusline/actions)、[TS-06 证据](../development/typescript-migration/ts-06/README.zh-CN.md)及[验收跟踪 #96](https://github.com/fbincon/claude-code-statusline/issues/96)区分已完成与待验证项。

请通过[反馈表单](https://github.com/fbincon/claude-code-statusline/issues/new?template=preview-feedback.yml)提供版本、环境、复现与脱敏证据。本预览不关闭 TS-06，也不替代最新稳定版。
