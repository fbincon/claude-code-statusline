# v3.16.1 — 运行观测、来源超时与保存冲突修复

[English](v3.16.1.md) | **简体中文**

已于 **2026-10-31** 发布。完整门禁、渠道及本机证据见[交付记录](../development/runtime-source-save-fixes.zh-CN.md#final-release)。

本版本修复运行观测的代理身份、命令源超时和保存冲突。

- 运行观测在 turn 启动时保留代理身份，使子代理请求与完成共享同一生命周期记录，不再留下虚假的运行中主回合；按已观测结束时间核对迟到终态批次（[#197](https://github.com/fbincon/claude-code-statusline/issues/197)）。
- 保留命令源的失败超时、执行诊断和错误观测，不再把 deadline 到期变为 `cancelled/no_consumers`；延迟结算确认成功或需暂停的失败后，核对暂记的自动反馈（[#195](https://github.com/fbincon/claude-code-statusline/issues/195)）。
- 将明确目标的 `profile_conflict` 识别为确定拒绝，双编辑器直接打开普通冲突审阅，保留草稿／历史及胜出方已保存配置（[#196](https://github.com/fbincon/claude-code-statusline/issues/196)）。

显示 schema 17、编辑器协议 31 及既有来源／runtime／存储格式保持兼容。升级后重新运行 `claude-statusline install`，并重启 Claude Code 加载匹配的 runtime Mod。不会把不完整的历史观测改称完整。

支持平台／运行时：Node 22／24，Linux／WSL、Windows 和 macOS；原有八安装目标／32 项 Node／十六宿主矩阵及每宿主 313 项 Native 容量案例保持支持。

两编辑器各通过三条取消／保存／恢复旅程，十一路径偏好均已恢复；真实交互式 Claude 2.1.314 测试与记录的 API／Native／转录请求匹配，没有虚假主回合。付费验收保持在批准预算内；请求及成本详情见交付记录。

仅接受 [issue #96 六项既有缺口](https://github.com/fbincon/claude-code-statusline/issues/96)，它们仍未验证。发布完成后本机新发现只提 issue，保留 v3.16.1，本任务不再补发其他修补版。
