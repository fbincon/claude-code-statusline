# v3.10.0 — 外观、样例场景与文件诊断

[English](v3.10.0.md) | **简体中文**

已于 **2026-10-28** 发布。完整门禁、渠道及本机证据见[交付记录](../development/appearance-preview-diagnosis.zh-CN.md)。

本版本为双编辑器新增四个主题、八个渐变预设、确定性样例场景和输入文件诊断。

- 通过统一注册源新增 ocean、ember、slate、blossom 四主题及八个渐变预设。
- 查看实际色块与适用背景提示，编辑／反转 2–5 个渐变色标；接受到显示草稿，或取消当前配色页。
- 双编辑器可选择十四个确定性场景、临时预览宽度及行浏览，不采集、不改变已保存显示配置。
- 按实例／代理行解释不适用渐变、共享背景、阈值、关闭／转换颜色和对比度保护。
- 使用当前未保存草稿诊断明确指定的输入文件。编辑器默认仅输入，可明确加入匹配的已有本地观测；报告保持来源／时间标识和分页只读展示。

显示 schema 16、编辑器协议 26 需要匹配的安装资源。旧配置读取不写入，显式保存保留备份；降级前恢复兼容备份。来源／runtime／portable／界面偏好格式版本保持不变。升级后运行 `claude-statusline install` 并重启 Claude Code。

支持平台／运行时：Node 22／24，Linux／WSL、Windows 和 macOS；既有宿主最低版本及语言选择保持可用。

仅接受 [issue #96 六项既有缺口](https://github.com/fbincon/claude-code-statusline/issues/96)，它们仍未验证。本版本不执行付费模型测试；发布后新发现只提 issue，不补发修补版。
