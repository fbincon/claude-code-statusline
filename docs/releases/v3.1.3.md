# v3.1.3 — Post-migration correctness and installation repairs

[English](#english) | [简体中文](#简体中文)

<a id="english"></a>

Repair all eleven findings in the post-migration review: Windows editor bridge identity, npm/PATH ownership, doctor validation, invalid task IDs, language/version queries, execution-clock trust, transcript replacement, replay deduplication and backup-path safety.

Usage now keeps exact disk-backed message identities with a bounded hot cache. Old compressed caches whose identities cannot be recovered are preserved and reported unavailable; a new session establishes complete accounting. Display schema 8 and configuration/runtime protocols 12/2 remain compatible. Doctor checks complete skill bodies, host fields and runtime write permission.

Upgrade with `npm install --global --ignore-scripts @fbincon/claude-code-statusline@3.1.3`, run `claude-statusline install`, then restart Claude Code. See [installation and recovery](../USER_GUIDE.md#installation-and-integration).

The [v3.1.3-only decision](approvals/v3.1.3.json) accepts the same six existing physical/desktop/exact-declaration gaps; they remain unverified. New automated or functional failures are not waived. D06 remains FAIL and PERF-01 remains NOT_STARTED. Existing beta and Python rollback artifacts remain available.
