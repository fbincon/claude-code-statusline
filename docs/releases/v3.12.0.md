# v3.12.0 — Source operations, scheduled commands and package execution

**English** | [简体中文](v3.12.0.zh-CN.md)

Published on **2026-10-28**. Full gate, channel and machine evidence is in the [delivery record](../development/source-command-package-management.md#v3120-delivery-record).

This release adds reviewed source operations, separately approved scheduled commands and package execution in both editors.

- Show shared readable source state, bounded execution summaries, saved GitHub check pages and reviewed binding maintenance.
- Require separate approval for automatic commands, default to 300 seconds and run only while applicable confirmed contexts retain active leases. Equal inputs share work; distinct contexts rotate fairly with one command per source.
- Execute verified upgrades, rollback, unfinished-package recovery and independent configuration restoration in both editors. Drafts require explicit handling; durable controls survive package replacement, the old editor becomes read-only and closing detaches. Reviewed history cleanup protects active work, rollback material and referenced snapshots.
- Keep unverifiable executor identity unknown and protected; package recovery waits for confirmed exit or a different identity.
- Fix [#173](https://github.com/fbincon/claude-code-statusline/issues/173): ordinary npm manifest permissions no longer cause false package-page compatibility warnings; recovery files retain private permission requirements. [#157](https://github.com/fbincon/claude-code-statusline/issues/157) is closed with actual v3.11.0 tag/OIDC/provenance evidence, retaining the unverified account-capacity limitation.

Editor protocol advances to 28, source registry to 3 for command automatic permission and jobs to 4 for execution summaries. Display schema stays 16; external command observation stays v1. Rerun `claude-statusline install` and restart Claude Code to load matching Mods. Rollback refuses older packages that cannot read current configuration.

Supported platforms/runtimes: Node 22/24 on Linux/WSL, Windows and macOS; existing host minimums and language choices remain supported.

All six public-download jobs passed, and the actual test installation is now 3.12.0 with its original display/UI preferences preserved. The installed `0600`/`0644`/`0664` permission regression passed with unchanged bytes, modes and configuration.

Only the six existing [#96 gaps](https://github.com/fbincon/claude-code-statusline/issues/96) are accepted and remain unverified. Automated/PTY evidence does not establish physical or human desktop acceptance. No paid model calls are part of this release. Post-publication findings receive issues without a patch release.
