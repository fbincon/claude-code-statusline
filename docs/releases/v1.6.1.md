# v1.6.1: Clearer external TUI sections

The external `/statusline-configure` and standalone `claude-statusline configure` now distinguish page titles, related options, columns, selection and Preview. The in-session Client remains the visual reference, retaining its interaction.

- Main/Subagents align toggle, item and description columns; Settings groups appearance, refresh/behavior, Git metrics, formats, risk colors, subagent visibility and portable actions.
- Layout separates mode, row boundaries and item priorities/widths. Item forms group format and fitting. Nonselectable group titles remain visible during scrolling; navigation dispatches by stable field key.
- Titled content/Preview frames start at 64×20. Compact 64×18–19 keeps the original minimum, with two control rows, preserved input on resize and monochrome hierarchy. Preview fits its actual inner width.
- Python and both Mods are 1.6.1. Display schema v4, configuration protocol v3, runtime protocol v1, stored settings, editor/live preferences and launcher behavior remain compatible. Upgrading from v1.6.0 needs no display migration.

## Install or upgrade

Python 3.10–3.14; Linux/WSL, Windows and macOS. External integration requires Claude Code 2.1.258+; Client requires 2.1.287+. The fixed runtime host remains 2.1.289. Supported editor entries default on while explicit false and independent live preferences persist.

~~~text
pipx install --force "https://github.com/fbincon/claude-code-statusline/releases/download/v1.6.1/claude_code_statusline-1.6.1-py3-none-any.whl"
claude-statusline install
claude-statusline doctor
~~~

Restart Claude Code. See [external section controls](https://github.com/fbincon/claude-code-statusline/blob/v1.6.1/docs/USER_GUIDE.md#external-tui-sections), [capture provenance](https://github.com/fbincon/claude-code-statusline/blob/v1.6.1/docs/images/README.md#external-tui-v161) and [compatibility/downgrade](https://github.com/fbincon/claude-code-statusline/blob/v1.6.1/docs/USER_GUIDE.md#version-compatibility).
