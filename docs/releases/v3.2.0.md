# v3.2.0 — Configuration editing, quick setup and sample explanation

[English](#english) | [简体中文](#简体中文)

<a id="english"></a>

Edit the middle of labels, search queries, numeric values and file paths in both editors with grapheme-safe cursor movement, insertion, Backspace/Delete and horizontal scrolling. Rejected text and input overflow are explained. Native host-split paste remains limited by the host's lack of paste-origin metadata.

Open **Quick setup** with Ctrl+P or from Settings. Choose daily development, compact display, usage observation or multi-agent work; left/right and repeated-metric examples remain available. Inspect appearance and a sample, then continue editing or save. Cancellation preserves the previous draft; collector choices and explicit disablement remain unchanged.

Configured item details now explain draft enablement, known local requirements and sample condition hiding, clipping or width omission. The renderer supplies the reasons by instance ID, with separate agent sample rows. Actual session fields remain unobserved. Explanation does not write configuration, scan transcripts or start collection. External save failures keep the editor and draft open.

Upgrade with `npm install --global --ignore-scripts @fbincon/claude-code-statusline@3.2.0`, run `claude-statusline install`, then restart Claude Code. Node 22/24 and all six languages remain supported. Editor protocol advances to **13**; display schema **8**, runtime protocol **2**, portable **1** and UI preferences **1** remain compatible. Reinstall matching frontend/backend resources after upgrading.

The [v3.2.0-only decision](approvals/v3.2.0.json) accepts six historical physical/desktop/exact-declaration gaps, still marked unverified. New failures remain blocking. See [implementation and validation](../development/configuration-experience.md). Existing beta and Python rollback artifacts remain available.

两套编辑器的标签、搜索、数值和文件路径支持完整字素光标、插入、Backspace/Delete 和水平滚动，拒绝输入及队列溢出均有提示。原生宿主拆成单键的粘贴仍受缺少来源标记的限制。

通过 Ctrl+P 或设置页进入**快速配置**，选择日常开发、紧凑显示、用量观察或多代理协作；保留左右分组、重复指标示例。检查外观和示例后继续微调或保存。取消保留原有草稿，采集选择和显式禁用保持不变。

组件详情新增配置与示例说明，按实例解释草稿开关、本地已知条件、条件隐藏、裁剪和宽度省略，并分别说明代理示例行。真实会话字段保持未观察。解释不写配置、不扫描转录、不启动采集。外部保存失败时保留界面和草稿。

升级执行 `npm install --global --ignore-scripts @fbincon/claude-code-statusline@3.2.0`，再运行 `claude-statusline install` 并重启 Claude Code。继续支持 Node 22/24 和六种语言。编辑器协议升级为 **13**；显示 schema **8**、运行协议 **2**、portable **1** 和 UI preferences **1** 保持兼容，升级后需重新安装匹配的前后端资源。

[v3.2.0 专属决定](approvals/v3.2.0.json)接受原有六项实机、桌面和精确声明缺口，继续标为未验证；新增失败仍阻止发布。见[实现与验收](../development/configuration-experience.zh-CN.md)。保留既有 beta 和 Python 回退产物。
