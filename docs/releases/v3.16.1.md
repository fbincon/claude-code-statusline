# v3.16.1 — Runtime, source timeout and save-conflict repairs

**English** | [简体中文](v3.16.1.zh-CN.md)

Published on **2026-10-31**. Full gate, channel and machine evidence is in the [delivery record](../development/runtime-source-save-fixes.md#final-release).

This release repairs runtime agent identity, command-source timeouts and save conflicts.

- Preserve agent identity on runtime turn start so subagent requests and completion share one lifecycle entry instead of leaving a phantom running main turn; reconcile delayed terminal batches by observed end time ([#197](https://github.com/fbincon/claude-code-statusline/issues/197)).
- Retain failed command-source timeouts, execution diagnostics and error observations instead of converting deadline expiry into `cancelled/no_consumers`; reconcile provisional automatic feedback when delayed settlement confirms success or a pause failure ([#195](https://github.com/fbincon/claude-code-statusline/issues/195)).
- Recognize explicit-target `profile_conflict` as a definitive refusal and open ordinary conflict review in both editors, keeping the draft/history and saved winner intact ([#196](https://github.com/fbincon/claude-code-statusline/issues/196)).

Display schema 17, editor protocol 31 and existing source/runtime/storage formats remain compatible. Rerun `claude-statusline install` and restart Claude Code to load the matching runtime Mod. Old incomplete observations are not relabeled as complete.

Supported platforms/runtimes: Node 22/24 on Linux/WSL, Windows and macOS; the existing eight-target/32-Node/sixteen-host matrix and 313 Native capacity cases per host remain supported.

Both editors passed three cancel/save/restore journeys, all eleven preference paths were restored, and interactive Claude 2.1.314 testing matched the recorded API/Native/transcript requests without phantom main turns. Paid acceptance stayed within the approved budget; request and cost details are in the delivery record.

Only the six existing [#96 gaps](https://github.com/fbincon/claude-code-statusline/issues/96) are accepted and remain unverified. Post-publication machine findings receive issues while retaining v3.16.1; no additional patch release is part of this task.
