# v3.16.5 — Claude Code integration and Native controls

**English** | [简体中文](v3.16.5.zh-CN.md)

Published on **2026-11-21**.

This patch fixes bundled plugin integration on Claude Code 2.1.330 and lets users resume an unfinished 3.16.4 update.

- Install, upgrade and recover bundled plugins on Claude Code 2.1.330 and report validation failures. [#292](https://github.com/fbincon/claude-code-statusline/issues/292)
- Keep both Retry and Close available in narrow Native editor panes. [#287](https://github.com/fbincon/claude-code-statusline/issues/287)
- Compare packages before applying the scoped maintenance job budget. [#288](https://github.com/fbincon/claude-code-statusline/issues/288)

## Compatibility

If you have an unfinished 3.16.4 transaction, complete its original target using the [package management guide](../PACKAGE_MANAGEMENT.md#package-transaction-recovery), then update to v3.16.5. Run `claude-statusline install` and restart Claude Code to load the matching plugins.

This release uses display schema 17, editor protocol 32 and the existing storage formats. It supports Linux/WSL, Windows and macOS on Node 22/24.

The six existing [#96 gaps](https://github.com/fbincon/claude-code-statusline/issues/96) are accepted and remain unverified.
