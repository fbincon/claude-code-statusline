# v3.10.0 — Appearance, sample scenarios and file diagnosis

**English** | [简体中文](v3.10.0.zh-CN.md)

Published on **2026-10-28**. Full gate, channel and machine evidence is in the [delivery record](../development/appearance-preview-diagnosis.md).

This release adds four themes, eight gradient presets, deterministic sample scenarios and input-file diagnosis to both editors.

- Add ocean, ember, slate and blossom themes with a shared registration source, plus eight gradient presets.
- Preview actual color swatches, select surface-appropriate colors and edit/reverse 2–5 gradient stops. Accept candidates into the display draft and cancel individual color pages.
- Select fourteen deterministic sample scenarios, temporary preview widths and row browsing in both editors without collecting or changing saved display settings.
- Explain inactive gradients, shared backgrounds, thresholds, disabled/converted colors and contrast protection per instance/agent row.
- Diagnose an explicitly selected input file using the current unsaved draft. Editors default to input-only evidence; existing matching local observations remain opt-in. Reports retain origin/time labels and paged read-only presentation.

Display schema 16 and editor protocol 26 require matching installed resources. Old configurations read without writes; explicit saves retain backups. Restore a compatible backup before downgrading. Source/runtime/portable/UI-preference formats retain their versions. Rerun `claude-statusline install` and restart Claude Code after upgrading.

Supported platforms/runtimes: Node 22/24 on Linux/WSL, Windows and macOS; existing host minimums and language choices remain supported.

Only the six existing [#96 gaps](https://github.com/fbincon/claude-code-statusline/issues/96) are accepted and remain unverified. No paid model tests were run. Post-publication findings receive issues without a patch release.
