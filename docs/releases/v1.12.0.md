# v1.12.0 — Conditional visibility, item colors, themes and Powerline

Choose when an item appears and how it is colored through either editor or the CLI. Defaults retain the existing statusline appearance. Both main and subagent rows support per-item foreground/background overrides and optional Powerline blocks.

## Installation and compatibility

```text
pipx install --force fbincon-claude-code-statusline==1.12.0
claude-statusline install
claude-statusline doctor
```

Linux/WSL, Windows 10/11 and macOS 14+ retain Python 3.10–3.14 support. Display schema 7 and editor protocol 9 require matching package/Mod resources. Portable format v1, interface preferences v1 and runtime protocol v2 remain independent. Reading, previewing and `install --dry-run` leave v1–v6 display files unchanged; actual configuration saves or installation back up the original bytes before migration. Installation rejects invalid/future display files even with `--force`; uninstall remains available for recovery. Existing languages, item selections and explicit editor/collector opt-outs remain supported.

Before a downgrade, use the newer package to remove its native editor when necessary, and restore a compatible pre-migration display backup. Changing only the schema number cannot preserve these new fields. See [appearance and recovery](../APPEARANCE.md).

## Display changes

- Hide confirmed clean Git, confirmed zero active agents or empty task lists. A completed nonempty checklist stays visible. Unknown, stale and partial observations retain existing behavior; conditions reuse shared collectors.
- Show context and allowance items only when raw used percentage reaches an optional integer threshold. Visibility thresholds are separate from warning/critical color thresholds and do not depend on rounded or translated display text.
- Choose `classic`, `dark`, `light` or `terminal` themes. Item colors accept inheritance, terminal defaults, ANSI 0–255 and RGB. Theme changes retain item overrides; enabled risk foregrounds take precedence while preserving backgrounds.
- Enable Powerline separately, with ASCII `>` by default and an optional font-dependent arrow. Padding and boundaries participate in grapheme-safe fitting; hidden items leave no empty separators/rows and each row resets style.
- Edit, preview, cancel, review imports, export and save the complete configuration in both editors. Claude host themes and native preview backgrounds remain separate choices.

The existing macOS Client focus/input limitation remains documented in the [user guide](../USER_GUIDE.md#macos-mouse-reporting-and-client-focus). Physical fonts and terminal palettes can differ; no fonts are installed. Normal rendering remains local and model-free.

## Validation

- Local checks: 781 Python tests (773 passed, eight platform skips), 96 native and ten runtime Mod tests, both TypeScript checks, strict validators, generated resources, Ruff and bilingual documentation checks passed. GitHub CI covers Linux, Windows and macOS with Python 3.10–3.14 and fixed Claude hosts; all final head, merge and tag jobs are required before publication.
- The immutable installed candidate `d7d7c37d30ae0f2e158735806917cba261b41dda` passed independent wheel rebuilding, isolated wheel/sdist installation and core/native/runtime smoke. Real v1.11.0 wheel upgrades passed with default-enabled and explicit-opt-out preferences, read-only access, backed-up migration, compatible backup restoration, a real downgrade and reupgrade.
- Installed appearance workflows passed 20 external cases (five sizes × two languages × two backgrounds), eight native cases (two sizes × two languages × two backgrounds) and six rendering PTYs. Actual dark/light terminal reconstructions were inspected, including the independent light native preview background. These are automated and agent image checks; no new human Windows/macOS terminal acceptance or paid model calls are claimed.
- Fixed-source performance used 39,000 primary samples, 6,900 selected controls and 8,000 appearance samples. A small repeatable default cost remains: roughly 0.12–0.18 ms for 32-agent warm refresh and about 6 ms for controlled cold import, including environmental variation. See the [complete performance report](../development/performance-v1.12.0.md) for controls, limitations and opt-in costs. Raw receipts remain in ignored `dist/validation/v1.12`.

## 条件显示、逐项颜色、主题与 Powerline

通过两个编辑器或 CLI 控制显示项何时出现以及如何配色，默认保留既有外观。主／子代理行都支持逐项前景／背景色和按需开启的 Powerline。

```text
pipx install --force fbincon-claude-code-statusline==1.12.0
claude-statusline install
claude-statusline doctor
```

继续支持 Linux／WSL、Windows 10/11、macOS 14+ 与 Python 3.10–3.14。显示 schema 7、编辑器协议 9 要求软件包与 Mod 资源匹配；portable v1、界面偏好 v1、runtime v2 独立。读取 v1–v6、预览和 `install --dry-run` 不写入，实际配置保存或安装时先备份再迁移；未来或非法显示配置即使使用 `--force` 也会被安装器拒绝，仍可卸载以便恢复。保留语言、项目选择及显式编辑器／采集退出设置。降级时用新版软件先移除需要清理的原生编辑器，恢复迁移前的兼容显示备份；不要只修改 schema 数字。详见[外观与恢复](../APPEARANCE.zh-CN.md)。

- 仅依据完整有效观测隐藏干净 Git、零活动代理和空任务列表；非空但全部完成的列表仍显示，未知／过期／部分数据沿用原有表现。
- 上下文与额度按原始已用比例判断显示阈值，独立于警告／危险颜色阈值，不受四舍五入或翻译影响。
