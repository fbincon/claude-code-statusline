# v3.14.0 — 自适应与连续背景

[English](v3.14.0.md) | **简体中文**

已于 **2026-10-29** 发布。完整门禁、渠道及本机证据见[交付记录](../development/adaptive-row-scenarios.zh-CN.md)。

本版本新增自适应进度条、连续 Powerline 背景和五个新方案。

- 自适应进度条按空间逐步缩减，始终保留百分比与已用／剩余含义；自定义标签和图标保持完整。
- Powerline 连续行背景在最终拟合、分组、换行和对齐后着色。
- 新增 `powerline-daily`、`agent-workbench`、`quota-cost`、`narrow-terminal`、`light-readable` 五个方案，保持数据源授权独立。Native 新入口六语言标题已修正。
- 新增 `release:signatures` 专用验证流程；原生全树 npm 签名审计仍有内置私有工作区包限制。
- 包审阅状态在确认后台进程退出后重新核对最新私有结果，避免把早先“运行中”快照之后已发布的完成结果误报为中断。所属编辑器、配置修订、未知存活状态和现有期限继续受到检查。

显示 schema 17，编辑器协议 30；portable／profile 外层格式保持 1。旧文件读取不写入。保留八个安装目标、32 项 Node、十六个固定宿主和 271 项容量案例。升级后运行 `claude-statusline install` 并重启 Claude Code。

支持平台／运行时：Node 22／24，Linux／WSL、Windows 和 macOS；既有宿主最低版本及语言选择保持可用。

仅接受 [issue #96 六项既有缺口](https://github.com/fbincon/claude-code-statusline/issues/96)，它们仍未验证；必需自动化失败仍阻断发布。付费模型范围及结果见交付记录；发布后新发现只提 issue，不补发修补版。
