# v3.14.0 — Adaptive and continuous appearance

**English** | [简体中文](v3.14.0.zh-CN.md)

Published on **2026-10-29**. Full gate, channel and machine evidence is in the [delivery record](../development/adaptive-row-scenarios.md).

This release adds adaptive bars, continuous Powerline backgrounds and five new schemes.

- Adaptive bars progressively fit available space while retaining percentages and used/remaining meaning. Custom labels and icons stay whole.
- Paint continuous Powerline row backgrounds after final fitting, grouping, wrapping and alignment.
- Add `powerline-daily`, `agent-workbench`, `quota-cost`, `narrow-terminal` and `light-readable` schemes, keeping source authorization independent. Correct Native entry captions in all six languages.
- Add the `release:signatures` flow to verify signatures and provenance; native full-tree npm auditing retains its bundled-private-workspace limitation.
- Reconcile package-review status with the latest private result after observing worker exit, avoiding false interruption when completion was published after an earlier running snapshot. Ownership, configuration revisions, unknown liveness and existing deadlines remain enforced.

Display schema 17 and editor protocol 30 retain portable/profile envelopes 1 and read-only old-file handling. Preserve eight installation targets, 32 Node cases, sixteen fixed hosts and 271 capacity cases. Rerun `claude-statusline install` and restart Claude Code after upgrading.

Supported platforms/runtimes: Node 22/24 on Linux/WSL, Windows and macOS; existing host minimums and language choices remain supported.

Only the six existing [#96 gaps](https://github.com/fbincon/claude-code-statusline/issues/96) are accepted and remain unverified; required automated failures still block publication. Paid-model scope and outcomes are recorded in the delivery record. Post-publication findings receive issues without a patch release.
