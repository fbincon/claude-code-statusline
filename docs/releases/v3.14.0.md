# v3.14.0 — Adaptive and continuous appearance

**English** | [简体中文](v3.14.0.zh-CN.md)

Adaptive bars progressively fit available space while retaining percentages and used/remaining meaning. Custom labels and icons stay whole. Continuous Powerline row backgrounds are painted after final fitting, grouping, wrapping and alignment.

Five schemes add `powerline-daily`, `agent-workbench`, `quota-cost`, `narrow-terminal` and `light-readable`, keeping source authorization independent. Native entry captions are corrected in all six languages. The new `release:signatures` flow verifies signatures and provenance; native full-tree npm auditing retains its bundled-private-workspace limitation.

Display schema 17 and editor protocol 30 retain portable/profile envelopes 1 and read-only old-file handling. Preserve eight installation targets, 32 Node cases, sixteen fixed hosts and 271 capacity cases. Only the six existing #96 gaps remain accepted and unverified; required automated failures still block publication.
