# v3.6.0 — Explicit sources and workflow status

Add locally registered JSON, GitHub and command sources, shared management in
both editors and CLI, and optional clickable directory/PR/check text.

- Source activation is explicit. Imports remove local bindings; previews use
  samples. GitHub and commands refresh only on request, outside rendering.
- GitHub PR/check components supplement the existing host PR field. Unknown,
  absent, cancelled and skipped checks never become a false passing result.
- Source errors and stale values remain marked; identity changes suppress old
  results. Commands use literal argv, bounded output/deadlines and descendant
  cleanup.
- Shared component capabilities align supported options, source guidance and
  link settings. Existing component IDs, defaults and profiles are preserved.
- Display schema 10 and editor protocol 17 require matching frontend/backend
  resources. Old display files migrate in memory and are rewritten only on save.

See [extensions](../EXTENSIONS.md), [CLI reference](../reference/cli.md),
[implementation and validation](../development/extensions.md) and the
[version-specific acceptance decision](approvals/v3.6.0.json).

Published on 2026-10-23 from `359b627aa3c4349b15f0b5007fc33fa17a8c0062`.
Final PR/main/tag gates, eight installation targets, 32 Node cases, thirteen
fixed hosts, reproducible builds and three-channel public downloads passed.

including the unchanged main retry and delayed npm visibility recovery. The six
