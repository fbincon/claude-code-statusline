# v3.1.2 — External terminal editor navigation and text repairs

[English](#english) | [简体中文](#简体中文)

<a id="english"></a>

Repair six external `/statusline-configure` regressions found by an independent comparison with the fixed Python v2.0.0 source.

- Open sources/requirements for unconfigured picker types without crashing; resolve catalog titles correctly even when custom instance IDs collide with type IDs.
- Edit a new text component's body first, preserving its original Unicode through preview, save and reopen in both scopes.
- Restore Settings/Layout selection and scroll on return, and page grouped forms by visible fields rather than terminal rows.
- Honor monochrome TERM capabilities before truecolor hints and clear a resolved form error without dismissing unrelated notices.
- Add keyboard, style, persistence and installed-PTY regressions. Pure documentation changes receive necessary checks; product/version/approval/workflow changes and releases retain the complete matrix.

Node 22/24, public CLI, protocol 12, display schema 8 and independent preference/save behavior remain compatible. Upgrade with `npm install --global --ignore-scripts @fbincon/claude-code-statusline`, run `claude-statusline install`, and restart Claude Code. Exact version: `@fbincon/claude-code-statusline@3.1.2`. [Installation and recovery](../USER_GUIDE.md#installation-and-integration).

**Accepted known gaps:** the [v3.1.2-only maintainer decision](approvals/v3.1.2.json) accepts physical macOS sleep, macOS 14 Intel desktop/power, Windows 10 desktop, WSL desktop/popup, remaining target-specific human/power checks and Claude 2.1.296 exact declarations. They remain unverified/unavailable; new functional or automated failures are not waived. D06 stays FAIL; PERF-01 stays NOT_STARTED. Existing beta and Python rollback artifacts remain available.

[Implementation and validation](../development/external-tui-regressions.md). Final public delivery receipts are recorded in the [maintained evidence](https://github.com/fbincon/claude-code-statusline/blob/main/docs/development/external-tui-regressions.md).

通过独立对照固定 Python v2.0.0 源码，修复外部 `/statusline-configure` 的六项回归。

- 未配置类型可打开来源／要求说明，避免崩溃；自定义实例 ID 与类型 ID 重名时，目录标题仍正确。
- 新文字组件首先编辑正文，两个作用域均保留原始 Unicode，并正确进入预览、保存及重开。
- Settings／Layout 返回时恢复选中字段与滚动，分组表单按可见字段翻页。
- 单色 TERM 优先于真彩提示，修正值后清除对应表单错误，无关通知保持原有行为。
- 增加按键、样式、持久化和安装包 PTY 回归。纯文档变更运行必要检查；产品／版本／批准／工作流变更和发布保留完整矩阵。

Node 22／24、公共 CLI、协议 12、显示 schema 8 及独立偏好／保存行为保持兼容。升级执行 `npm install --global --ignore-scripts @fbincon/claude-code-statusline`，然后运行 `claude-statusline install` 并重启 Claude Code；固定版本为 `@fbincon/claude-code-statusline@3.1.2`。[安装与恢复](../USER_GUIDE.zh-CN.md#安装与接入)。

**接受的已知缺口：** [v3.1.2 专属维护者决定](approvals/v3.1.2.json)接受 macOS 实机睡眠、macOS 14 Intel 桌面／电源、Windows 10 桌面、WSL 桌面／弹窗、其他目标人工／电源检查、Claude 2.1.296 精确声明。未验证／不可用状态保留，不豁免新增功能或自动化失败。D06 保持 FAIL，PERF-01 保持 NOT_STARTED，已有 beta 和 Python 回退产物保留。
