# v3.17.0 — AgentRow and editor improvements

**English** | [简体中文](v3.17.0.zh-CN.md)

Published on **2026-11-28**.

Use the same subagent display configuration with Claude Code's AgentRow Mod and the legacy command callback. Both configuration editors place Layout before Settings, and the external editor adds component examples and longer Claude-launched sessions.

- Render custom subagent lines through AgentRow on compatible hosts. Choose the integration with `claude-statusline install --subagent-renderer auto|mod|legacy`. [#308](https://github.com/fbincon/claude-code-statusline/pull/308)
- Record, restore and share keyboard shortcuts between both editors. Use consistent component-list controls and activate a selected terminal Settings entry with Enter. [#301](https://github.com/fbincon/claude-code-statusline/pull/301) · [#302](https://github.com/fbincon/claude-code-statusline/pull/302) · [#303](https://github.com/fbincon/claude-code-statusline/pull/303) · [#304](https://github.com/fbincon/claude-code-statusline/pull/304) · [#306](https://github.com/fbincon/claude-code-statusline/pull/306)
- Find Layout before Settings in both editors. The external editor shows the example after the description for a selected component.
- Use the external editor for up to 30 minutes when launching it from Claude Code.
- Follow task reports and package or source job progress as they update in the external editor. [#305](https://github.com/fbincon/claude-code-statusline/pull/305)
- Keep task timing, current state and tool activity tied to their originating user prompt as live observations catch up. [#300](https://github.com/fbincon/claude-code-statusline/pull/300)

## Compatibility and installation

Install or update the npm package, run `claude-statusline install` and restart Claude Code to load the matching Mods. This release uses display schema 17, editor protocol 33 and shortcut preferences schema 1. [Upgrade guide](../USER_GUIDE.md#upgrading) · [Protocol and schema versions](../reference/cli.md#protocol-and-schema-versions)

Use Node 22/24 on Linux x64, Windows with x64 Node, or macOS Intel or Apple Silicon. The AgentRow Mod requires Claude Code 2.1.326 or newer. The command callback is available on 2.1.205–2.1.322 and 2.1.326–2.1.332. Claude Code 2.1.323–2.1.325 shows its built-in subagent rows. [Host requirements](../USER_GUIDE.md#requirements)

The six existing [#96 gaps](https://github.com/fbincon/claude-code-statusline/issues/96) are accepted and remain unverified.
