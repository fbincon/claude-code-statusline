# v3.16.3 — Configuration skill workflow repairs

**English** | [简体中文](v3.16.3.zh-CN.md)

Published on **2026-11-05**. Full gate, channel and machine evidence is in the [delivery record](../development/skill-workflows.md#final-release).

This release repairs the bundled configuration skill workflows and aligns the CLI reference with the shared slash parser.

- The `/statusline-config` wizard keeps item and language choices within the host question tool's limits. It starts from saved values, retains answers across pages and saves once after every answer is resolved. A page's “None” option affects only that page; cancellation does not save configuration. [Wizard](../USER_GUIDE.md#statusline-config-wizard)
- Repeated instances, text/spacers, groups and main-row alignments stop the type-based wizard before edits. It explains user-default scope and directs named-profile/project work to the matching editor or terminal command. [Profiles and projects](../PROFILES.md)
- Argument fallback treats quoted values as literal arguments. The wizard checks installation/ownership before asking and rereads saved state before applying answers; a changed snapshot requires restarting. This is a best-effort recheck, not a revision-bound save. [Workflow and limits](../development/skill-workflows.md)
- Theme choices come from the current registry. The CLI reference now reflects all nineteen shared slash-parser actions, including instance, group, alignment, layout and transfer operations; profile/project management remains in terminal commands or editors. [Slash support](../reference/cli.md#slash-command-support)
- The external launcher's fallback describes the stable Node TUI, suggests the Windows `.cmd` entry when appropriate and retains its prohibition on starting terminal interfaces through model tools. [External editor](../USER_GUIDE.md#external-terminal-statusline-configure)

After upgrading, run `claude-statusline install` and restart Claude Code to refresh the installed skills. Display schema 17, editor protocol 31 and existing storage formats remain compatible.

Supported platforms/runtimes: Node 22/24 on Linux/WSL, Windows and macOS; existing host minimums and language choices remain supported.

Only the six existing [#96 gaps](https://github.com/fbincon/claude-code-statusline/issues/96) are accepted and remain unverified. Paid-model scope and outcomes are recorded in the delivery record. Post-publication findings receive issues without a patch release.
