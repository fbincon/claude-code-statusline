# v1.3.0a2 — external TUI and in-session Client

This opt-in preview preserves the existing external TUI and introduces an experimental Client TUI inside the current Claude Code session. Latest stable remains v1.2.0.

- `/statusline-configure` opens the existing platform terminal TUI; `/statusline-configure-native` opens Client without another terminal. Both install/disable independently. Reinstall restores enabled owned external resources removed by older native migration.
- Click the Client region once, then use arrows for navigation/order, Tab for pages, Space for toggles, / for search and Ctrl+G to cancel editing. s saves/continues, f saves/finishes and q discards/closes. Esc remains host-owned. Grouped borders, aligned settings and compact separators distinguish content and preview.
- Both editors share revision-protected atomic saves. Client keeps conflicting drafts and checks unknown outcomes before retry. Claude preferences apply separately. Ordered acknowledged input and copied snapshots protect rapid keys, pending drafts and late replies.

## Install

```bash
pipx install --force "https://github.com/fbincon/claude-code-statusline/releases/download/v1.3.0a2/claude_code_statusline-1.3.0a2-py3-none-any.whl"
claude-statusline install --experimental-slash-tui --native-editor
claude-statusline doctor
```

Restart Claude Code in a trusted terminal. Select only the desired enable flag if you need one mode. `--no-experimental-slash-tui` and `--no-native-editor` disable them independently. Mod requires 2.1.287+; the fixed host matrix checks Linux 2.1.287/2.1.288 and Windows/macOS 2.1.288. Existing Python/platform support and display schema are unchanged. See the [fixed-tag Client guide](https://github.com/fbincon/claude-code-statusline/blob/v1.3.0a2/docs/development/native.md) and [capture provenance](https://github.com/fbincon/claude-code-statusline/blob/v1.3.0a2/docs/images/README.md).

## Validation

Local regression: 437 Python tests passed (8 platform skips), 34 official Mod tests passed on fixed Linux hosts, and TypeScript, Ruff, shared contracts and documentation checks passed. Final fixed-candidate CI, installed-package and download results are recorded during release verification.

The maintainer confirmed v1.3.0a1's native-control UI passed human acceptance on Linux, Windows and macOS. v1.3.0a2 Client human acceptance is separately pending on all three platforms. Automated callback/PTY tests and reconstructed terminal captures are not human acceptance. No paid model/timer suite was run for this UI release.

Assets: matching wheel, source distribution and SHA256SUMS. Backend 1.3.0a2 pairs with Mod 1.3.0-alpha.2. This release is a prerelease and does not change Latest.
