# v1.7.2 — Clearer in-session configuration controls

The in-session editor consolidates its controls in a wrapping, state-aware footer and uses a consistent heading and key style. Python and both Mods are 1.7.2.

## Interface and input

- The heading is **Configure Status Line**, in the same cyan as the section titles. Letter keys display uppercase and action descriptions lowercase; numbered page names and modifier-key spelling retain their existing form.
- All idle page controls start with Tab. Main/Subagents order is `Tab page · Space toggle · ↑↓ select · ←→ order · Ctrl+E format · / search`; Settings, Layout and item forms retain their applicable edit/adjust controls after Tab.
- Filter keeps its search entry. The footer offers search on idle item pages, H to show/hide preferences in Settings, A only when expanded, and dedicated editing/busy/recovery controls. Claude preferences still apply separately from tool saves.
- Complete hints wrap together. Drawing and keyboard pagination share the footer budget; 32×12 panes retain selection and a sample preview, reducing details or secondary hints when needed.
- Ordinary ASCII letter shortcuts accept either case outside editing. Search, fields, paths and numeric buffers retain literal case; Ctrl/Meta combinations, Ctrl+E/G/U and Shift+Tab retain their roles.

## Install or upgrade

```bash
pipx install --force "https://github.com/fbincon/claude-code-statusline/releases/download/v1.7.2/claude_code_statusline-1.7.2-py3-none-any.whl"
claude-statusline install --dry-run
claude-statusline install
claude-statusline doctor
```

Restart Claude Code after integration. On Windows use `claude-statusline.exe`. Existing display schema v5, configuration protocol v4, runtime protocol v2, timing behavior and independently saved installation preferences remain compatible. See the [user guide](../USER_GUIDE.md).
