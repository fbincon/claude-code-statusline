# v3.1.1 — External terminal editor rendering and contextual controls

[English](#english) | [简体中文](#简体中文)

<a id="english"></a>

The external `/statusline-configure` editor retains six languages, cyan headings and full-row selection while restoring clear field names, search details and state-specific controls.

- Complete group separators share one cyan/bold style. Terminal-default borders and backgrounds, highlighted keys and notices, and basic-color preview intensity remain readable in light and dark profiles.
- Fix double ellipses, duplicated Enter labels, inherited-value localization and English preview plurals. Literal labels, icons, text and Git references keep their spelling.
- Restore Enter/Ctrl+S saving hints, add/copy/remove discovery, category navigation, numeric editing hints, format scope/back controls and match snippets. Filtered lists omit ordering hints.
- Changed configuration text shows the pending-edit marker before confirmation; opening an edit or entering a portable-file path alone does not. Small windows retain the title, wrapped dimensions and exit controls.
- Drawing responsibilities and product regressions are separated. Public CLI, editor protocol 12, display schema 8 and persisted configuration formats remain compatible. Node 22/24 and the existing supported targets remain unchanged.

Upgrade with `npm install --global --ignore-scripts @fbincon/claude-code-statusline`, then run `claude-statusline install` and restart Claude Code so installed resources match. The fixed package is `@fbincon/claude-code-statusline@3.1.1`. [Installation and recovery](../USER_GUIDE.md#installation-and-integration).

**Accepted known gaps:** this version has its own maintainer decision accepting and disclosing the same six existing gaps: physical macOS sleep, macOS 14 Intel desktop/power, Windows 10 desktop, WSL desktop/popup, remaining target-specific human/power checks and Claude 2.1.296 exact declarations. They remain unverified; new functional or automated failures are not waived. [Version-specific approval](approvals/v3.1.1.json) · [Validation and delivery](../development/external-tui-parity.md).

D06 remains FAIL; PERF-01 remains separate and NOT_STARTED. This patch makes no performance claim. Existing beta and Python rollback artifacts are retained.

外部 `/statusline-configure` 编辑器保留六语言、青色标题和整行选中，恢复清晰字段名称、搜索详情与按状态匹配的操作提示。

- 完整分组横线统一青色加粗；边框与背景保留终端默认值，快捷键和通知保持加粗，基础色阶的预览亮色保留强度，兼容明暗终端。
- 修复双省略号、重复 Enter、继承值本地化及英文预览复数；用户标签、图标、文字和 Git 引用保持原样。
- 恢复 Enter/Ctrl+S 保存提示、添加／复制／移除入口、分类导航、数字输入、格式作用域／返回提示与搜索匹配片段；筛选时隐藏排序提示。
- 配置文本实际改变后，在确认前即显示修改标记；仅打开编辑或填写导入／导出路径不标记配置改动。小窗口保留标题、换行尺寸信息和退出操作。
- 拆分绘制职责及产品回归测试。公共 CLI、编辑器协议 12、显示 schema 8 和持久配置格式保持兼容；Node 22／24 及现有支持目标保持不变。

升级使用 `npm install --global --ignore-scripts @fbincon/claude-code-statusline`，随后执行 `claude-statusline install` 并重启 Claude Code，确保安装资源配套；固定版本为 `@fbincon/claude-code-statusline@3.1.1`。[安装与恢复](../USER_GUIDE.zh-CN.md#安装与接入)。
