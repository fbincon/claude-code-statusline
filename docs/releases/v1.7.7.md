# v1.7.7 — Readable external TUI on light terminals

The external configuration editor follows the terminal's default text colors. Headings and shortcut keys remain bold and readable on light and dark terminal backgrounds; selections reverse the default foreground/background. Sample previews use a separate dark interior, preserving the status-line sample palette within terminal capabilities.

## Install or upgrade

```text
pipx install --force fbincon-claude-code-statusline==1.7.7
claude-statusline install --dry-run
claude-statusline install
claude-statusline doctor
```

Close Claude Code before updating the installed integration and restart it afterwards. The CLI name remains `claude-statusline`; saved display configuration and integration preferences are retained. Previous distribution-name installations use the [migration guide](../USER_GUIDE.md#migrate-the-previous-distribution-name).

## Behavior and compatibility

- `/statusline-configure` and standalone `configure` share terminal-default chrome. Keys and headings are bold; descriptions use regular text. Fixed white/cyan foregrounds and dim chrome are removed, including forms, empty searches and small-window guidance.
- Every preview interior cell has a dedicated dark background targeting `#17191e`; uncolored spans and resets use neutral text targeting `#dedee7`. RGB/ANSI sample colors retain their capability-based mapping. Monochrome terminals or failed base-pair initialization fall back to default text; exhausted sample pairs retain the neutral preview pair.
- External color allocation is centralized, cached by foreground/background, and bounded by Python's color-pair attributes. Compatibility exports retain shared identity; navigation, saves, configuration schema v5, configuration protocol v4 and runtime protocol v2 remain compatible.
- Capture analysis records light/dark terminal-default fixtures and the ANSI palette, checks reversed colors and full preview fill, and distinguishes terminal reconstructions from physical-terminal/human evidence.

Python and both Mod release manifests are 1.7.7. The in-session editor continues to use the applied Claude theme. The external minimum remains 64×18; 32×12 exercises readable resize/cancel guidance. This UI patch uses local commands and fixed samples without paid model calls.

## Validation and publication

Local checks passed 657 Python tests (649 passes, eight expected platform skips), 59 native and ten runtime official Mod tests on Claude Code 2.1.295, both TypeScript projects with exact 2.1.294 declarations, generated contracts, Ruff and documentation checks.

Publication requires all 13 Python/build and ten fixed Mod CI jobs on the PR, merge commit and tag; complete local checks; exact-commit distributions and independent rebuilding; installed-package and 1.7.6 upgrade checks; five-size light/dark external PTYs; checksum verification; TestPyPI acceptance; and formal PyPI index installations. Platform evidence, reconstructed terminal images and human acceptance are recorded separately.

## v1.7.7 — 浅色终端下清晰的外部 TUI

外部配置编辑器跟随终端默认文字色，浅色和深色背景下的标题及快捷键保持加粗、清晰；选中项反转默认前景／背景。样例预览使用独立深色内部区域，按终端能力保留状态栏样例配色。

### 安装或升级

```text
pipx install --force fbincon-claude-code-statusline==1.7.7
claude-statusline install --dry-run
claude-statusline install
claude-statusline doctor
```

更新已安装接入前退出 Claude Code，完成后重新打开。CLI 仍为 `claude-statusline`，保留显示配置与接入偏好；旧分发名称安装使用[迁移指南](../USER_GUIDE.zh-CN.md#迁移旧分发名称)。

### 行为与兼容性

- `/statusline-configure` 与独立 `configure` 共用终端默认色界面；按键和标题加粗，说明使用普通文字。表单、空搜索和小窗口提示同样移除固定白色／浅青色及淡化属性。
- 完整填充预览内部，深底目标为 `#17191e`，无色 span 和颜色重置使用目标 `#dedee7` 的中性文字。RGB／ANSI 样例按能力映射；无色或基础色对初始化失败时使用默认文字，样例颜色对不足时使用预览基础色对。
- 外部颜色分配集中管理，按前景／背景缓存，并遵守 Python 颜色对属性上限。兼容导出保持共享身份；导航、保存、显示 schema v5、配置协议 v4 和运行协议 v2 保持兼容。
- 捕获分析记录浅色／深色终端默认色夹具及 ANSI 调色板，检查反色与预览完整填充；终端重建图、物理终端检查和真人验收分别记录。

Python 和两个 Mod 发布 manifest 为 1.7.7。内部编辑器继续使用 Claude 实际主题。外部最低尺寸仍为 64×18，32×12 检查清晰的缩放／取消提示。本次 UI 补丁使用本地命令和固定样例，不调用付费模型。
