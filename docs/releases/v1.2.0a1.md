# v1.2.0a1 — Native configuration editor preview

A native configuration editor is now bundled with the Python package. This prerelease keeps native integration opt-in; **v1.1.1 remains the Latest stable release**.

Main and Subagents edit all 24 main and 10 subagent items, exclusions, ordering and sample preview. Settings covers the nine existing tool options. Saves send a complete draft and opening revision, retain the pane after success, and preserve drafts on conflicts. Uncertain outcomes require reading saved state before retry. Actual theme/verbose host rows apply separately with lock/refusal/partial-success feedback.

The installer uses a tool-owned local marketplace and official plugin operations, binds the selected absolute backend, and migrates owned `/statusline-configure` resources only after verification. `/statusline-configure-native`, the wizard and standalone TUI remain available. Doctor separates disk installation from unverified session loading. Explicit disablement, incompatible hosts, downgrade and uninstall have ownership-preserving recovery paths.

Install the preview wheel, then explicitly enable native integration:

```bash
pipx install --force "https://github.com/fbincon/claude-code-statusline/releases/download/v1.2.0a1/claude_code_statusline-1.2.0a1-py3-none-any.whl"
claude-statusline install --native-editor
claude-statusline doctor
```

Restart Claude Code 2.1.287+ in a trusted terminal and run `/statusline-configure`. Use `install --no-native-editor` to remove owned native integration and persist disablement. Before downgrading Python packages, run that command with the newer package first. Display schema v2 and protocol v1 are retained; Mod SemVer 1.2.0-alpha.1 matches backend PEP 440 1.2.0a1.

Validation includes Python/platform/build CI, exact-build Mod declarations, strict plugin validation, official Mod tests, TypeScript, owned installation and complete JSON bridge saves on Linux 2.1.287/2.1.288 and Windows/macOS 2.1.288. Separate wheel/sdist/rebuild and public-download installation checks are release gates. The maintainer confirmed the full Linux human checklist on 2026-10-04 using backend 1.2.0a1 and host 2.1.288; terminal product/version was not supplied. Windows/macOS native human interaction remains unverified. **Stable v1.2.0 and Phase 2 completion require those remaining human results.**

See the [English user guide](https://github.com/fbincon/claude-code-statusline/blob/v1.2.0a1/docs/USER_GUIDE.md#native-editor-preview) and [native behavior/acceptance](https://github.com/fbincon/claude-code-statusline/blob/v1.2.0a1/docs/development/native.md).
