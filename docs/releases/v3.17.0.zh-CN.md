# v3.17.0 — AgentRow 子代理状态行与编辑器改进

[English](v3.17.0.md) | **简体中文**

已于 **2026-11-28** 发布。

Claude Code 的 AgentRow Mod 与旧版命令回调使用同一份子代理显示配置。两种配置编辑器都将「布局」放在「设置」之前，外部编辑器增加了使用时间和组件示例。

- 在兼容宿主上通过 AgentRow 显示自定义子代理状态行。使用 `claude-statusline install --subagent-renderer auto|mod|legacy` 选择接入方式。 [#308](https://github.com/fbincon/claude-code-statusline/pull/308)
- 在两种编辑器中录制、恢复和共享快捷键。组件列表操作统一，外部编辑器可按 Enter 打开选中的设置项。 [#301](https://github.com/fbincon/claude-code-statusline/pull/301) · [#302](https://github.com/fbincon/claude-code-statusline/pull/302) · [#303](https://github.com/fbincon/claude-code-statusline/pull/303) · [#304](https://github.com/fbincon/claude-code-statusline/pull/304) · [#306](https://github.com/fbincon/claude-code-statusline/pull/306)
- 两种编辑器的「布局」均位于「设置」之前，外部编辑器在所选组件的说明后展示示例。
- 从 Claude Code 打开的外部编辑器可使用至多 30 分钟。
- 在外部编辑器中查看自动更新的任务报告、包作业与来源作业进度。 [#305](https://github.com/fbincon/claude-code-statusline/pull/305)
- 实时观测尚未更新时，仍将任务计时、当前状态和工具活动关联到对应的用户提示词。 [#300](https://github.com/fbincon/claude-code-statusline/pull/300)

## 兼容性与安装

安装或更新 npm 包后，运行 `claude-statusline install`，重启 Claude Code 以加载匹配的 Mod。本版使用显示 schema 17、编辑器协议 33 和快捷键偏好 schema 1。 [升级指南](../USER_GUIDE.zh-CN.md#升级) · [协议与 schema 版本](../reference/cli.zh-CN.md#协议与-schema-版本)

支持使用 Node 22/24 的 Linux x64、运行 x64 Node 的 Windows、以及 Intel 或 Apple Silicon 的 macOS。AgentRow Mod 需要 Claude Code 2.1.326 或更新版本。2.1.205–2.1.322 和 2.1.326–2.1.332 支持命令回调，2.1.323–2.1.325 显示 Claude Code 内置的子代理行。 [宿主要求](../USER_GUIDE.zh-CN.md#运行要求)

已接受现有 [#96 缺口](https://github.com/fbincon/claude-code-statusline/issues/96) 的六项未验证事项。
