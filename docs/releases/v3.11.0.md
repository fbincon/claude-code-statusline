# v3.11.0 — Task browsing and version review

**English** | [简体中文](v3.11.0.zh-CN.md)

This release adds the standalone `task view` command and external-editor task entry, with shared Native/external search, status filters, tree folding, evidence layers and stable reading position.

Both editors now show local installation status and offer explicit metadata checks and verified package dry-run reviews. Package rollback and configuration-restoration reviews remain separate. Execution and protected history cleanup continue through the existing CLI; their editor flows belong to later UPDATE-02 slices.

Editor protocol is 27; display schema remains 16 and task details remain version 1. Reinstall matching Native resources after upgrading, then reopen the editor or restart Claude. Existing display choices, task stores and source permissions remain compatible.

[Task details](../TASK_DETAILS.md) · [Package management](../PACKAGE_MANAGEMENT.md) · [Implementation and validation](../development/task-version-review.md).

Publication requires the final PR/main/tag evidence chain and the version-specific acceptance of only the six existing, still-unverified issue #96 gaps. Automated and PTY evidence does not establish human desktop or physical power acceptance.
