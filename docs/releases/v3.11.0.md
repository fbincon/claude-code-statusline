# v3.11.0 — Task browsing and version review

**English** | [简体中文](v3.11.0.zh-CN.md)

Published on **2026-10-28**. Full gate, channel and machine evidence is in the [delivery record](../development/task-version-review.md).

This release adds task browsing and local version review to both editors.

- Add the standalone `task view` command and external-editor task entry, with shared Native/external search, status filters, tree folding, evidence layers and stable reading position.
- Show local installation status and offer explicit metadata checks and verified package dry-run reviews in both editors.
- Keep package rollback and configuration-restoration reviews separate. Execution and protected history cleanup continue through the existing CLI; their editor flows belong to later UPDATE-02 slices.

Editor protocol is 27; display schema remains 16 and task details remain version 1. Rerun `claude-statusline install`, then reopen the editor or restart Claude Code. Existing display choices, task stores and source permissions remain compatible.

Supported platforms/runtimes: Node 22/24 on Linux/WSL, Windows and macOS; existing host minimums and language choices remain supported.

Known issue: ordinary npm manifest permissions such as `0644`/`0664` can produce an incorrect local read/compatibility warning on the version page. [Issue #173](https://github.com/fbincon/claude-code-statusline/issues/173) records the cause and regression requirements; 3.11.0 is retained and no 3.11.1 is published.

Only the six existing [#96 gaps](https://github.com/fbincon/claude-code-statusline/issues/96) are accepted and remain unverified. Automated and PTY evidence does not establish human desktop or physical power acceptance. Paid-model scope and outcomes are recorded in the delivery record. Post-publication findings receive issues without a patch release.
