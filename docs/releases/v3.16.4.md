# v3.16.4 — Reliable npm setup and statusline fixes

**English** | [简体中文](v3.16.4.zh-CN.md)

Published on **2026-11-21**.

The default npm first entry now reaches setup on a fresh install. This release also improves rendering, source selection and editor controls.

- Let GitHub sources follow the current worktree branch as it changes.
- Complete the default `npx @fbincon/claude-code-statusline` installation and open setup after confirmation. [#220](https://github.com/fbincon/claude-code-statusline/issues/220)
- Fix subagent display, session effort and task timing transitions.
- Correct permission-mode snapshots, context percentages, semantic separators and main-row styles.
- Improve component selection and group movement, and keep Native editor controls clear of host recovery buttons.
- Align Hong Kong Chinese wording across the CLI and editors.

Run `claude-statusline install` and restart Claude Code after upgrading so the bundled editors match editor protocol 32. Display schema 17 remains readable. Saving a following GitHub source can advance the source registry to version 4. Check downgrade compatibility before replacing the package.

Supported platforms and runtimes include Linux/WSL, Windows and macOS with Node 22/24. The existing Claude Code host requirements apply.

The six existing [#96 gaps](https://github.com/fbincon/claude-code-statusline/issues/96) are accepted and remain unverified.
