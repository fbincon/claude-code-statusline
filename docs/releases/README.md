## How to read this index

- **Date** is the public release date from the [changelog](../../CHANGELOG.md).
- **Status** is `Latest`, `Stable` or `Preview`; alpha, beta and release-candidate tags are previews.
- The language link opens the other language: `#简体中文` for historical one-page notes, `.zh-CN.md` for v3.10.0 and later.
- [`approvals/`](approvals/registry.json) holds version-limited maintainer decisions. Delivery evidence is under [development history](../development/history/README.md).

## Directory notes

Each version has one release page; v3.10.0 and later split English and Chinese. `approvals/` contains machine-readable decisions, not reader documentation. The [changelog](../../CHANGELOG.md) owns the dated one-line summaries; [development history](../development/history/README.md) owns delivery and acceptance evidence.
