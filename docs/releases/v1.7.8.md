# v1.7.8 — Independent native preview backgrounds

The in-session configuration editor keeps previews inside the pane and adds **Preview background (UI only)** in Settings. Choose `light` or `dark` to match the terminal’s background type, independently of the Claude theme. Compare the default and ANSI palettes on that surface before saving display changes.

## Install or upgrade

```text
pipx install --force fbincon-claude-code-statusline==1.7.8
claude-statusline install --dry-run
claude-statusline install
claude-statusline doctor
```

Restart Claude Code after refreshing the integration. Display configuration and recorded integration preferences are retained. The CLI remains `claude-statusline`; previous distribution-name installations use the [migration guide](../USER_GUIDE.md#migrate-the-previous-distribution-name).

## Behavior and compatibility

- Preview background is an editor preference remembered immediately, including after discarding unsaved display edits. It defaults to the previous dark surface; missing/invalid stored values use dark, and a failed write restores the last choice. It is outside configuration drafts, presets, portable exports and the actual status line.
- The light/dark presets are `#ffffff` and `#17191e`. Choose them manually to match terminal appearance; this does not query the terminal’s exact RGB background. The host repaints default Client backgrounds inside a docked pane, so transparent properties alone cannot provide the terminal background there.
- RGB samples retain their values; ANSI samples address terminal slots 0–15 instead of named colors that the host remaps. Plain text uses the terminal foreground. Padding, empty/loading/error/overflow rows fill the chosen background, and titles identify both the palette and background.
- Chrome follows the applied Claude theme. Display schema v5, configuration protocol v4, runtime protocol v2, navigation, revision-bound saves and separate Claude preference Apply remain compatible. Python and both Mod manifests are 1.7.8.

## Validation and publication

Local validation passed 659 Python tests (651 passes, eight expected platform skips), 65 native and ten runtime official Mod tests on Claude Code 2.1.295, both TypeScript projects with matching 2.1.295 declarations, generated contracts, Ruff and documentation checks.

Four independent terminal-default/Claude-theme combinations passed real Linux x86_64 / Python 3.14.4 / Claude Code 2.1.295 PTYs at 120×30 docked and 80×48 inline sizes. They select the background through the real UI, compare default/ANSI and Colors off, cover pages/forms, preserve configuration on cancel and keep background choices across reopening and separate theme Apply. Eight [preview comparison images](../development/native.md#terminal-background-previews) reconstruct the recorded cells with explicit xterm/default-color analysis fixtures; they are separate from physical-terminal screenshots and human acceptance.

Publication requires all 13 Python/build and ten fixed Mod jobs on PR, merge and tag; exact-commit distributions and independent rebuilding; isolated installed/upgrade checks and persistent editor PTYs; draft/public asset SHA256 verification; TestPyPI acceptance; formal PyPI index installations; and identical GitHub/Gitee assets. Ordinary checks use local commands and fixed samples without paid model calls. Existing platform support and the documented macOS Client focus limitation remain unchanged.

## v1.7.8 — 独立选择原生预览背景

会话内编辑器保留框内预览，在 Settings 新增 **Preview background (UI only)**。按终端背景深浅选择 `light` 或 `dark`，与 Claude 主题独立；保存显示配置前，可在该底色上比较 default 与 ANSI。

### 安装或升级

```text
pipx install --force fbincon-claude-code-statusline==1.7.8
claude-statusline install --dry-run
claude-statusline install
claude-statusline doctor
```

刷新接入后重新启动 Claude Code，保留显示配置和接入偏好。CLI 仍为 `claude-statusline`；旧分发名称安装使用[迁移指南](../USER_GUIDE.zh-CN.md#迁移旧分发名称)。

### 行为与兼容性

- 预览背景是立即记忆的编辑器偏好，丢弃未保存显示编辑后仍保留。默认沿用深色预览，缺失／无效存储值使用深色，写入失败恢复原选择；不进入配置草稿、预设、可移植导出或实际状态栏。
- 两种标准底色为 `#ffffff` 与 `#17191e`，由用户匹配终端深浅，不查询终端背景的精确 RGB。宿主会重绘停靠 Pane 中 Client 的默认背景，因此仅使用透明属性无法在该位置提供终端背景。
- RGB 保留原值；ANSI 直接使用终端 0–15 色槽，避免宿主把命名颜色映射为固定 RGB。无色文字使用终端前景；行尾、空行、加载、错误和溢出行完整填充所选背景，标题标明配色与底色。
- 主界面跟随 Claude 实际主题。显示 schema v5、配置协议 v4、运行协议 v2、导航、revision 保存及 Claude 偏好独立 Apply 保持兼容。Python 和两个 Mod manifest 为 1.7.8。

四种独立的终端默认色／Claude 主题组合已通过 Linux x86_64／Python 3.14.4／Claude Code 2.1.295 的 120×30 停靠及 80×48 内嵌 PTY。通过实际 UI 选择底色，比较 default／ANSI 与 Colors off，覆盖页面／表单、取消时配置不变、重开后保留背景及主题单独 Apply。八张[对比图片](../development/native.zh-CN.md#终端背景预览)使用明确的 xterm／默认色分析夹具重建捕获单元格，与物理终端截图及真人验收分别记录。
