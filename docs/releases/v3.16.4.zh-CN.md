# v3.16.4 — 修复 npm 首次设置与状态栏行为

[English](v3.16.4.md) | **简体中文**

已于 **2026-11-21** 发布。

全新安装时，默认 npm 入口可以进入 setup。本版还改进了渲染、来源选择和编辑器控件。

- 使 GitHub 来源可随工作树当前分支切换。
- 修复默认 `npx @fbincon/claude-code-statusline` 安装，用户确认后进入 setup。[#220](https://github.com/fbincon/claude-code-statusline/issues/220)
- 修复子代理显示、会话强度和任务计时状态转换。
- 修复权限模式快照、上下文百分比、语义分隔符和主栏样式。
- 改进组件选择与组移动，使 Native 编辑器控件避开宿主恢复按钮。
- 统一 CLI 和编辑器中的香港中文术语。

升级后运行 `claude-statusline install` 并重启 Claude Code，使内置编辑器匹配编辑器协议 32。显示 schema 17 保持可读。保存跟随分支的 GitHub 来源可能将来源登记表升级到版本 4。替换软件包前请检查降级兼容性。

支持 Linux／WSL、Windows 和 macOS，运行时为 Node 22/24。沿用现有 Claude Code 宿主要求。

已接受现有 [#96 缺口](https://github.com/fbincon/claude-code-statusline/issues/96) 的六项未验证事项。
