# v3.16.0 — Six additional languages

**English** | [简体中文](v3.16.0.zh-CN.md)

Release preparation is in progress. Publication and actual-machine evidence will be recorded in the [delivery record](../development/language-expansion.md).

Add Spanish, French, German, Brazilian Portuguese, Russian and Indonesian to both interface and statusline language selectors. All twelve languages are bundled for offline use and cover CLI help/errors, both editors, recovery, previews and main/subagent output. UI language saves immediately; output language follows display Save/Cancel.

Editor protocol 31 requires matching frontend/backend resources. Rerun `claude-statusline install` and restart Claude Code after upgrading. Display schema 17 and UI preferences 1 retain their formats and existing values. Before downgrading to a version without a selected language, reset both language choices to English using the current package.

The release requires complete accepted translations, 144 independent UI/output combinations, 313 actual-host capacity cases and the existing eight-target/32-Node/sixteen-host product matrix. Client props, Pane and Client drawing retain independent limits and whole-grapheme fitting. Node dictionary declaration types remain bounded as language coverage grows.

Only the six existing [issue #96 gaps](https://github.com/fbincon/claude-code-statusline/issues/96) are accepted and remain unverified. No paid model tests are planned. New post-publication machine findings receive issues without a patch release.
