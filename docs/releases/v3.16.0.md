# v3.16.0 — Six additional languages

**English** | [简体中文](v3.16.0.zh-CN.md)

Published on **2026-10-30**. Full gate, channel and machine evidence is in the [delivery record](../development/language-expansion.md#final-release).

This release adds six interface and statusline languages, bringing the public release to twelve.

- Add Spanish, French, German, Brazilian Portuguese, Russian and Indonesian to both interface and statusline language selectors.
- Bundle all twelve languages for offline use, covering CLI help/errors, both editors, recovery, previews and main/subagent output. UI language saves immediately; output language follows display Save/Cancel.
- Keep Client props, Pane and Client drawing within independent limits and whole-grapheme fitting as language coverage grows. Node dictionary declaration types remain bounded.

Editor protocol 31 requires matching frontend/backend resources. Rerun `claude-statusline install` and restart Claude Code after upgrading. Display schema 17 and UI preferences 1 retain their formats and existing values. Before downgrading to a version without a selected language, reset both language choices to English using the current package.

Supported platforms/runtimes: Node 22/24 on Linux/WSL, Windows and macOS; the existing eight-target/32-Node/sixteen-host matrix remains supported.

The release requires complete accepted translations, 144 independent UI/output combinations and 313 actual-host capacity cases. All of them passed, together with the final PR/main/tag gates.

Only the six existing [#96 gaps](https://github.com/fbincon/claude-code-statusline/issues/96) are accepted and remain unverified. No paid model tests were run. Post-publication findings receive issues without a patch release; private harness diagnostics and the actual outcomes are recorded in the delivery record.
