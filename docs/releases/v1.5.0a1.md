# v1.5.0a1: Formatting, layouts and host preferences

This preview delivers Phase 4 configuration. **v1.4.0 remains Latest; v1.5.0 stable waits for maintainer confirmation of the new Linux/Windows interactions and the usable macOS entries.** The existing macOS Client input limitation remains open.

- Add opt-in model abbreviations, compact/full/grouped numbers, labels, Unicode/ASCII icons, custom item text, risk thresholds, used/remaining allowances and reset time/time-zone formats. Existing default appearance is retained; missing and expired values remain unavailable and observed zero stays zero.
- Add explicit main rows, item priorities and terminal-column widths. Narrow explicit rows truncate and remove low-priority items without adding continuation rows; auto keeps wrapping. Subagent running/completed filters, row limits and task widths retain host order and emit empty content for hidden IDs.
- Add editable minimal, developer, monitoring and multi-agent presets and portable JSON import/export. Files contain only display and tool-managed padding/refresh/Vim settings. Imports replace editor drafts for review before Save; exports can contain unsaved edits and protect existing files/live configuration.
- Complete both editors with scoped Ctrl+E forms, Layout and Settings operations. Curses keeps legacy Enter saves and adds Ctrl+S from every page. Native Claude appearance, time/title and model/effort/thinking/fast behavior use actual host rows and a separate per-row Apply with locks, conflict checks and partial results.

## Install or upgrade the preview

Python 3.10–3.14 supports Linux/WSL, Windows and macOS. Fresh preview installations opt into editor entries explicitly; existing preferences are retained. External requires Claude Code 2.1.258+, Client 2.1.287+.

```text
pipx install --force "https://github.com/fbincon/claude-code-statusline/releases/download/v1.5.0a1/claude_code_statusline-1.5.0a1-py3-none-any.whl"
claude-statusline install --experimental-slash-tui --native-editor
claude-statusline doctor
```

Restart Claude Code. Click the Client region before keyboard input; use `s`/`f`/`q` for save/finish/discard, Ctrl+E for item formats, and page 4 for Layout. The standalone `claude-statusline configure` remains available on macOS when Client input does not work. See the [complete configuration guide](https://github.com/fbincon/claude-code-statusline/blob/v1.5.0a1/docs/USER_GUIDE.md#formatting-layout-presets).

Display schema v3 reads v1/v2 without rewriting them. The first actual save backs up original bytes and migrates to v3. Backend/Mod JSON protocol is v2; rerun install to synchronize matching resources. Before downgrading, close editors, remove native with the newer package, restore the pre-migration display backup using its metadata, install the older package and rerun install/doctor. Runtime/lifecycle/editor enablement formats are independent. [Recovery instructions](https://github.com/fbincon/claude-code-statusline/blob/v1.5.0a1/docs/USER_GUIDE.md#version-compatibility).

## Validation and acceptance

- Local suite: 507 Python tests, 499 passed and eight expected platform skips; 40 official Mod tests, strict plugin validation, TypeScript, shared contracts, Ruff, documentation and whitespace checks.
- CI retains the 13 Python/build jobs and adds a fifth fixed Mod job: Linux 2.1.287/2.1.288/2.1.289, Windows/macOS 2.1.288. PR, merge and tag checks are publication gates.
- Installed-wheel Linux x86_64 / Python 3.14.4 / Claude Code 2.1.289 PTYs cover 120×30 and 80×48, both persistent entries, CJK input and files, ANSI palette, formats/rows/priorities/widths, presets/import/export, cancel, shared saves and actual theme/turn-duration Apply/readback. Agent visual inspection and automated PTYs are separate from human acceptance.
- Same-harness, 50-sample Linux measurements compare v1.4.0 `6c7826e` with formatting code `a040243`: model-only render P50/P95 51.170/61.929 → 55.245/63.612 ms. Formatted and explicit five-item fixtures measure 52.690/60.660 and 53.498/62.186 ms. Small fixtures and scheduling noise limit the comparison; lazy Git/transcript collection remains covered by regressions.
- Release assets are built from the fixed verified merge commit and require inventory inspection, independent wheel/sdist rebuild/install, SHA256, draft-byte and public-download/installation checks. Raw evidence stays outside distributions.

Human Phase 4 acceptance remains pending. Confirm Linux/Windows new interactions and macOS standalone/CLI configuration, retaining the reported Client limitation, before stable promotion. This preview adds no Phase 5 runtime indicators and runs no paid model/timer suite.
