# v3.15.0 — Incremental multilingual development

**English** | [简体中文](v3.15.0.zh-CN.md)

Published on **2026-10-30**. Full gate, channel and machine evidence is in the [delivery record](../development/i18n-02-delivery.md#final-release).

This release adds an incremental translation workflow while preserving complete offline support for the six public-release languages.

- Add an incremental translation workflow for English, Simplified Chinese, Taiwan Traditional Chinese, Hong Kong Traditional Chinese, Japanese and Korean.
- Use the current English template during development when official translations are missing, stale or unvalidated; English and Simplified Chinese stay complete. Invalid submissions cannot hide behind fallback, and verified retired templates stay outside current resources.
- Let developers inspect truthful coverage, freeze an immutable task list, validate a batch and explicitly update matching acceptance records. Node, Native and packaged JSON consume the same effective resources; language history and review inputs stay out of the runtime package.
- Keep UI language saving immediately and output language following display Save/Cancel. Native props, Pane and Client drawing retain separate budgets; dictionaries and acceptance history are never sent to the Client.

Display schema 17, editor protocol 30, existing aliases, stored settings and Native recovery remain compatible. Rerun `claude-statusline install` and restart Claude Code after upgrading.

Supported platforms/runtimes: Node 22/24 on Linux/WSL, Windows and macOS; existing host minimums and the six interface/output languages remain supported.

Publication requires the final PR/main/tag gates, eight installation targets, 32 Node cases, sixteen fixed hosts, all 271 retained capacity cases plus twelve language cases, and installed 36-combination language checks.

Only the six existing [#96 gaps](https://github.com/fbincon/claude-code-statusline/issues/96) are accepted and remain unverified. No paid model calls are included. Post-publication findings receive issues without a patch release.
