# v3.15.0 — Incremental multilingual development

**English** | [简体中文](v3.15.0.zh-CN.md)

Published on 2026-10-30 to [GitHub](https://github.com/fbincon/claude-code-statusline/releases/tag/v3.15.0), [npm](https://www.npmjs.com/package/@fbincon/claude-code-statusline) and [Gitee](https://gitee.com/fbincon/claude-code-statusline/releases/tag/v3.15.0). All required gates and public/machine checks passed; [final evidence](../development/i18n-02-delivery.md#final-release) preserves source identities and the six unverified #96 gaps.

I18N-02 adds an incremental translation workflow while preserving complete offline support for English, Simplified Chinese, Taiwan Traditional Chinese, Hong Kong Traditional Chinese, Japanese and Korean in public releases.

During development, missing, stale or unvalidated official translations use the current English template. English and Simplified Chinese stay complete. Source meaning, named placeholders, contextual contracts, terminology and translation edits invalidate the applicable acceptance records. Invalid submissions cannot hide behind fallback; verified retired templates stay outside current resources.

Developers can inspect truthful coverage, freeze an immutable incremental task list, validate a batch and explicitly update matching acceptance records. Node, Native and packaged JSON consume the same effective resources. Multilingual search preserves the actual language of fallback evidence. Language history and review inputs stay out of the runtime package.

UI language still saves immediately; output language still follows display Save/Cancel. Display schema 17, editor protocol 30, existing aliases, stored settings and Native recovery remain compatible. Native props, Pane and Client drawing retain separate budgets; dictionaries and acceptance history are never sent to the Client.

Publication requires final PR/main/tag gates, eight installation targets, 32 Node cases, sixteen fixed hosts, all 271 retained capacity cases plus twelve language cases, and installed 36-combination language checks. Only the six existing [#96 gaps](https://github.com/fbincon/claude-code-statusline/issues/96) are accepted and remain unverified. No paid model calls are included. Post-publication machine findings receive issues without a patch release.
