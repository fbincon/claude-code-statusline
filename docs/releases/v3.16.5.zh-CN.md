# v3.16.5 — Claude Code 集成与 Native 控件修复

[English](v3.16.5.md) | **简体中文**

已于 **2026-11-21** 发布。

修复 Claude Code 2.1.330 上的内置插件安装，并为卡在 3.16.4 的升级提供恢复路径。

- 在 Claude Code 2.1.330 上安装、升级和恢复内置插件，并显示具体校验失败原因。 [#292](https://github.com/fbincon/claude-code-statusline/issues/292)
- 让 Native 编辑器在窄窗格中同时保留重试和关闭按钮。 [#287](https://github.com/fbincon/claude-code-statusline/issues/287)
- 先比较包内容，再检查维护路线的专项任务预算。 [#288](https://github.com/fbincon/claude-code-statusline/issues/288)

## 兼容性

有未完成的 3.16.4 事务时，先按[包管理指南](../PACKAGE_MANAGEMENT.zh-CN.md#包事务恢复)恢复原目标，再升级到 v3.16.5。运行 `claude-statusline install`，然后重启 Claude Code 以加载匹配的插件。

沿用显示 schema 17、编辑器协议 32 和现有存储格式。支持 Linux／WSL、Windows 和 macOS，运行时为 Node 22/24。

已接受现有 [#96 缺口](https://github.com/fbincon/claude-code-statusline/issues/96) 的六项未验证事项。
