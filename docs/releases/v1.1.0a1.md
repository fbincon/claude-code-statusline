# v1.1.0a1 · macOS Preview

[English](#english) | [简体中文](#简体中文)

<a id="english"></a>

v1.1.0a1 is the first prerelease package with macOS support. At the time of this prerelease, the latest stable version for Linux/WSL and Windows remained [v1.0.0](https://github.com/fbincon/claude-code-statusline/releases/tag/v1.0.0).

## Changes

- The macOS preview covers the main status line, subagent rows, installation/configuration/diagnostic commands, and standalone curses TUI. Optional experimental `/statusline-configure` uses tmux popup.
- Adapt POSIX file locks, private permissions, atomic writes, session process start identity, sleep-inclusive native timing, and cross-process reboot detection, with diagnostics and fallback when interfaces are unavailable.
- Poll macOS TUI input to handle SIGINT and similar signals promptly without additional keystrokes.
- Package and CLI both report `1.1.0a1`; display schema v2, feature schema v1, old configuration, and runtime state remain compatible without migration.

## Installation and upgrading

Requires Python 3.10+, Claude Code CLI, and pipx. The macOS preview validation covers Intel / Apple Silicon, macOS 15/26, and Python 3.10/3.14; the Apple Silicon Python 3.10 lower bound tested is 3.10.11. Windows 10/11 supports CPython 3.10–3.14 x86/x64 and installs windows-curses automatically.

```text
pipx install "https://github.com/fbincon/claude-code-statusline/releases/download/v1.1.0a1/claude_code_statusline-1.1.0a1-py3-none-any.whl"
pipx ensurepath
```

For an existing installation, add `--force`. Reopen the terminal, then run:

```bash
claude-statusline --version
claude-statusline install --dry-run
claude-statusline install
claude-statusline doctor
```

On Windows, use `claude-statusline.exe`. Install fixed-tag source with `pipx install "git+https://github.com/fbincon/claude-code-statusline.git@v1.1.0a1"`. The v1.0.0 packages and tag do not include macOS support.

Assets include the universal wheel, source distribution, and `SHA256SUMS`. Verify with `sha256sum -c SHA256SUMS` on Linux/WSL or `shasum -a 256 -c SHA256SUMS` on macOS; on Windows, compare `Get-FileHash -Algorithm SHA256` results with the checksum file.

## Validation and boundaries

Local validation completed 332 tests, with 4 platform-specific skips and all remaining tests passing. Ruff F/E9 and whitespace checks passed. Clean-commit distributions were checked for version, conditional dependencies, modules, skills, documentation, and screenshots. The isolated wheel installation passed six CLI smoke scenarios; the wheel rebuilt from the source distribution matched all package files, metadata, and entry points.

All three assets downloaded after publication matched local artifacts byte for byte and passed SHA256SUMS verification. Installing the README's public wheel URL in isolated pipx directories printed 1.1.0a1 and passed all six CLI smoke scenarios.

Release commit `87281af0be0a71a2b67144f1d6b90f62b7a8eaf2` passed all 13 [main CI](https://github.com/fbincon/claude-code-statusline/actions/runs/36910775725) jobs, covering Linux/Windows regressions, eight macOS combinations, and distribution checks, with actual POSIX PTY and tmux popup tests. The automatically triggered [tag CI](https://github.com/fbincon/claude-code-statusline/actions/runs/36911291954) also passed 13/13 jobs.

[Release branch CI](https://github.com/fbincon/claude-code-statusline/actions/runs/36910126187) and [PR CI](https://github.com/fbincon/claude-code-statusline/actions/runs/36910180221) also passed fully. The release-branch source tree matched the main release commit; all eight downloaded branch macOS reports passed native clock, parent-directory sync, and six CLI smoke scenarios. Their actual versions were:

| macOS | Architecture | Python |
| --- | --- | --- |
| 15.7.9 | Apple Silicon arm64 | 3.10.11, 3.14.7 |
| 15.7.9 | Intel x64 | 3.10.21, 3.14.7 |
| 26.6.1 | Intel x64 | 3.10.22, 3.14.7 |
| 26.6.2 | Apple Silicon arm64 | 3.10.11, 3.14.7 |

Automated tests use temporary configuration and synthetic sessions. Actual Claude session appearance, fonts/character widths, real sleep/resume, and desktop-terminal experience had not been manually accepted for this release, so macOS remained a preview. The experimental entry point requires Claude to be started in a valid tmux session; Terminal.app / iTerm2 automatic launching is not provided in this version.
