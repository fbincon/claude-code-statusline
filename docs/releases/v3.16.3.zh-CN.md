# v3.16.3 — 配置技能工作流修复

[English](v3.16.3.md) | **简体中文**

已于 **2026-11-05** 发布：[npm](https://www.npmjs.com/package/@fbincon/claude-code-statusline/v/3.16.3)、[GitHub 正式版／Latest](https://github.com/fbincon/claude-code-statusline/releases/tag/v3.16.3) 和 [Gitee 正式版](https://gitee.com/fbincon/claude-code-statusline/releases/tag/v3.16.3)。[交付记录](../development/skill-workflows.zh-CN.md#final-release)列明验收通过的源码、原始文件、六项实际技能调用及发布／本机核验结果。

- `/statusline-config` 向导按宿主问答工具的限制分页提供条目和语言选项，以已保存值为起点，跨页保留答案，全部答案解决后一次保存。某页的“本页全不选”只影响该页，取消不保存配置。[问答向导](../USER_GUIDE.zh-CN.md#statusline-config-问答向导)
- 遇到重复实例、text／spacer、分组或主行对齐，基于类型的向导在编辑前停止。说明用户默认配置范围，将命名方案／项目管理引导到对应编辑器或终端命令。[方案与项目](../PROFILES.zh-CN.md)
- 参数回退按字面参数处理引号内的值。向导在提问前检查安装／归属，应用答案前重新读取已保存状态；快照变化时需要重新开始。这是尽力而为的复核，保存操作未绑定修订号。[工作流与限制](../development/skill-workflows.zh-CN.md)
- 主题选项来自当前注册表。CLI 参考覆盖共享 slash 解析器的十九项动作，包括实例、分组、对齐、布局和传输；方案／项目管理仍使用终端命令或编辑器。[slash 支持](../reference/cli.zh-CN.md#slash-命令支持范围)
- 外部启动器的回退说明采用稳定 Node TUI 定位，在适用时提示 Windows `.cmd` 入口，继续禁止通过模型工具启动终端界面。[外部编辑器](../USER_GUIDE.zh-CN.md#外部终端入口-statusline-configure)

升级后运行 `claude-statusline install`，重启 Claude Code 以刷新已安装技能。显示 schema 17、编辑器协议 31 及既有存储格式保持兼容。
