# v3.12.0 — 来源操作、命令调度与包执行

[English](v3.12.0.md) | **简体中文**

来源管理提供共享可读状态、有界执行摘要、已保存 GitHub 检查分页及审核后绑定维护。命令自动执行单独审核，默认 300 秒，仅适用且已确认的上下文持有有效租约时调度；相同输入共享，不同上下文公平轮转，同源命令串行。

双编辑器支持已验证升级、回退、未完成包事务恢复及独立配置还原。草稿须明确处理；持久控制入口贯穿包替换，旧编辑器只读，关闭仅脱离。历史清理显式审核，保护活跃工作、回退材料及引用快照。

无法核验的执行器身份保持未知并保留保护，确认退出或身份不同后才能恢复包事务。

修复 [#173](https://github.com/fbincon/claude-code-statusline/issues/173)：普通 npm 清单权限不再造成版本页兼容误报，恢复材料仍要求私有权限。[#157](https://github.com/fbincon/claude-code-statusline/issues/157) 已凭真实 v3.11.0 tag／OIDC／provenance 证据关闭，账户容量限制保留未验证状态。

编辑器协议升至 28，命令自动许可使用来源注册表 3，执行摘要使用任务 4。显示 schema 仍为 16，外部命令观测仍为 v1。安装匹配 Mod，集成完成后重新打开外部编辑器或重启 Claude。无法读取当前配置的旧包会在回退审核中被拒绝。
