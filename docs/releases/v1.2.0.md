# v1.2.0 — Native configuration editor

The native Main/Subagents/Settings editor is now the preferred configuration entry on compatible Claude Code 2.1.287+ hosts. Stable installation preserves explicit native disablement and externally disabled plugins. This release promotes the accepted v1.2.0a1 UI, synchronizes Mod/backend versions, and preserves display schema v2 and protocol v1.

Install or upgrade the stable wheel:

```bash
pipx install --force "https://github.com/fbincon/claude-code-statusline/releases/download/v1.2.0/claude_code_statusline-1.2.0-py3-none-any.whl"
claude-statusline install
claude-statusline doctor
```

Restart Claude Code, then run `/statusline-configure` or `/statusline-configure-native`. The editor supports all existing selections, ordering, sample preview and nine tool settings. Full saves use revision protection and keep the pane open. Actual theme/verbose host preferences apply separately. The wizard and standalone TUI remain available; `install --no-native-editor` persists disablement and removes owned native integration.

The maintainer explicitly confirmed the complete human checklist on Linux, Windows 11 and macOS 14.5 against fixed preview v1.2.0a1 (`d161e55`). Windows/macOS architecture, terminal product/version and separate host-version outputs were not supplied; those fields remain unknown. Automated CI independently checks the Python platform matrix and native Linux 2.1.287/2.1.288 plus Windows/macOS 2.1.288 installation, official Mod tests, strict validation, TypeScript and complete JSON saves. Release gates also include wheel/sdist/rebuild, draft/public SHA256 and isolated public/fixed-tag installation.

See the [user guide](https://github.com/fbincon/claude-code-statusline/blob/v1.2.0/docs/USER_GUIDE.md#native-configuration-editor), [native acceptance](https://github.com/fbincon/claude-code-statusline/blob/v1.2.0/docs/development/native.md#stable-acceptance-record), and [changelog](https://github.com/fbincon/claude-code-statusline/blob/v1.2.0/CHANGELOG.md). v1.2.0 is the Latest stable release; v1.2.0a1 remains a prerelease.
