# v1.7.5 — Portable repository links and Gitee Release notes

Repository documentation now follows the host and selected branch/tag through relative links. GitHub remains the primary development and publishing repository; Gitee synchronizes the same main commit, tag objects and package assets. The repository layout and application behavior retain their existing contracts.

## Install or upgrade

```text
pipx install --force "https://github.com/fbincon/claude-code-statusline/releases/download/v1.7.5/fbincon_claude_code_statusline-1.7.5-py3-none-any.whl"
pipx ensurepath
claude-statusline install --dry-run
claude-statusline install
claude-statusline doctor
```

Verify SHA256SUMS before installation and restart Claude Code after integration. Windows uses `claude-statusline.exe`. Users of this repository's previous distribution name must follow the [package-name migration](https://github.com/fbincon/claude-code-statusline/blob/v1.7.5/docs/USER_GUIDE.md#migrate-the-previous-distribution-name) first. The default README commands continue to install or upgrade `fbincon-claude-code-statusline` from PyPI.

## Documentation and publication

- Both READMEs use relative language, document, license, screenshot and section links. GitHub CI/Issues and GitHub source installation retain their primary identity. README remains a project introduction with generic package commands; version history belongs in the changelog and Release notes.
- A setuptools metadata hook resolves the English README links to this fixed GitHub tag for PyPI, including image and section targets. Source README bytes remain intact in the source distribution; direct and independently rebuilt wheel descriptions are checked against the same conversion.
- A local Gitee note renderer reads the original public GitHub Release and actual Gitee attachment URLs. It resolves document refs, retains historical distribution names and prerelease/support claims, adapts fixed-version installation/update commands, and records original GitHub publication provenance. Missing/mismatched attachments or metadata stop rendering before output.
- Maintainer instructions cover snapshots, local review, API update/readback and repeatable task-driven synchronization. Historical tags and assets retain their original objects and bytes; current and historical notes are adapted on Gitee.
- Include the package-index visibility fix after v1.7.4: retry incomplete/404 index reads for up to three minutes without repeating publication; reject permission, identity and checksum failures immediately.

Python and both Mod release manifests are 1.7.5. Display schema v5, configuration protocol v4 and runtime protocol v2, saved preferences, installed integration and timing behavior remain compatible. Existing platform/terminal limitations and historical human acceptance keep their original scope. This documentation/build patch makes no paid model calls.

## Validation

Local checks passed 638 Python tests (630 passes, eight expected platform skips), 55 native and 10 runtime official Mod tests, both strict validators and TypeScript projects, generated contracts, Ruff and 805 documentation links/bilingual pairs. Fifteen documentation/publication regressions cover Markdown destinations, historical notes, metadata mismatches and output preservation on failure. A PTY signal-exit timeout during a concurrent run passed isolated reproduction and the complete sequential rerun.

The wheel/sdist metadata and rendered PyPI links passed strict inspection; the sdist retained the source README bytes. All 20 existing Gitee notes rendered from actual public GitHub metadata and real Gitee URLs. Installed-wheel core/native/runtime smoke and an isolated 1.7.4-to-1.7.5 upgrade passed, preserving display and all saved integration-preference bytes and repeat-install behavior.

Release acceptance requires the complete Python and Mod checks, all 20 PR/merge/tag CI jobs, fixed-commit wheel/sdist inspection, independent rebuilding, isolated installed-package/upgrade smoke, verified draft/public attachments, TestPyPI acceptance and formal PyPI index installation checks. Gitee synchronization uses these same artifacts and checks download bytes separately from browser navigation.
