# v1.3.0a1 — Native editor usability preview

This preview makes statusline configuration easier to operate inside Claude Code. **Latest stable remains v1.2.0.**

- Direct checked item rows replace the dropdown; Enter toggles the focused item.
- Horizontal tabs, p/n pagination, compact settings and a bounded bottom sample preview reduce scrolling. Enabled and disabled rows share the standalone TUI ordering rules.
- s saves and continues; f saves and closes after confirmed success. Pending theme/verbose preferences remain visible until separately applied or explicitly discarded.
- Host preferences are folded behind h. Numeric acceptance is per field; conflict, ownership, revision and unknown-save protections remain.
- The source separates editor logic, page composition and reusable controls; runtime packaging includes the nested TypeScript tree.

The body requires at least 32 columns × 12 rows. Placement, Tab/arrows and keyboard grants remain host-owned. An isolated Client probe confirmed key delivery after a click and no Escape delivery; no Client mode is shipped. Configuration schema v2 and JSON protocol v1 remain compatible.

```bash
pipx install --force "https://github.com/fbincon/claude-code-statusline/releases/download/v1.3.0a1/claude_code_statusline-1.3.0a1-py3-none-any.whl"
claude-statusline install --native-editor
claude-statusline doctor
```

Restart Claude Code 2.1.287+ in a trusted terminal and run `/statusline-configure` or `/statusline-configure-native`. The preview requires explicit native enablement. The standalone TUI and wizard remain available.

Validation includes Python regression tests, official Mod tests, TypeScript, fixed-host native CI, Linux persistent-plugin PTY checks at 120×30/80×48, nested resource checks and distribution/rebuild verification. New Linux, Windows and macOS human acceptance is pending; previous v1.2.0 acceptance applies to its original UI only. Stable v1.3.0 requires all three new results.

See the [English controls and acceptance guide](https://github.com/fbincon/claude-code-statusline/blob/v1.3.0a1/docs/development/native.md).

## v1.3.0a1 — 原生编辑器操作体验预览

本预览改善 Claude Code 内的状态栏配置操作。**Latest 稳定版仍为 v1.2.0。**

- 直接勾选行替代下拉框，Enter 切换当前项目。
- 横向页签、p/n 翻页、紧凑设置和限高底部样例预览减少滚动；启用及未启用行采用与独立 TUI 一致的排序规则。
- s 保存继续，f 在确认保存后关闭；待应用的 theme/verbose 保留，需单独应用或明确丢弃。
- h 展开宿主偏好；数值按字段接受，保留冲突、归属、revision 和未知保存结果保护。
- 按编辑逻辑、页面组合、公共控件展开源码结构，运行包包含嵌套 TypeScript 子目录。

最小要求为正文 32 列 × 12 行；位置、Tab/方向键及键盘授予仍由宿主决定。隔离 Client 探针确认点击后可收到按键、Esc 不传入，本轮不发布 Client 模式。配置 schema v2、JSON 协议 v1 保持兼容。

按上方命令安装并明确启用原生，在受信任终端重启 Claude Code 2.1.287+，运行 `/statusline-configure` 或 `/statusline-configure-native`。独立 TUI 与向导继续可用。

验证包含 Python 回归、官方 Mod 测试、TypeScript、固定宿主原生 CI、Linux 120×30/80×48 持久插件 PTY、嵌套资源检查及分发包/重建核验。新界面的 Linux、Windows、macOS 真人验收均待完成；v1.2.0 的历史验收仅适用于旧界面。稳定 v1.3.0 要求三平台的新结果。

参见[中文操作和验收说明](https://github.com/fbincon/claude-code-statusline/blob/v1.3.0a1/docs/development/native.zh-CN.md)。
