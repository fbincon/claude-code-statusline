# v1.10.0 — Find items and review configuration imports

Both configuration editors now offer ranked English/Chinese search, category filters, source/requirement guidance and import differences before accepting a draft.

## Install or upgrade

```text
pipx install --force fbincon-claude-code-statusline==1.10.0
claude-statusline install
claude-statusline doctor
```

Restart Claude Code after refreshing the bundled integration. Backend and native editor resources must match: configuration protocol is v7, while display schema v6, portable format v1, interface preferences v1 and runtime protocol v2 stay unchanged. Existing display settings and default item selections are preserved.

## Configuration workflow

- Search IDs, English/Chinese names and descriptions, custom labels and categories. Exact matches, prefixes, English initials, substrings and ordered subsequences form stable ranking tiers. Highlighting uses the original matching characters and an alternate-field snippet when needed.
- Ctrl+F selects a category. Filters stay in the current editor session; filtered reordering is blocked while toggling and formatting remain available. Clear the query and choose All categories to restore the full order.
- Ctrl+E opens item details. Sources and requirements explains the scope, source fields, verified host versions, collector prerequisites, possible unavailable reasons and setup entries for all 74 items. It does not probe live data or enable collectors.
- Import opens expandable differences against the current unsaved draft, with candidate Main/Subagents sample previews. A accepts the already-read candidate into the draft; saving is separate and retains the original revision and transactional backup rules. Cancellation, invalid files and save conflicts preserve the appropriate draft. Interface language and independent host/collector preferences are outside portable files.
- The four existing presets remain editable and their purposes are documented. Existing IDs, metric semantics, defaults and production rendering are retained.

See [discovery and import review](../USER_GUIDE.md#item-discovery-import-review), [shared contracts](../development/contracts.md) and the [changelog](../../CHANGELOG.md).

## Validation and publication

Publication requires cross-platform PR/merge/tag CI, a fixed-merge wheel/source distribution/checksum set, independent rebuilding and isolated installation/upgrade checks, installed editor PTYs, verified draft/public bytes, TestPyPI acceptance and formal PyPI index installations. GitHub and Gitee use the same original package files.

Terminal captures contain fixed samples from actual editor output. Automated PTYs and agent image inspection are distinct from human acceptance; the existing macOS Client focus limitation remains documented. No paid model calls are needed for this release.

## v1.10.0 — 查找项目与审阅配置导入

两个配置编辑器增加中英文分级搜索、分类筛选、来源／条件说明，以及接受草稿前的导入差异审阅。

### 安装或升级

```text
pipx install --force fbincon-claude-code-statusline==1.10.0
claude-statusline install
claude-statusline doctor
```

刷新包内接入后重启 Claude Code。后端与原生编辑器资源须匹配：配置协议升级至 v7；显示 schema v6、便携格式 v1、界面偏好 v1、运行协议 v2 不变。保留现有显示设置和默认项目选择。

### 配置流程

- 检索 ID、中英文名称／说明、自定义标签和分类，按精确、前缀、英文首字母缩写、子串、有序子序列分级，同等级保持现序；高亮原始匹配字符，必要时显示其他字段片段。
- Ctrl+F 选择分类。筛选仅保留在当前编辑会话；筛选时禁止排序，仍可勾选和修改格式。清空查询并选择全部分类后恢复完整顺序。
- Ctrl+E 打开项目详情。“来源与启用条件”解释全部 74 项的范围、来源、已核实版本、采集要求、可能不可用原因和设置入口，不探测实时数据，也不开启采集。
- 导入与当前未保存草稿比较，按分区展开差异，并提供主栏／子代理候选样例预览。A 接受已读取候选到草稿，保存仍是独立操作，沿用原 revision 和备份事务。取消、无效文件和保存冲突保留相应草稿；界面语言及独立宿主／采集偏好不在便携文件内。
- 四种既有预设继续可编辑，并补充适用场景。项目 ID、指标语义、默认选择及生产渲染保持兼容。

见[查找与导入审阅](../USER_GUIDE.zh-CN.md#item-discovery-import-review)、[共享契约](../development/contracts.zh-CN.md)和[变更日志](../../CHANGELOG.zh-CN.md)。

### 验证与发布

发布要求跨平台 PR／合并／标签 CI、固定合并提交的 wheel／源码包／校验文件、独立重建和隔离安装／升级检查、安装后双端 PTY、草稿／公开字节核验、TestPyPI 验收及正式 PyPI 索引安装。GitHub 与 Gitee 使用相同原始包文件。

终端捕获来自真实编辑器输出，内容为固定样例。自动 PTY、代理画面检查与人工验收分别记录；既有 macOS Client 焦点限制继续保留。本版本验证不需要付费模型调用。
