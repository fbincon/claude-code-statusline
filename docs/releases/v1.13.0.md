# Five interface and statusline languages

Traditional Chinese (`zh-Hant`), Japanese (`ja`) and Korean (`ko`) join English and Simplified Chinese across CLI help/errors, both editors, previews and main/subagent statuslines. General Traditional Chinese is a single shared variant. English remains the default, existing choices are preserved, and language selection is explicit.

```text
pipx install --force fbincon-claude-code-statusline==1.13.0
claude-statusline install
claude-statusline config language set ja
claude-statusline config set statusline-language ja
claude-statusline doctor
```

Replace `ja` with `en`, `zh-CN`, `zh-Hant` or `ko`. Interface language saves immediately; output language belongs to the display draft and follows Save/Cancel. Use `--language en` for a single CLI invocation without changing the saved interface preference.

## Changes

- All five packs contain 1,304 messages, including 220 statusline messages. A single ordered registry generates Python metadata, TypeScript language types, static native resources and individual statusline modules. Coverage, keys, placeholders, duplicates and terminal-safe text are release checks; runtime English fallback remains available.
- Both editors cycle in either direction and retain selection, search and unsaved changes. Failed preference writes retain the previous language. Search includes all five languages' names, descriptions and categories, stable IDs and custom labels, preserving ranking and original-text highlights.
- Python statusline refreshes import only the selected language module, plus English if fallback is needed. They do not scan locale directories or parse interface JSON. Both editors prepare multilingual search fields once and update changed custom labels independently. No new runtime dependency is introduced.
- Commands, configuration keys, paths, model names, units and user text remain unchanged. Complete documentation continues in English and Simplified Chinese; the [translation contribution guide](../development/i18n.md) documents the source/generated layout and adding another language.

## Compatibility

Display schema 7, interface preferences v1, portable v1 and runtime v2 remain unchanged. Editor protocol **10** requires the matching Python package and bundled native resources; old/new editor backends are rejected explicitly. Run `claude-statusline install` after upgrading to update installed resources. Existing backup and atomic-write behavior is retained.

Before downgrading to an older package, use the current version to run `claude-statusline config language set en` and `claude-statusline config set statusline-language en`, then follow the [downgrade instructions](../USER_GUIDE.md#upgrading) and install matching native resources. Do not change schema numbers by hand.

Linux/WSL, Windows 10/11, macOS 14+ and Python 3.10–3.14 remain supported. Existing [macOS Client focus/input limitations](../USER_GUIDE.md#macos-mouse-reporting-and-client-focus) remain documented. Font and terminal-palette differences can affect appearance.

## Validation

- 792 local Python tests completed: 784 passed and eight platform skips. The native Mod passed 102 tests and the runtime Mod passed ten; both TypeScript checks, Ruff, generated-resource and bilingual-document checks passed. CLI and both editors cover all 25 interface/output combinations, including editor save/cancel/reopen behavior. A temporary additional language verifies resource-only expansion.
- The installed candidate at `1134aee5425ed50fa0ca936321abb246e011b6b0` passed wheel inventory checks, an independent wheel rebuild with identical internal bytes, native/runtime install smoke and a real v1.12.0 wheel upgrade. Upgrade checks retained display/UI language, custom labels and explicit editor/collector opt-outs, and replaced protocol 9 resources with protocol 10.
- The three new languages passed 30 external Linux PTY cases (five sizes × two backgrounds × three languages) and 12 native cases (two sizes × two backgrounds × three languages). Common/minimum viewport images were inspected; official Client tests additionally cover the 32×12 native pane. [Capture provenance](../images/languages/README.md) distinguishes direct output, tmux color conversion, fixed sample data and image reconstruction. These are automated checks and agent inspection, with no new human Windows/macOS terminal acceptance, native-speaker review or paid model calls claimed.
- [Fixed-source performance measurements](../development/performance-v1.13.0.md) compare v1.12.0 with the implementation and 2/5/10-language resource variants, recording P50/P95, memory, resource size and noise screening. Synthetic extra languages are test fixtures and are not shipped.
- Publication requires all 13 Python/build and ten Mod jobs on the final PR, merged commit and tag, followed by nine TestPyPI and nine formal PyPI jobs. Published packages and both mirrors use the same verified artifacts and SHA256 manifest.

## 五种界面与状态栏语言

在英文、简体中文基础上，新增通用繁体中文（`zh-Hant`）、日语（`ja`）和韩语（`ko`），覆盖 CLI 帮助与错误、两个编辑器、预览以及主／子代理状态栏。默认仍为英文，保留已有选择，不自动识别系统语言。

```text
pipx install --force fbincon-claude-code-statusline==1.13.0
claude-statusline install
claude-statusline config language set zh-Hant
claude-statusline config set statusline-language zh-Hant
claude-statusline doctor
```

可将 `zh-Hant` 替换为 `en`、`zh-CN`、`ja` 或 `ko`。界面语言立即保存；输出语言属于显示草稿，随保存／取消处理。`--language en` 仅覆盖本次 CLI 调用。

- 五套资源各包含 1,304 条消息，其中 220 条用于状态栏。统一有序注册表生成 Python 注册信息、TypeScript 类型、原生静态资源与独立状态栏模块；发布严格检查键、覆盖率、占位符、重复键和终端安全性，并保留运行时英文回退。
- 两端支持双向切换，保留选中项、搜索和草稿；写入失败保留原语言。搜索覆盖五语言名称、说明、分类、稳定 ID 与自定义标签，沿用排序与原文高亮规则。
- Python 状态栏仅按需导入当前语言及必要的英文回退模块，不扫描目录或解析界面 JSON。两端预建搜索字段，自定义标签只更新自身缓存；没有新增运行时依赖。
- 命令、配置键、路径、模型名、单位和用户文本保持原样。完整文档继续维护英／简中两套，扩展方法见[翻译贡献指南](../development/i18n.zh-CN.md)。

显示 schema 7、界面偏好 v1、portable v1 和 runtime v2 不变；编辑器协议升为 **10**，要求软件包与原生资源匹配，明确拒绝新旧混用。升级后运行 `claude-statusline install` 更新资源，保留备份与原子写入行为。降级前先使用新版执行 `claude-statusline config language set en` 和 `claude-statusline config set statusline-language en`，再按[降级说明](../USER_GUIDE.zh-CN.md#升级)安装旧软件及匹配资源，不要手改 schema 数字。

- 本地 792 项 Python 测试中 784 项通过、8 项平台跳过；原生 Mod 102 项、runtime Mod 10 项、两端 TypeScript、Ruff、生成资源和双语文档检查通过。CLI 与两个编辑器覆盖全部 25 种界面／输出语言组合，编辑器还覆盖保存、取消和重新打开；临时语言验证无需修改业务代码即可扩展。
