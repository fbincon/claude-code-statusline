# v3.13.0 — 草稿历史与配置复用

[English](v3.13.0.md) | **简体中文**

已于 **2026-10-29** 发布。完整门禁、渠道及本机证据见[交付记录](../development/draft-history-and-reuse.zh-CN.md)。

本版本为双编辑器新增共享草稿历史、结构修复和配置复用。

- 两个编辑器共享有界撤销／重做和未保存变更审阅。可比较并发配置变化、导出保留的草稿、明确丢弃重载，或采用审阅过的修订后重试保存。未知保存继续冻结历史，直到核对完成。
- 外部撤销／重做使用 Ctrl+Z / Ctrl+R，Native 使用 Ctrl+_ / Ctrl+R，“变更与历史”也提供 U/R。Unix 宿主会在 Client 收到前拦截 Ctrl+Z，维护者已接受这一兼容调整。
- 结构编辑提供原子的对齐修复。可在组件间复制所选视觉字段，并通过依赖审阅、ID 映射及可选显式布局转换复用完整分组。导入来源保持未绑定，必须明确选择本机来源；导入不授予授权。

编辑器协议为 29；显示 schema 16、portable／方案格式 1 及现有运行时／来源格式兼容。升级后运行 `claude-statusline install` 并重启 Claude Code 加载匹配资源。

支持平台／运行时：Node 22／24，Linux／WSL、Windows 和 macOS；既有宿主最低版本及语言选择保持可用。

本版本已知问题：[#178](https://github.com/fbincon/claude-code-statusline/issues/178) 全树签名审计、[#179](https://github.com/fbincon/claude-code-statusline/issues/179) 实际配置验证隔离及 [#180](https://github.com/fbincon/claude-code-statusline/issues/180) Native 样式入口未翻译在 v3.13.0 时保持开放；详情见交付记录。v3.13.0 保留，不补发修补版。

仅接受 [issue #96 六项既有缺口](https://github.com/fbincon/claude-code-statusline/issues/96)，它们仍未验证。付费模型及请求详情见交付记录；发布后新发现只提 issue，不补发修补版。
