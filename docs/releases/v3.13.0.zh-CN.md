# v3.13.0 — 草稿历史与配置复用

[English](v3.13.0.md) | **简体中文**

两个编辑器共享有界撤销／重做和未保存变更审阅。可比较并发配置变化、导出保留的草稿、明确丢弃重载，或采用审阅过的修订后重试保存。未知保存继续冻结历史，直到核对完成。

外部撤销／重做使用 Ctrl+Z / Ctrl+R，Native 使用 Ctrl+_ / Ctrl+R，“变更与历史”也提供 U/R。Unix 宿主会在 Client 收到前拦截 Ctrl+Z，维护者已接受这一兼容调整。

结构编辑现在提供原子的对齐修复。可在组件间复制所选视觉字段，并通过依赖审阅、ID 映射及可选显式布局转换复用完整分组。导入来源保持未绑定，必须明确选择本机来源；导入不授予授权。

编辑器协议为 29；显示 schema 16、portable／方案格式 1 及现有运行时／来源格式兼容。升级后安装匹配的前后端资源并重新打开编辑器。

[使用说明](../DRAFT_HISTORY.zh-CN.md) · [实现与验收](../development/draft-history-and-reuse.zh-CN.md)。

最终 PR／main／tag 门禁及 npm OIDC 发布完成，GitHub／npm／Gitee 字节和六项公开下载检查通过。仅接受并保留 issue #96 原有六项未验证缺口。
