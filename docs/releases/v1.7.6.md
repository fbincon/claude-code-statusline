# v1.7.6 — Theme-aware in-session configuration

The in-session configuration editor follows Claude Code’s applied theme. Item text, bold shortcut keys, selected rows, headings, descriptions and recovery controls remain readable with light and dark themes. Shortcut keys use the theme’s primary text color; their emphasis does not depend on a fixed white foreground.

## Install or upgrade

```text
pipx install --force fbincon-claude-code-statusline==1.7.6
claude-statusline install --dry-run
claude-statusline install
claude-statusline doctor
```

Close Claude Code before migrating an older installation and restart it after refreshing integration. Existing installations under the previous distribution name follow the [migration guide](../USER_GUIDE.md#migrate-the-previous-distribution-name). The command stays `claude-statusline`; configuration and recorded integration preferences are retained.

## Behavior and compatibility

- Host semantic colors handle standard, daltonized, ANSI and host-supported auto/custom themes. Theme drafts still require separate Apply; a refusal preserves the applied theme and tool draft.
- Sample preview content fills every row with a dedicated dark background and retains production RGB/ANSI spans. Uncolored samples have an explicit neutral foreground; frame titles follow the host theme.
- Main, Subagents, Settings, Layout, item forms, compact layouts, loading and recovery use consistent color roles. Retry/Close remain outside Client. Input, navigation and saving retain their existing contracts.
- Fix capture foreground/background defaults and reverse-video handling; validate terminal readability instead of requiring white keys. Extend fixed-host CI to Claude Code 2.1.294 on Linux, Windows and macOS; publishing requires 13 Python/build and ten Mod jobs.
- Include the existing Gitee local-wheel instructions and expanded bilingual project structure. README remains a project introduction; history stays in changelogs and Release notes.

Python and both Mod release manifests are 1.7.6. Display schema v5, configuration protocol v4 and runtime protocol v2 remain compatible. This UI patch makes no paid model calls. Existing macOS Client interaction limitations and historical human acceptance retain their original scope.

## Validation

Local checks passed 643 Python tests (635 passes and eight expected platform skips), 59 native and ten runtime official Mod tests, strict validators, both TypeScript projects, generated contracts, Ruff and 823 documentation links. Real Linux PTYs exercised eight themes at two viewport sizes, plus persistent installed-wheel advanced editing and cross-editor readback. Isolated migration from the verified original 1.7.2 wheel preserved display configuration and recorded editor disablement; repeat installation remained idempotent.

Release acceptance requires the complete Python and official Mod tests, strict validation and TypeScript, generated contracts, documentation checks, all 23 PR/merge/tag CI jobs, exact-commit distributions, independent wheel rebuilding, installed-package/upgrade smoke, real Linux terminal theme captures, draft/public checksums, TestPyPI acceptance and formal PyPI index installations. Terminal reconstructions and automated checks are recorded separately from OS screenshots and human acceptance.

```text
pipx install --force fbincon-claude-code-statusline==1.7.6
```
