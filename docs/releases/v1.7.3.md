# v1.7.3 — Accurate schema diagnostics and refreshed TUI documentation

Doctor now reports the supported display schema in both success and migration messages. A valid v5 file reports `[OK] display config schema: v5`; supported older files name v5 as their next-save migration target. The apply-draft requirement also follows the supported version constant.

## Documentation and screenshots

- Both README galleries use 21 original screenshots grouped by configuration entry, platform and page. Linux and Windows in-session galleries have all four pages; macOS has the supplied Main page. External galleries have four pages on each platform. The previous 18-image gallery retains its original bytes, source records and hashes in the archive.
- The bilingual README, user/CLI guides, display definitions and development documentation were checked against source. The catalog has 60 main and 14 subagent items, with 10/five enabled by default; `prompt-timer` is an alias, not another item. Protocol examples, collector defaults and the seven-job Mod matrix are corrected.
- Guides explain optional execution time, incomplete wait coverage, Stop candidates, confirmed completion and frozen clocks. Native turn duration, task clocks, session runtime and API duration remain separate measurements.

## Install or upgrade

```text
pipx install --force "https://github.com/fbincon/claude-code-statusline/releases/download/v1.7.3/claude_code_statusline-1.7.3-py3-none-any.whl"
claude-statusline install --dry-run
claude-statusline install
claude-statusline doctor
```

Restart Claude Code after integration; Windows uses `claude-statusline.exe`. Python and both Mods are 1.7.3. Display schema v5, configuration protocol v4, runtime preference schema v2 and runtime protocol v2 remain compatible with saved choices. See the [user guide](https://github.com/fbincon/claude-code-statusline/blob/v1.7.3/docs/USER_GUIDE.md).

## Validation and publication

- Local validation passed 599 Python tests (591 passes, eight expected platform skips), 55 native and 10 runtime official Mod tests, both validators and TypeScript checks, generated contracts and Ruff. Regression checks cover supported legacy/current schemas, changed version constants, invalid/newer files, complete-draft refusal and unchanged configuration bytes.
- Documentation checks validate bilingual pairs, links and anchors; image verification checks all 21 supplied PNGs and the 18 archived files against their original hashes. Static screenshots illustrate layout; historical human acceptance and the macOS Client focus limitation keep their original scope.
- Publication requires all 20 PR/merge/tag CI jobs, installed core/native/runtime smoke, five-size external PTYs, persistent advanced Client PTYs, shared-configuration readback and 1.7.2 upgrades. Fixed-merge inventories, independent rebuild/install, draft/public SHA256 and public wheel/fixed-tag installations are verified before delivery.
