# v3.1.0 — Node LTS compatibility and regional Traditional Chinese

[English](#english) | [简体中文](#简体中文)

<a id="english"></a>

The statusline supports stable Node 22 and 24 (`^22.0.0 || ^24.0.0`). Reproducible builds keep their fixed Node 24.21.0/npm 11.19.0 toolchain. One offline npm package includes the existing Linux/WSL x64, Windows x64 and macOS Intel/Apple Silicon native dependencies.

- Traditional Chinese now offers **繁體中文（台灣）** (`zh-TW`) and **繁體中文（香港）** (`zh-HK`) throughout CLI, both editors, search, previews and production output. Interface and output choices remain independent.
- Existing `zh-Hant` arguments and configuration resolve to Taiwan. Reads leave files untouched; explicit saves and exports use `zh-TW`, retaining backup and transaction protection.
- Editor protocol **12** requires matching resources. After upgrading, run `claude-statusline install` and restart Claude Code. Display schema 8, UI preferences 1, portable envelope 1 and runtime protocol 2 retain their formats. Before downgrading, reset both languages to English with the newer package or restore a compatible backup.
- Install with `npm install --global --ignore-scripts @fbincon/claude-code-statusline`, then run `claude-statusline install --dry-run`, `claude-statusline install` and `claude-statusline doctor`. A fixed install uses `@3.1.0`. [Installation and recovery](../USER_GUIDE.md#installation-and-integration).
- Delivery includes the npm tgz, rebuildable source tar.gz, `build-manifest.json` and `SHA256SUMS`. CI requires the original eight targets/thirteen hosts plus 32 source/package-bound Node compatibility cases. Public-download checks cover latest 22.x and 24.x on Linux, Windows and macOS.

**Accepted known gaps:** the maintainer explicitly accepted the six existing gaps for this version: physical macOS sleep, macOS 14 Intel desktop/power, Windows 10 desktop, WSL desktop/popup, remaining target-specific human/power checks and Claude 2.1.296 exact declarations. They remain unverified; new functional or automated failures are not waived. [Approval](approvals/v3.1.0.json) · [Validation and delivery evidence](../development/node-regional-languages.md).

D06 remains FAIL; PERF-01 remains separate. This release makes no performance-improvement claim. Existing beta and Python rollback artifacts are retained.
