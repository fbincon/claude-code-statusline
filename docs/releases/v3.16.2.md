# v3.16.2 — Task pane controls and draft protection

**English** | [简体中文](v3.16.2.zh-CN.md)

Published on **2026-11-01**. Full gate, channel and machine evidence is in the [delivery record](../development/editor-input-delivery.md#final-release).

This release adds task-pane keyboard controls and protects unsaved editor drafts.

- Open `/statusline-task` and press **G** to search. Use **F/E/S** for status, evidence and identity, **N/P** for rows, **J/K** for pages and **Z** to fold the selected agent. Click the report to use `/` and arrows. Short panes give priority to report rows. [Task details](../TASK_DETAILS.md)
- Click the body of `/statusline-configure-native` before using editor shortcuts. In GNOME Terminal, **Ctrl+/** or **Ctrl+Shift+-** undoes an edit and **Ctrl+R** redoes it. The history page also accepts plain **U/R**. Empty history is reported explicitly. [Draft history](../DRAFT_HISTORY.md)
- **Ctrl+E** in the Native add picker shows the catalog type’s requirements. In the configured list it still edits the selected instance. Active manager fields keep their own input. [Component catalog](../COMPOSITION.md)
- The external editor asks before dropping unsaved configuration on Esc. Terminal key sequences and paste are consumed as complete inputs. File diagnosis keeps the active field visible in small windows and pages by the visible report height. [Editor controls](../USER_GUIDE.md)

After upgrading, run `claude-statusline install` and restart Claude Code to load the matching Native plugin. Display schema 17 and editor protocol 31 remain compatible.

Supported platforms/runtimes: Node 22/24 on Linux/WSL, Windows and macOS; existing host minimums and language choices remain supported.

Only the six existing [#96 gaps](https://github.com/fbincon/claude-code-statusline/issues/96) are accepted and remain unverified. Paid-model scope and outcomes are recorded in the delivery record. Post-publication findings receive issues without a patch release.
