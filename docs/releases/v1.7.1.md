# v1.7.1 — Clearer configuration TUIs

The in-session editor uses the available space more efficiently, and both editors make shortcut keys easier to scan. Python and both Mods are 1.7.1.

## Interface and documentation

- Section titles occupy frame edges in larger Client panes; compact panes retain a one-row heading. The minimum Client size remains 32×12, with frames from 64×20.
- Settings, Layout and item details pack actual field and group-heading rows into each page. Group context repeats across pages, page keys retain the field offset where possible, and resizing retains input and selection.
- Layout mode, row boundaries and item fitting occupy consecutive groups; item formats precede fitting controls. Field/value alignment respects CJK and combining characters.
- Both editors display white bold shortcut keys with regular dim descriptions and clip only complete shortcut groups. h still shows/hides Claude preferences; a applies them separately from tool Save/Finish.
- README platform galleries now include the existing Layout examples after Settings. Original PNGs and provenance remain unchanged; duplicated user-guide examples are removed. Retained images illustrate their original captures.

## Install or upgrade

```bash
pipx install --force "https://github.com/fbincon/claude-code-statusline/releases/download/v1.7.1/claude_code_statusline-1.7.1-py3-none-any.whl"
claude-statusline install --dry-run
claude-statusline install
claude-statusline doctor
```

Restart Claude Code after integration. On Windows use `claude-statusline.exe`. Existing configuration, display schema v5, configuration protocol v4, runtime protocol v2, timing behavior and independently saved installation preferences remain compatible. See the [user guide](../USER_GUIDE.md).

## Validation and publication

- Local checks cover 593 Python tests (585 passes, eight expected platform skips), 47 native and 10 runtime official Mod tests, both TypeScript projects, official static validation, generated contracts, Ruff and documentation links.
- Publication requires all 20 PR/merge/tag jobs, isolated installed-package external PTYs at five sizes, persistent advanced Client PTYs, shared configuration readback, 1.7.0 upgrades, fixed-merge wheel/sdist inventories and independent rebuilds/installations.
- Draft/public assets, SHA256SUMS and public wheel/fixed-tag installations are checked before completing delivery. No paid model/timer suite is needed for this presentation patch.
- Automated tests and agent capture inspection are separate from human acceptance. Existing macOS Client focus troubleshooting and earlier platform acceptance records remain available; this patch does not establish new human terminal acceptance.
