# v3.13.0 — Draft history and configuration reuse

**English** | [简体中文](v3.13.0.zh-CN.md)

Published on **2026-10-29**. Full gate, channel and machine evidence is in the [delivery record](../development/draft-history-and-reuse.md).

This release adds shared draft history, structural repair and configuration reuse to both editors.

- Share bounded undo/redo and a review of unsaved changes. Compare concurrent configuration changes, export a retained draft, explicitly discard/reload or adopt a reviewed revision before retrying Save. Unknown saves keep history frozen until reconciliation.
- Use Ctrl+Z / Ctrl+R for external undo/redo and Ctrl+_ / Ctrl+R for Native, with U/R also in Changes and history. The maintainer accepted this compatibility adjustment because the Unix host intercepts Ctrl+Z before Client delivery.
- Offer atomic alignment repairs for structural edits. Copy selected visual fields between components and reuse complete groups with reviewed dependencies, identity mappings and optional explicit layout conversion. Imported source bindings remain unresolved until explicitly rebound locally; import grants no authorization.

Editor protocol is 29. Display schema 16, portable/profile formats 1 and existing runtime/source formats remain compatible. Rerun `claude-statusline install` and restart Claude Code to load matching resources.

Supported platforms/runtimes: Node 22/24 on Linux/WSL, Windows and macOS; existing host minimums and language choices remain supported.

Known issues at this release: [#178](https://github.com/fbincon/claude-code-statusline/issues/178) full-tree signature audit, [#179](https://github.com/fbincon/claude-code-statusline/issues/179) real-profile validation isolation and [#180](https://github.com/fbincon/claude-code-statusline/issues/180) the untranslated Native style entry remain open at v3.13.0; details are in the delivery record. v3.13.0 is retained without a patch.

Only the six existing [#96 gaps](https://github.com/fbincon/claude-code-statusline/issues/96) are accepted and remain unverified. Paid-model and request details are in the delivery record. Post-publication findings receive issues without a patch release.
