# v3.13.0 — Draft history and configuration reuse

**English** | [简体中文](v3.13.0.zh-CN.md)

Both editors share bounded undo/redo and a review of unsaved changes. Compare concurrent configuration changes, export a retained draft, explicitly discard/reload or adopt a reviewed revision before retrying Save. Unknown saves keep history frozen until reconciliation.

External undo/redo uses Ctrl+Z / Ctrl+R; Native uses Ctrl+_ / Ctrl+R, with U/R also in Changes and history. The maintainer accepted this compatibility adjustment because the Unix host intercepts Ctrl+Z before Client delivery.

Structural edits now offer atomic alignment repairs. Copy selected visual fields between components and reuse complete groups with reviewed dependencies, identity mappings and optional explicit layout conversion. Imported source bindings remain unresolved until explicitly rebound locally; import grants no authorization.

Editor protocol is 29. Display schema 16, portable/profile formats 1 and existing runtime/source formats remain compatible. Install matching frontend/backend resources and reopen editors after upgrading.
