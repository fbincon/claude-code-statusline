## 本目录说明

每个版本保留一个发布页面；v3.10.0 及以后英文和中文分页。`approvals/` 是机器可读的版本决定，不是读者文档。[变更日志](../../CHANGELOG.zh-CN.md)负责带日期的简明版本摘要，[开发历史](../development/history/README.zh-CN.md)负责交付与验收证据。
