# v3.16.2 — 任务窗格操控与草稿保护

[English](v3.16.2.md) | **简体中文**

发布于 **2026-11-01**。交付记录列出了验收通过的源码、原始文件与安装检查结果。[发布证据](../development/editor-input-delivery.zh-CN.md#final-release)

- 打开 `/statusline-task` 后按 **G** 搜索，**F/E/S** 分别操作状态筛选、证据与身份，**N/P** 逐行选择，**J/K** 翻页，**Z** 展开或折叠选中的代理。点击正文后可用 `/` 和方向键。较矮窗格优先显示报告行。[任务详情](../TASK_DETAILS.zh-CN.md)
- 使用 `/statusline-configure-native` 的快捷键前先点击编辑区正文。在 GNOME Terminal 中按 **Ctrl+/** 或 **Ctrl+Shift+-** 撤销，按 **Ctrl+R** 重做。历史页也接受普通 **U/R**，历史为空时会提示原因。[草稿历史](../DRAFT_HISTORY.zh-CN.md)
- Native 添加选择器中的 **Ctrl+E** 显示目录类型的只读要求，在已配置列表中则编辑选中的实例。活动管理器的字段独立处理输入。[组件目录](../COMPOSITION.zh-CN.md)
- 外部编辑器按 Esc 放弃未保存的配置时会先确认，按完整序列处理终端组合键和粘贴。文件诊断在小窗中保留当前字段，并按可见报告高度翻页。[编辑器操作](../USER_GUIDE.zh-CN.md)

升级后运行 `claude-statusline install`，重启 Claude Code 加载配套 Native 插件。显示 schema 17 和编辑器协议 31 保持兼容。
