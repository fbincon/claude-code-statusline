# v3.16.0 — 新增六种语言

[English](v3.16.0.md) | **简体中文**

发布准备进行中；发布与本机验证证据将在[交付记录](../development/language-expansion.zh-CN.md)中记录。

界面和状态栏语言选择器新增西班牙语、法语、德语、巴西葡萄牙语、俄语和印度尼西亚语。十二种语言全部随包离线提供，覆盖 CLI 帮助／错误、双编辑器、恢复、预览及主／子代理输出。界面语言立即保存，输出语言随显示 Save／Cancel。

编辑器协议 31 要求匹配的前后端资源。升级后重新运行 `claude-statusline install` 并重启 Claude Code。显示 schema 17 与界面偏好 1 保留原格式及已有值。降级到不支持所选语言的版本前，使用当前版本将两种语言重置为英文。

发布要求完整验收译文、144 组独立界面／输出组合、313 项实际宿主容量案例，以及原有八安装目标／32 项 Node／十六宿主产品矩阵。Client props、Pane 和 Client 绘制保留独立限制及完整字素适配；Node 字典声明类型在语言扩展时保持有界。

仅接受 [issue #96 六项既有缺口](https://github.com/fbincon/claude-code-statusline/issues/96)，它们仍未验证。不计划付费模型测试；发布后本机新发现只提 issue，不补发修补版。
