# v3.16.0 — 新增六种语言

[English](v3.16.0.md) | **简体中文**

已于 **2026-10-30** 发布。完整门禁、渠道及本机证据见[交付记录](../development/language-expansion.zh-CN.md#final-release)。

本版本新增六种界面和状态栏语言，公开发行版达到十二种语言。

- 界面和状态栏语言选择器新增西班牙语、法语、德语、巴西葡萄牙语、俄语和印度尼西亚语。
- 十二种语言全部随包离线提供，覆盖 CLI 帮助／错误、双编辑器、恢复、预览及主／子代理输出。界面语言立即保存，输出语言随显示 Save／Cancel。
- 语言覆盖扩大时，Client props、Pane 和 Client 绘制保持独立限制和完整字素适配；Node 字典声明类型保持有界。

编辑器协议 31 要求匹配的前后端资源。升级后重新运行 `claude-statusline install` 并重启 Claude Code。显示 schema 17 与界面偏好 1 保留原格式及已有值。降级到不支持所选语言的版本前，使用当前版本将两种语言重置为英文。

支持平台／运行时：Node 22／24，Linux／WSL、Windows 和 macOS；原有八安装目标／32 项 Node／十六宿主产品矩阵保持支持。

发布要求完整验收译文、144 组独立界面／输出组合和 313 项实际宿主容量案例；这些项目与最终 PR／main／tag 门禁均已通过。

仅接受 [issue #96 六项既有缺口](https://github.com/fbincon/claude-code-statusline/issues/96)，它们仍未验证。本版本未运行付费模型测试；发布后新发现只提 issue，不补发修补版。私有验收脚本诊断及实际结果见交付记录。
