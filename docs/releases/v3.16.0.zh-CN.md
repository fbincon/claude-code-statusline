# v3.16.0 — 新增六种语言

[English](v3.16.0.md) | **简体中文**

发布状态：已完成；发布日期：2026-10-30。准确源码、门禁、公开渠道及本机验证结果见[交付记录](../development/language-expansion.zh-CN.md#final-release)。

界面和状态栏语言选择器新增西班牙语、法语、德语、巴西葡萄牙语、俄语和印度尼西亚语。十二种语言全部随包离线提供，覆盖 CLI 帮助／错误、双编辑器、恢复、预览及主／子代理输出。界面语言立即保存，输出语言随显示 Save／Cancel。

编辑器协议 31 要求匹配的前后端资源。升级后重新运行 `claude-statusline install` 并重启 Claude Code。显示 schema 17 与界面偏好 1 保留原格式及已有值。降级到不支持所选语言的版本前，使用当前版本将两种语言重置为英文。

发布要求完整验收译文、144 组独立界面／输出组合、313 项实际宿主容量案例，以及原有八安装目标／32 项 Node／十六宿主产品矩阵。Client props、Pane 和 Client 绘制保留独立限制及完整字素适配；Node 字典声明类型在语言扩展时保持有界。实际覆盖结果：8 个安装目标、32 项 Node、16 个固定宿主、144 组界面／输出组合和 313 个实际宿主容量案例全部通过，最终 PR／main／tag 门禁保留原始证据身份。

仅接受 [issue #96 六项既有缺口](https://github.com/fbincon/claude-code-statusline/issues/96)，它们仍未验证。未运行付费模型测试；发布后本机新发现只提 issue，不补发修补版。实际模型请求与发布后发现：模型调用及请求尝试均为零，已完成的检查中未发现新的产品问题。首次 Native 启动失败属于私有验收脚本的配置路径诊断，与成功重试分别保留。
