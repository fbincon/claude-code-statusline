# v1.9.0 — English and Simplified Chinese statusline output

Choose the language of the actual main statusline and subagent rows independently of the interface language. English remains the default. Both editors preview output-language changes immediately and save them with display settings.

## Install or upgrade

```text
pipx install --force fbincon-claude-code-statusline==1.9.0
claude-statusline install
claude-statusline doctor
claude-statusline config language set zh-CN
claude-statusline config set statusline-language zh-CN
```

Restart Claude Code after refreshing bundled integration. Later output-language changes take effect on the next statusline refresh. The package name, Python import and CLI remain unchanged.

## Language and configuration behavior

- Settings offers **Statusline language (save with display settings)** with **English / 简体中文** choices. Preview follows the draft; Save persists output language, Cancel discards it. Interface language retains its immediate, independent save behavior.
- Translate tool-owned phrases and known lifecycle, permission, effort, cache and review values. Preserve unknown values, model/tool/task names, paths, branches, custom labels/icons, numbers, currency and technical units. Item-owned label boundaries protect user data and avoid duplicate inherited prefixes.
- `config set statusline-language en|zh-CN` sets output language. `config apply --statusline-language en|zh-CN` is optional and preserves the current value when omitted. The legacy wizard reads interface preferences and localized CLI descriptions before applying all answers atomically.
- Display schema and configuration protocol advance to **v6**. Historical v1–v5 reads/imports default to English without rewriting files; explicit saves back up and migrate. Revisions and exports include language, presets retain it, display reset restores English. UI preference schema v1, runtime protocol v2 and portable envelope v1 remain independent.
- Upgrade matching backend/native resources together. Before downgrading to a schema-v5-only package, remove newer native integration and restore a compatible display backup as described in [output language and recovery](../USER_GUIDE.md#statusline-language).

## Validation and publication

Development validation passed **706 Python tests** (698 passes, eight expected platform skips), **74 native and ten runtime official Mod tests**, both TypeScript projects, resource/contract generation, Ruff and bilingual documentation checks. A generated Python-only resource subset keeps normal rendering free of UI preference reads and UI JSON parsing. All **444 default-English production/preview comparisons** match the previous release.

Installed development wheels passed real Linux x86_64 / CPython 3.14.4 language PTYs: external 64×18, 64×20, 80×24, 120×30 and 80×48; persistent native 120×30 and 80×48 with fixed Claude Code 2.1.294. Checks cover both switch directions, unsaved drafts, cancel, save, shared preferences, reopen and subsequent production rendering. [Eight new images](../images/README.md#statusline-language-captures) reconstruct actual terminal cells, including real renderer stdout with fixed JSON input. Agent image inspection is separate from human acceptance.

Same-machine 50-sample formatted-render P50/P95: previous release 54.261/66.363 ms; English 55.051/64.294 ms; Chinese 54.313/68.506 ms. Small fixtures and scheduling noise limit conclusions. This release uses local commands and fixed samples without paid model calls, and does not claim new human or Windows/macOS terminal acceptance.

Publication requires all 23 cross-platform jobs on the PR, merge and tag, fixed-merge wheel/sdist/checksums, independent rebuild/install and upgrade verification, verified draft/public bytes, TestPyPI acceptance, formal PyPI index installations, and identical GitHub/Gitee attachments. The existing [macOS Client focus limitation](../USER_GUIDE.md#macos-mouse-reporting-and-client-focus) remains documented.

## v1.9.0 — 中英文状态栏输出

主状态栏与子代理行的实际输出可独立于界面语言选择中英文，默认英文。两个编辑器立即预览输出语言草稿，随显示设置保存。

### 安装或升级

```text
pipx install --force fbincon-claude-code-statusline==1.9.0
claude-statusline install
claude-statusline doctor
claude-statusline config language set zh-CN
claude-statusline config set statusline-language zh-CN
```

刷新包内接入后重启 Claude Code；后续输出语言修改在状态栏下次刷新时生效。软件包名称、Python 导入及 CLI 名称不变。

### 语言与配置行为

- 设置页提供**状态栏语言（随显示设置保存）**，选项为 **English / 简体中文**。预览采用草稿，保存持久化输出语言，取消放弃修改；界面语言仍立即独立保存。
- 翻译内置短语和已知生命周期、权限、强度、缓存及审核值。未知值、模型／工具／任务名称、路径、分支、自定义标签／图标、数字、货币和技术单位保留。内置标签边界保护用户数据并避免重复前缀。
- `config set statusline-language en|zh-CN` 设置输出语言；可选 `config apply --statusline-language en|zh-CN` 省略时保留当前值。旧版向导读取界面偏好及 CLI 翻译说明，再一次原子应用全部答案。
- 显示 schema 与配置协议升级到 **v6**。读取／导入 v1–v5 补为英文且不改写，显式保存先备份再迁移。revision 和导出包含语言，预设保留它，显示 reset 恢复英文；UI 偏好 schema v1、运行协议 v2 和可移植封装 v1 保持独立。
- 后端／原生资源须匹配升级。降级到仅支持 schema v5 的包前，移除新原生接入并恢复兼容显示备份；见[语言与恢复](../USER_GUIDE.zh-CN.md#状态栏语言)。

### 验证与发布

开发验证通过 **706 项 Python 测试**（698 通过、8 项预期平台跳过）、**74 项原生及 10 项运行 Mod 官方测试**、两个 TypeScript 工程、资源／契约生成、Ruff 和双语文档检查。轻量 Python 资源子集使正常渲染不读取 UI 偏好或解析 UI JSON；**444 个默认英文生产／预览对照**与旧版一致。

安装开发包在 Linux x86_64／CPython 3.14.4 下通过真实语言 PTY：外部 64×18、64×20、80×24、120×30、80×48；固定 Claude Code 2.1.294 的持久化原生 120×30、80×48。覆盖双向切换、未保存草稿、取消、保存、共享偏好、重开及后续生产渲染。[八张新图片](../images/README.zh-CN.md#状态栏语言采集)重建真实单元格，包括固定 JSON 输入的真实 renderer stdout；代理画面检查与人工验收分开记录。

同机 50 样本格式化渲染 P50／P95：旧版 54.261／66.363 ms、英文 55.051／64.294 ms、中文 54.313／68.506 ms。小型样例与调度噪声限制结论。本轮仅用本地命令和固定数据，不调用付费模型，不宣称新增人类或 Windows／macOS 终端验收。

发布要求 PR／合并／标签的 23 项跨平台检查，固定合并提交的 wheel／sdist／校验文件、独立重建／安装／升级验证、草稿／公开字节核验、TestPyPI 验收、正式 PyPI 索引安装，以及 GitHub／Gitee 一致附件。既有 [macOS Client 焦点限制](../USER_GUIDE.zh-CN.md#macos-鼠标报告与-client-焦点)继续保留。
