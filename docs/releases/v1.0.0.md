# v1.0.0

[English](#english) | [简体中文](#简体中文)

<a id="english"></a>

The first public release of Claude Code Statusline.

- Linux/WSL: Python 3.10+; Windows 10/11: CPython 3.10–3.14, x86/x64.
- Main status line: model and effort, Git, context, limits, tokens, and end-to-end per-turn timing.
- Individual subagent rows (Claude Code 2.1.205+) and unified TUI/CLI configuration for main and subagent lines.
- MIT License; see the version-specific repository README for installation, screenshots, and configuration.

Linux/Windows × Python 3.10/3.14 CI and distribution build checks passed. The wheel was installed in an isolated Linux environment and verified for installation, doctor, main/subagent rendering, and uninstallation.

Download the wheel and run `pipx install <downloaded .whl file>`, then `claude-statusline install --dry-run`, `claude-statusline install`, and `claude-statusline doctor`. On Windows, use `claude-statusline.exe`.

Assets include the wheel, source distribution, and `SHA256SUMS`. This version does not support macOS; native Windows ARM64 Python is not guaranteed.
