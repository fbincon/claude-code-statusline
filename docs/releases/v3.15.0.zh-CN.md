# v3.15.0 — 增量多语言开发

[English](v3.15.0.md) | **简体中文**

已于 2026-10-30 发布到 [GitHub](https://github.com/fbincon/claude-code-statusline/releases/tag/v3.15.0)、[npm](https://www.npmjs.com/package/@fbincon/claude-code-statusline) 和 [Gitee](https://gitee.com/fbincon/claude-code-statusline/releases/tag/v3.15.0)。必需门禁、公开检查和本机验证均通过；[最终证据](../development/i18n-02-delivery.zh-CN.md#final-release)保留来源身份及 #96 六项未验证缺口。

I18N-02 新增增量翻译工作流，同时保持公开发行版对英语、简体中文、台湾繁体中文、香港繁体中文、日语和韩语的完整离线支持。

开发期间，缺失、陈旧或未验证的官方译文使用当前英文模板；英文和简体中文保持完整。源文案含义、命名占位符、语义上下文、术语及译文修改会使对应验收失效。不合法的新提交不能藏在回退之后；可验证的退休模板不进入当前资源。

开发者可以查看真实覆盖率、冻结不可变增量任务清单、验证一批译文，并显式更新匹配的验收记录。Node、Native 和包内 JSON 使用同一份有效资源；多语言搜索保留回退证据的真实来源。语言历史和审阅输入不进入运行包。

界面语言继续立即保存；输出语言继续随显示设置保存／取消。显示 schema 17、编辑器协议 30、既有别名、存储设置及 Native 恢复保持兼容。Native props、Pane 和 Client 绘制分别检查预算，字典和验收历史不传给 Client。

发布要求最终 PR／main／tag 门禁、八个安装目标、32 项 Node、十六个固定宿主、全部既有 271 项容量案例加十二项语言案例，以及安装包 36 种语言组合检查。仅接受 [#96 六项既有缺口](https://github.com/fbincon/claude-code-statusline/issues/96)，它们仍未验证。本任务不调用付费模型；发布后本机新发现只提 issue，不补发修补版。
