# v3.15.0 — 增量多语言开发

[English](v3.15.0.md) | **简体中文**

已于 **2026-10-30** 发布。完整门禁、渠道及本机证据见[交付记录](../development/i18n-02-delivery.zh-CN.md#final-release)。

本版本新增增量翻译工作流，同时保持六种公开发行语言的完整离线支持。

- 为英语、简体中文、台湾繁体中文、香港繁体中文、日语和韩语新增增量翻译工作流。
- 开发期间，缺失、陈旧或未验证的官方译文使用当前英文模板；英文和简体中文保持完整。不合法的新提交不能藏在回退之后；可验证的退休模板不进入当前资源。
- 开发者可以查看真实覆盖率、冻结不可变任务清单、验证一批译文，并显式更新匹配的验收记录。Node、Native 和包内 JSON 使用同一份有效资源；语言历史和审阅输入不进入运行包。
- 界面语言继续立即保存；输出语言继续随显示设置保存／取消。Native props、Pane 和 Client 绘制分别检查预算，字典和验收历史不传给 Client。

显示 schema 17、编辑器协议 30、既有别名、存储设置及 Native 恢复保持兼容。升级后运行 `claude-statusline install` 并重启 Claude Code。

支持平台／运行时：Node 22／24，Linux／WSL、Windows 和 macOS；既有宿主最低版本及六种界面／输出语言保持可用。

发布要求最终 PR／main／tag 门禁、八个安装目标、32 项 Node、十六个固定宿主、全部既有 271 项容量案例加十二项语言案例，以及安装包 36 种语言组合检查。

仅接受 [issue #96 六项既有缺口](https://github.com/fbincon/claude-code-statusline/issues/96)，它们仍未验证。本版本不调用付费模型；发布后新发现只提 issue，不补发修补版。
