# v3.0.0 — TypeScript stable release

[English](#english) | [简体中文](#简体中文)

<a id="english"></a>

The statusline now ships as the stable TypeScript npm package, with the existing configuration, component composition, CLI and both editors. Normal installation and use require Node instead of Python.

- Requires Node **24.21.0**; the verified toolchain uses npm **11.19.0**. One offline npm package bundles Linux/WSL x64, Windows x64 and macOS Intel/Apple Silicon dependencies. Windows ARM uses x64 Node emulation; native Windows ARM64 and 32-bit runtimes are outside the support contract.
- Fresh installs default **native timing and advanced live collection off**. Saved preferences and explicit installation flags retain precedence. Use `install --native-timing` for timing sampling or `install --live-metrics` for complete observations. Basic hook/transcript task timing remains available; both compatible editors still default on.
- External TUI pages restore complete frames, grouped separators, aligned columns, full-width selections, terminal cyan headings and bold shortcut keys. Existing edit/save/cancel behavior, Unicode width handling and production preview colors are preserved.
- Install: `npm install --global --ignore-scripts @fbincon/claude-code-statusline`, then `claude-statusline install --dry-run`, `claude-statusline install` and `claude-statusline doctor`. Restart Claude Code. Use `@3.0.0` for a fixed version; Windows uses `.cmd`/`.ps1` wrappers or an explicit Node/JavaScript entry. [Installation, Python transition and rollback](../USER_GUIDE.md#installation-and-integration).
- Four assets: `fbincon-claude-code-statusline-3.0.0.tgz`, `claude-code-statusline-3.0.0-source.tar.gz`, `build-manifest.json`, `SHA256SUMS`. Check hashes before installing the local tgz with `--offline --ignore-scripts`. Source and package manifests identify the immutable source; automatic repository ZIPs are not the rebuildable source attachment.

Display schema 8, editor protocol 11, runtime protocol 2 with v1 compatibility, task schema 4 and independent preferences remain compatible. Reads do not rewrite old configuration; real saves retain backups. Preserve the Python v2.0.0 environment and compatible pre-cutover backup when rollback is needed. No PyPI upload occurs; the published beta and its artifacts remain intact.

**Accepted known gaps:** on 2026-10-18 the maintainer approved v3.0.0 publication while retaining unverified physical macOS sleep/resume, macOS 14 Intel desktop/power, Windows 10 desktop, WSL desktop/popup and remaining target-specific human/power checks. Claude 2.1.296 exact declarations remain unavailable; official Mod tests and available exact-host checks are separate evidence. The macOS Client may require clicking its region before typing. This version-limited decision does not mark missing checks passed or waive failed functional/automated checks. [Decision and approval record](../development/typescript-migration/ts-06/README.md#stable-decision-2026-10-18).

D06 remains **FAIL: 104 pass / 60 fail / 28 inconclusive**. PERF-01 is a separate follow-up; this release makes no performance improvement claim. [Delivery evidence](../development/typescript-migration/ts-06/stable-release.md) records actual CI, source/package identity and public-channel checks; [tracker #96](https://github.com/fbincon/claude-code-statusline/issues/96) retains the distinction between verified results and accepted gaps.

状态栏现通过 TypeScript npm 包正式分发，保留已有配置、组件组合、CLI 和两种编辑器；正常安装及运行使用 Node，无需 Python。

- 需要 Node **24.21.0**，验证工具链使用 npm **11.19.0**。通用离线 npm 包包含 Linux/WSL x64、Windows x64 和 macOS Intel/Apple Silicon 原生依赖。Windows ARM 使用模拟 x64 Node；不提供原生 Windows ARM64 或 32 位运行时。
- 新安装默认**关闭原生计时和高级实时采集**，保留已保存偏好与显式安装参数优先级。`install --native-timing` 启用计时采样，`install --live-metrics` 启用完整观测。基础 hook/transcript 任务计时继续可用；兼容宿主的双编辑器仍默认启用。
- 外部 TUI 恢复完整边框、分组横线、列对齐、整行选中、终端青色标题及加粗快捷键；保留编辑、保存、取消、Unicode 宽度和生产预览配色。
- 安装：`npm install --global --ignore-scripts @fbincon/claude-code-statusline`，再执行 `claude-statusline install --dry-run`、`claude-statusline install`、`claude-statusline doctor`，随后重启 Claude Code。固定版本用 `@3.0.0`；Windows 使用 `.cmd`/`.ps1` 或明确的 Node/JavaScript 入口。[安装、Python 迁移及回退](../USER_GUIDE.zh-CN.md#安装与接入)。
- 四附件为 npm tgz、可重建源码 tar.gz、`build-manifest.json`、`SHA256SUMS`。先核对摘要，再以 `--offline --ignore-scripts` 安装本地 tgz。源码及包清单记录不可变源码身份；仓库自动 ZIP 不是可重建源码附件。

显示 schema 8、编辑器协议 11、runtime 协议 2/v1、任务 schema 4 及独立偏好保持兼容。读取不重写旧配置，真实保存保留备份。需要回退时保留 Python v2.0.0 环境及切换前兼容备份。不上传 PyPI，既有 beta 及其附件保留。

**接受的已知缺项：** 维护者于 2026-10-18 批准发布 v3.0.0，同时保留 macOS 实机休眠恢复、macOS 14 Intel 桌面/电源、Windows 10 桌面、WSL 桌面/弹窗及其他目标人工/电源覆盖的未验证状态。Claude 2.1.296 精确声明仍不可用，官方 Mod 测试与可用宿主类型检查分别记录。macOS Client 可能需先点击区域再输入。该批准仅适用于本版本，不把缺项标为通过，也不豁免功能或自动化失败。[决定与批准记录](../development/typescript-migration/ts-06/README.zh-CN.md#正式版决定2026-10-18)。

D06 保持 **FAIL：104 pass / 60 fail / 28 inconclusive**，PERF-01 后续独立处理，本次不宣称性能提升。[交付证据](../development/typescript-migration/ts-06/stable-release.zh-CN.md)记录实际 CI、源码/包身份及公开渠道检查；[跟踪 #96](https://github.com/fbincon/claude-code-statusline/issues/96)继续区分验证结果与接受的缺项。
