# v1.1.0

[English](#english) | [简体中文](#简体中文)

<a id="english"></a>

v1.1.0 is a stable release supporting Linux, WSL, Windows, and macOS with the same pure-Python wheel. macOS core functionality and the standalone TUI are now officially supported; experimental `/statusline-configure` adds a Terminal.app launcher.

## Highlights

- macOS supports the main status line, individual subagent rows, installation and configuration commands, doctor diagnostics, and standalone curses TUI, with file locking, atomic writes, process identity, and sleep-inclusive native timing.
- The macOS experimental launcher prefers a valid tmux popup, otherwise opening the TUI through Terminal.app in a local graphical session. No AppleScript automation permission is required; window closure or retention follows Terminal preferences.
- The Terminal launcher binds the current Python, CLI, configuration directory, and working directory, supporting spaces, Chinese characters, and shell metacharacters. Startup handshake, process verification, and result bridging handle launch failures, window closure, interruption, and timeout; invalidated calls cannot keep saving.
- Include main status line and Main/Subagents/Settings screenshots for Linux, macOS, and Windows, with unified installation, upgrade, file verification, and maintainer release procedures.
- Display configuration remains schema v2 and experimental preferences schema v1. Upgrades from v1.0.0 or v1.1.0a1 need no data migration. The experimental entry point is disabled by default and must be explicitly enabled.

## Supported platforms

- Native Linux / WSL: Python 3.10+.
- Windows 10/11: CPython 3.10–3.14, x86/x64; automatically installs `windows-curses>=2.4.2`. Native Windows ARM64 Python is not currently guaranteed; ARM devices can use x64 Python emulation.
- macOS 14+: CPython 3.10–3.14, Intel / Apple Silicon; Python must provide curses.
- Claude Code CLI: individual subagent rows require 2.1.205+, task effort 2.1.214+, and local configuration commands with arguments plus the experimental TUI launcher 2.1.258+. Older versions can still use the main line and wizard.

## Installation and upgrading

Prepare Python, Claude Code CLI, and pipx, then run in Bash / Zsh / PowerShell:

```text
pipx install "https://github.com/fbincon/claude-code-statusline/releases/download/v1.1.0/claude_code_statusline-1.1.0-py3-none-any.whl"
pipx ensurepath
```

For an existing installation, add `--force` to `pipx install`. Reopen the terminal, then run:

```bash
claude-statusline --version
claude-statusline install --dry-run
claude-statusline install
claude-statusline doctor
```

On Windows, use `claude-statusline.exe`. Rerun `install` after upgrading to synchronize skills, hooks, and command paths. Display preferences and runtime state remain in the Claude configuration directory. Fixed-tag source can be installed with `pipx install "git+https://github.com/fbincon/claude-code-statusline.git@v1.1.0"`.

Assets include the wheel, source distribution, and `SHA256SUMS`. Download all three into the same directory. Verify with `sha256sum -c SHA256SUMS` on Linux/WSL, `shasum -a 256 -c SHA256SUMS` on macOS, or compare Windows `Get-FileHash -Algorithm SHA256` results with the manifest.

Run `claude-statusline configure` in the current terminal for the standalone TUI. v1.1.0 是支持 Linux、WSL、Windows 和 macOS 的稳定版，提供同一个纯 Python wheel。macOS 核心功能与独立 TUI 转为正式支持；实验性 `/statusline-configure` 新增 Terminal.app 启动入口。

## 主要变化

- macOS 支持主状态栏、子 Agent 独立行、安装与配置命令、doctor 诊断和独立 curses TUI，并适配文件锁、原子写入、进程身份识别及包含睡眠时间的原生计时。
- macOS 实验启动器优先使用有效的 tmux popup，否则在本地图形会话中通过 Terminal.app 打开 TUI，无需 AppleScript 自动化权限；窗口关闭或保留遵循 Terminal 偏好。
- Terminal 启动器绑定当前 Python、CLI、配置目录和工作目录，支持空格、中文及 shell 特殊字符；通过启动握手、进程核验和结果回传处理启动失败、关窗、中断与超时，失效调用不能继续保存。
- 收录 Linux、macOS、Windows 的主状态栏与 Main、Subagents、Settings 配置页截图，统一安装、升级、文件校验及维护者发布流程。
- 显示配置继续使用 schema v2，实验功能偏好使用 schema v1；从 v1.0.0 或 v1.1.0a1 升级无需数据迁移。实验入口默认关闭，使用前需显式启用。

## 支持范围

- Linux 原生 / WSL：Python 3.10+。
- Windows 10/11：CPython 3.10–3.14，x86/x64；自动安装 `windows-curses>=2.4.2`。Windows ARM64 原生 Python 暂不承诺，ARM 设备可使用 x64 Python 仿真。
- macOS 14+：CPython 3.10–3.14，Intel / Apple Silicon，Python 需提供 curses。
- Claude Code CLI：子 Agent 独立行需要 2.1.205+，任务 effort 需要 2.1.214+；带参数配置命令的本地执行及实验性 TUI 启动器需要 2.1.258+。旧版仍可使用主状态栏和配置向导。
