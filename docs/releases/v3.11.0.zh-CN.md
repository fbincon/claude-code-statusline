# v3.11.0 — 任务浏览与版本审核

[English](v3.11.0.md) | **简体中文**

本版本增加独立 `task view` 命令和外部编辑器任务入口，Native／外部共享搜索、状态过滤、树折叠、证据分层及阅读位置保持。

双编辑器展示本机安装状态，提供显式元数据检查和已验证软件包 dry-run 审核。软件包回退与配置还原分别审核；执行和受保护历史清理继续通过既有 CLI，界面流程属于后续 UPDATE-02 切片。

编辑器协议为 27，显示 schema 保持 16，任务详情保持版本 1。升级后重新安装匹配的 Native 资源，再重开编辑器或重启 Claude。既有显示选择、任务存储及来源授权保持兼容。

[任务详情](../TASK_DETAILS.zh-CN.md) · [包管理](../PACKAGE_MANAGEMENT.zh-CN.md) · [实现与验收](../development/task-version-review.zh-CN.md)。

最终 PR／main／tag 证据链及公开下载检查已通过，相同六项 issue #96 既有缺口继续接受且未验证。自动化及 PTY 证据不代表人工桌面或实体电源验收。

已知问题：普通 npm 清单的 `0644`／`0664` 权限可能导致版本页误报本机读取／兼容错误。[Issue #173](https://github.com/fbincon/claude-code-statusline/issues/173) 记录原因和回归要求。维护者要求保留 3.11.0，留待后续开发修复，不发布 3.11.1；既有 CLI 包审核仍可使用。
