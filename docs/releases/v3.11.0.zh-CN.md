# v3.11.0 — 任务浏览与版本审核

[English](v3.11.0.md) | **简体中文**

已于 **2026-10-28** 发布。完整门禁、渠道及本机证据见[交付记录](../development/task-version-review.zh-CN.md)。

本版本为双编辑器新增任务浏览和本机版本审核。

- 新增独立 `task view` 命令和外部编辑器任务入口，Native／外部共享搜索、状态过滤、树折叠、证据分层及阅读位置保持。
- 双编辑器展示本机安装状态，提供显式元数据检查和已验证软件包 dry-run 审核。
- 软件包回退与配置还原分别审核；执行和受保护历史清理继续通过既有 CLI，界面流程属于后续 UPDATE-02 切片。

编辑器协议为 27；显示 schema 保持 16，任务详情保持版本 1。升级后运行 `claude-statusline install`，再重开编辑器或重启 Claude Code。既有显示选择、任务存储及来源授权保持兼容。

支持平台／运行时：Node 22／24，Linux／WSL、Windows 和 macOS；既有宿主最低版本及语言选择保持可用。

已知问题：普通 npm 清单的 `0644`／`0664` 权限可能导致版本页误报本机读取／兼容错误。[Issue #173](https://github.com/fbincon/claude-code-statusline/issues/173) 记录原因和回归要求；3.11.0 保留，不发布 3.11.1。

仅接受 [issue #96 六项既有缺口](https://github.com/fbincon/claude-code-statusline/issues/96)，它们仍未验证。自动化及 PTY 证据不代表人工桌面或实体电源验收。付费模型范围及结果见交付记录；发布后新发现只提 issue，不补发修补版。
