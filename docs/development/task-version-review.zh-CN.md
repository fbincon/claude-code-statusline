# 任务浏览与版本审核

[English](task-version-review.md) | **简体中文**

本页说明任务浏览与只读任务证据、本机包审核及其共享编辑器与 Native 展示。原始 v3.11.0 实现与发布证据见[交付记录](history/deliveries/task-version-review.zh-CN.md#任务浏览与版本审核)。[任务用法](../TASK_DETAILS.zh-CN.md) · [包管理](../PACKAGE_MANAGEMENT.zh-CN.md)。

## 职责与接口

Core 管理任务阅读／导航、包审核状态、本地化展示及响应校验；CLI 提供已知任务文件、本机包检查和既有 UPDATE-01 审核服务；platform 处理独立进程启动、包复制和有界 npm 进程；TUI 管理终端 I/O。Native 将完整任务报告保留在宿主侧，仅向 Client 发送有界展示／输入帧。

独立 `task view` 要求填写会话 ID，外部编辑器的“设置”可打开相同的任务查看器。省略 prompt ID 时跟随已发布的当前任务指针，指定 prompt ID 时固定查看该任务及其后续进展。两个终端入口与原生窗格共享状态过滤、不区分大小写的名称／ID 搜索、父级上下文、展开折叠、证据显示和稳定行锚点。任务读取只访问已知本机文件，原生窗格按需读取。

外部编辑器每 2 秒读取运行中的任务或作业。对空闲任务或结果待定的作业，每 10 秒读取一次。读取失败后延长重试间隔，最长 30 秒，并保留上次成功报告及读取时间。终端同一时间只读取当前可见页面，输入或确认期间暂停，可见内容变化后才重绘。按键立即刷新可复用进行中的读取。打开任务查看器或按键立即刷新时重读界面偏好。

## 审核与失败行为

进入包页面仅检查本机。显式元数据检查仍标记尚未验证；下载／暂存 dry-run 验证所选产物与接入预检。后续验证固定元数据结果的精确版本和完整性。审核快照绑定安装身份、prefix、配置目录、已保存配置摘要、渠道／历史及宿主身份；快照变化使结果失效。配置还原审核与软件包回退独立，不代表进行了产物验证。

长审核使用私有临时作业。对于已安装包，执行器来自当前包的独立副本。作业仅接受 check／dry-run 操作，具有所有者和截止时间，沿用有界、字面 argv 的 npm 适配器并禁用生命周期脚本。外部状态页按既有审核或执行 ID 查询，直到取得明确终态。原生窗格按需查询进度。关闭只取消当前视图的临时审核，迟到的启动结果也会被取消。交接后的执行在关闭视图后继续。取消在短请求时限内确认进程退出后才删除执行器副本。未确认停止时保留文件并阻止替换审核。临时审核文件不会成为安装事务或恢复历史。既有 CLI 执行、锁、快照及恢复继续由 UPDATE-01 提供。

损坏历史和快照仅报告、不修复；历史展示每页最多读取 16 条记录，未完成事务单独展示。审核不保存编辑器草稿，也不还原来源授权。
