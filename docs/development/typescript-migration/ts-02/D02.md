# D02 — Clocks, process identity and lossless JSON

**English** | [简体中文](D02.zh-CN.md)

State: **OPEN**. Date: 2026-10-12 (Asia/Shanghai).

Evidence and stage status:  [TS-02](README.md)。

## Direction

Probe the same operating-system clock and identity APIs as the frozen Python implementation through Koffi. Linux uses CLOCK_BOOTTIME and /proc boot/start identities; macOS uses mach_continuous_time, kern.bootsessionuuid and locale/timezone-fixed ps; Windows uses GetTickCount64, the boot GUID and the existing CreationDate-compatible token conversion.

## Interface and behavior

Use bigint for integer arithmetic and retain numeric JSON literals on disk. Node 24 JSON.parse reviver context.source captures the original lexeme before constructing LosslessNumber; field validators explicitly require integer syntax before BigInt conversion. A key scanner over syntactically valid JSON rejects every duplicate, including escaped and equal-value duplicates. Native JSON parsing preserves own __proto__ keys safely.

## Validation

An important rejected behavior: lossless-json 4.3.1 parse suppresses equal duplicates even with onDuplicateKey. Its numeric representation/serializer remain usable; its parser is not the strict entry point. Preserve integer-versus-float, missing/null/zero and frozen values. Canonical Unicode-key sorting and integer hashes are compared with Python; float canonicalization explicitly fails in this probe and remains TS-03 parity work.

## Alternatives and limitations

Date.now alone cannot supply a suspend-aware boot domain; hrtime alone does not establish persistent cross-process/reboot semantics. Do not derive boot identity from adjustable wall time. Unavailable identities stay unavailable and timing falls back with degraded evidence, never invented precision. No disk schema bump is made by this experiment.

## Recovery and exit

Native CI establishes API binding and Python equivalence, while injected observations establish failure paths. Physical suspend/reboot remains unverified. Keep this decision OPEN if that missing evidence prevents closing the original D02 gate; do not label simulation as physical acceptance.
