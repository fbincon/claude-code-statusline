# D01 — Runtime, distribution and layout

**English** | [简体中文](D01.zh-CN.md)

State: **OPEN**. Date: 2026-10-12 (Asia/Shanghai).

Evidence and stage status:  [TS-02](README.md)。

## Direction

Node 24.21.0 is the pinned candidate and minimum tested version; npm 11.19.0 is the local package manager, TypeScript 5.9.3 compiles ESM and Node's test runner executes probes. The package is private, version 0.0.0, and cannot be mistaken for the production application.

## Interface and behavior

Target Linux x64/WSL Linux, Windows x64 (including x64 emulation on ARM), and macOS 14+ Intel/Apple Silicon. The maintainer approved retirement of Windows x86 for the future TS major release; existing Python releases remain available without a new maintenance commitment. Native Windows ARM and new Linux architectures are not added implicitly. Node's OS/libc requirements must appear in the future installation guide.

## Validation

Use a future private npm workspace with packages/core, packages/platform, packages/cli and packages/tui. Keep existing Mods independently validated; shared pure modules are packaged into their supported module roots. Platform adapters and editor resources must not enter the eager renderer import graph. TS-02 records this layout but creates no production scaffold.

## Alternatives and limitations

Node 22 would prolong x86 support with a shorter support window. Bun and SEA would add a separate runtime or asset/native-addon packaging gate. Neither is required for the approved npm-first distribution. Koffi 3.3.3 and lossless-json 4.3.1 are MIT; the copied Unicode resources retain the repository's Unicode license.

## Recovery and exit

Close only after the required automated native/install matrix and an explicit disposition for uncovered targets. A runner label is not proof of Windows 10 desktop, WSL or macOS 14 Intel support. Roll back by retaining the Python installation; no user installation changes during TS-02.
