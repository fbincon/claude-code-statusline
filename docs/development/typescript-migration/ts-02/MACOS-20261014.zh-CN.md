## 交给 Linux 的边界

私有证据包、逐文件校验、固定源码／生成 JS 快照、双语摘要、Git bundle 与原 Windows 包位于
`dist/handoff/ts02-macos-20261014/`。先运行其中 `verify_transfer.py`，再导入 Git 提交；完整压缩包和 SHA-256 见
[macOS 交接清单](handoff.macos-20261014.json)及外部 `TRANSFER.json`。校验器只读文件，不执行归档里的原机路径或辅助脚本。

共享改动仅影响 POSIX 宿主探针退出路径；Linux／WSL 应补跑该回归及两个固定宿主 argv 检查。
Windows 生产实现和 v2 身份未改，但旧 Windows 结果仍只证明其原版本；Linux 必须运行整合后的完整原生／安装、Python、Mod CI 矩阵。

仍需处置：macOS 睡眠／恢复、实体 macOS 14 Intel、Windows 10、其他平台物理／GUI（包括 Linux GNOME／popup），
以及精确 2.1.296 声明和修复后完整矩阵。维护者未批准的支持范围变更不得由本机结果代替。
**D01／D02／D04 保持 OPEN，TS-02 保持 VALIDATING，TS-03 保持 NOT_STARTED**；由 Linux 汇总必要证据或明确支持范围决定后处理。
