# D04 — External terminal and launching

**English** | [简体中文](D04.zh-CN.md)

State: **DECIDED**. Date: 2026-10-14 (Asia/Shanghai).

Evidence and stage status: [TS-02](README.md).

## Direction

Use Node raw TTY input plus bounded VT output and the existing Unicode 18.0 grapheme/cell kernel. Avoid choosing a replacement widget framework before the input, restoration and launcher boundaries work.

## Interface and behavior

POSIX native PTYs exercise Ctrl+S, Ctrl+C, arrows, Chinese/combining/emoji input, resize, SIGTERM and full terminal-attribute restoration at five working sizes and 32×12 guidance. tmux starts the actual helper and returns a nonce-bound result. A Windows CREATE_NEW_CONSOLE probe opens genuine console input/output handles and toggles/restores raw mode.

## Validation

Launcher requests bind a nonce, expiry and parent process-start identity. Tests reject wrong/replayed/expired requests and PID-token reuse. GNOME argv and macOS .command generation preserve quoting and Unicode paths. Generated launch commands do not count as actual GUI execution.

## Alternatives and limitations

The [2026-10-12 Windows 11 x64 follow-up](validation.windows-local-20261012.json)
passes human-operated arrow keys, CJK/combining/emoji input, small/normal window
sizes, Ctrl+S/Ctrl+C, console-mode restoration after logging failure, and visual
confirmation. Three operation records are verified cumulatively against the same
probe sources and original events; the two incomplete attempts are retained.

The Windows checkpoint retained GNOME/Terminal.app, popup and other human gates;
the later observations and explicit deferrals are recorded below. Windows skips of
POSIX PTYs are explicit, not passed cases. SIGKILL cannot run terminal cleanup;
do not promise it can.

## Recovery and exit

The design satisfies the amended TS-02 platform gate; release-before checks remain. Full four-page editing, Apply/Save behavior and integration recovery remain TS-04. Existing macOS Client input limitations remain documented.

## Decision closure, 2026-10-14

Select Node raw TTY/VT and the shared Unicode kernel. Human Windows console, macOS Terminal.app/popup and Linux GNOME/popup evidence is distinct from automated PTY/signal tests. Linux direct 11/11 and popup repeat 12/12 gates pass; the missing-parent-confirmation failure is preserved, and Wayland focus is operator confirmation. WSL desktop and remaining target-specific human coverage are explicitly deferred until before release.

See [Linux integration, CI and release-before checklist](LINUX-20261014.md) and
[receipt summary](validation.linux-local-20261014.json). This stage decision does
not establish full migration acceptance; recovery retains the Python installation
and compatible backups described above.
