## 方向

在候选测量前固定维护者批准的策略。提交 3c448b8 在首版探针实现前记录 policy.json。预算原为迁移验收规则，现保留为 PERF-01 目标，不承诺 TypeScript 更快或更省内存。

## 接口与行为

对每个匹配案例，以 Python 指标 B 为基准：完整命令 P50 ≤ B + max(0.10B, 5 ms)，P95 ≤ B + max(0.15B, 10 ms)；进程内操作采用相同比例，毫秒容差分别为 0.1／0.2。进程峰值 RSS ≤ B + 32 MiB。保留未来完整候选的 100／10,000／100,000 行 transcript、0／8／32 Agent 和 32／1,000／10,000 Git 文件场景。

## 验证

同机、固定源码／测试器／样例，每轮每侧 50 次，三轮交替，区分 Python 冷／热字节码。准备和预热不计时；两侧渲染均启动新进程，stdout 必须匹配固定案例。RSS 使用进程峰值驻留／工作集计数，不用 V8 堆大小替代。运行时启动／原生加载控制项单列为描述性测量。

## 替代方案与限制

三轮都超预算且中位增量超过基线轮间范围时判失败。混合／噪声超标为未定，不算通过；至多追加一整组三轮，保留两组结果。不能根据结果放宽预算。有意更改测试器须记录新来源并单独测量，不能替换原始结果。

## 恢复及出口
