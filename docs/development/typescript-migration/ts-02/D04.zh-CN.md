# D04 — 外部终端与启动

[English](D04.md) | **简体中文**

状态: **OPEN**. 日期: 2026-10-12 (Asia/Shanghai).

证据和阶段状态见 [TS-02](README.zh-CN.md)。

## 方向

候选方案为 Node raw TTY 输入、有边界的 VT 输出，以及既有 Unicode 18.0 字素／单元格内核。先证明输入、恢复和启动器边界，再决定是否需要额外控件框架。

## 接口与行为

POSIX 原生 PTY 在五种工作尺寸和 32×12 提示尺寸验证 Ctrl+S、Ctrl+C、方向键、中文／组合字符／emoji、resize、SIGTERM 以及终端属性完整恢复。tmux 启动真实辅助进程并返回 nonce 绑定结果。Windows CREATE_NEW_CONSOLE 探针打开真实控制台输入／输出句柄，开启并恢复 raw 模式。

## 验证

启动请求绑定 nonce、有效期和父进程启动身份；测试拒绝错误、重复、过期请求及 PID 身份复用。GNOME 参数与 macOS .command 生成保留引用和 Unicode 路径。生成命令不等于实际 GUI 执行。

## 替代方案与限制

2026-10-12 的[本机 Windows 11 x64 验收](validation.windows-local-20261012.json)已通过真人操作的
方向键、中文／组合字符／emoji、大小窗口切换、Ctrl+S／Ctrl+C、日志失败后的模式恢复及视觉确认。
三个操作记录按相同探针源码与原始事件合并核验，保留前两次不完整记录；不将其改写为单次全部通过。

保持 D04 OPEN：GNOME／Terminal.app GUI 握手及焦点、tmux popup 行为及其他目标的人工验收仍保留。
Windows 对 POSIX PTY 的跳过明确记录，不算通过；SIGKILL 无法执行清理，不能承诺可恢复。
