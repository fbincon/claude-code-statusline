# D06 — Performance acceptance policy

**English** | [简体中文](D06.zh-CN.md)

State: **DECIDED**. Date: 2026-10-12 (Asia/Shanghai).

Evidence and stage status: [TS-02](README.md).

## Direction

DECIDED: freeze the maintainer-approved policy before candidate measurements. Commit 3c448b8 records policy.json before the first probe implementation. The budget is a migration acceptance rule, not a promise that TypeScript is faster or smaller.

## Interface and behavior

For each matched case with Python metric B: command P50 ≤ B + max(0.10B, 5 ms), command P95 ≤ B + max(0.15B, 10 ms); in-process floors are 0.1/0.2 ms with the same ratios. Peak process RSS ≤ B + 32 MiB. Preserve the 100/10,000/100,000 transcript, 0/8/32 Agent and 32/1,000/10,000 Git-file profiles for the future full candidate.

## Validation

Same machine, fixed source/harness/fixtures, 50 samples per side per round, three alternating rounds, separate cold/warm Python bytecode. Setup and priming are outside measurements. Both renderers start in fresh processes; stdout must match the frozen case. RSS comes from process peak resident/working-set counters, not V8 heap size. Runtime startup/native loading controls are separate descriptive measurements.

## Alternatives and limitations

Fail when all three rounds exceed budget and the median increase exceeds the baseline between-round range. A mixed/noisy excess is inconclusive, not pass; permit at most one additional complete three-round set and retain both. No post-result budget relaxation. An intentional harness change requires new provenance and an explicitly separated measurement, not replacing raw results.

## Recovery and exit

TS-02 measures only the real minimal model render profile, not the full backend. Other command, collector, Agent and in-process cases remain unmeasured until migration supplies equivalent candidates. Keep near-limit RSS visible in the result summary. TS-05 must run the complete mapped matrix before release acceptance.

For an inconclusive result only, invoke `benchmark -- NEW_DIRECTORY --repeat-of REPORT.json`. The parent report must match the measured graph and policy, contain no failed metric, and have no previous repeat. An exclusive reservation beside the canonical parent path prevents reusing the same parent for another attempt. Keep the reservation and both reports.
