# D05 — 入口退役、安装与恢复

[English](D05.md) | **简体中文**

状态: **OPEN**. 日期: 2026-10-12 (Asia/Shanghai).

证据和阶段状态见 [TS-02](README.zh-CN.md)。

## 方向

维护者已批准未来主版本采用 npm 优先分发，保留 CLI 能力并退役 Python import、python -m、pipx 安装与旧 .exe 名称。历史 Python 包保留作回滚／32 位路径；TS-02 不卸载或修改它们。

## 接口与行为

内部使用 LaunchSpec { executable, args }，绑定绝对 Node 可执行文件与已安装 JS 入口；旧单 executable 对应空 args。既有 executable 环境变量覆盖整个绑定，避免给旧覆盖值错误追加新 JS 前缀。探测 backendArgs 字符串数组（宿主 manifest 为 type:string、multiple:true）。

## 验证

在源码目录外安装 tarball，禁用生命周期脚本并从 PATH 排除 Python／编译器目录，再加载原生依赖、读取打包样例并比较渲染字节。验证 POSIX npm bin、PowerShell .cmd 与 Git Bash npm shim；PowerShell 使用 .cmd 可避免修改脚本执行策略。

## 替代方案与限制

两个 Mod 的临时副本添加 argv 前缀，通过真实宿主进程 API 调用 Node 收据后端。免费本机检查使用虚构密钥和不可达的本地 API，只发送本地 slash 命令；它证明调用链，不证明后端协议／UI parity。生产 Mod 源码和协议版本保持不变。

## 恢复及出口

升级策略：检测 pipx／PATH 冲突，校验所有权，保留不可变的兼容备份，在锁内只重绑自有设置／资源，保留无关设置与明确关闭项，失败时恢复原始字节。新安装验证前保留旧 Python 环境。完整 install／doctor／uninstall 与多文件中断恢复仍是 TS-04 门槛，隔离样例事务只是原型。
