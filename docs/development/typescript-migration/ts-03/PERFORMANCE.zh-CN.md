工具测量十项独立进程命令和 22 项进程内负载，每侧每轮 50 次、三轮交替，Python 冷／热字节码分别测量，共 **19,200 个正式样本**。八项启动／原生加载控制另有 400 个描述性样本。三组规模为 100／10,000／100,000 行 transcript、0／8／32 个 Agent、32／1,000／10,000 个 Git 文件。准备工作不计入时间；RSS 使用实际工作进程峰值，不累加子进程峰值。每个样本的输出及采集次数检查通过，测量后的源码与夹具哈希检查也通过。

既定 [D06 策略](../ts-02/D06.zh-CN.md)未变：命令 P50／P95 在 Python 基线上增加 10%／15% 或 5／10 ms 中的较大值；进程内固定余量为 0.1／0.2 ms；RSS 增量为 32 MiB。三轮全部超限且中位增量超过基线轮间波动才判失败；混合或噪声超限记为不确定。本轮含明确失败，不能使用同源码噪声复测例外，实际未复测。
