# 变更日志模板与格式检查

[English](changelog-template-maintenance.md) | **简体中文**

本次 2026-11-14 文档与检查维护在发布指南中加入项目特定的变更日志模板，记录适用范围，并新增带基线规则和未来条目规则的 `checkChangelog`。同时统一中文变更日志标题与术语，修正发布索引措辞，并从 CONTRIBUTING 与 AGENTS 链接模板。产品行为、命令、公开接口、存储格式及已发布版本均不变；不创建版本、tag、Release 或 npm 发布。

## 变更

| 领域 | 结果 |
| --- | --- |
| 模板 | `docs/RELEASING.zh-CN.md#变更日志模板` 及其英文版定义标题、3–7 条摘要、兼容性条目、固定页脚、证据限制和 issue 引用格式。 |
| 基线检查 | `checkChangelog` 检查单一 H1、版本标题与日期、倒序、重复版本、顶部版本与 `release.ts` 一致、中英版本／日期／bullet 数一致，以及 v3.0.0 起的发布说明链接。 |
| 未来条目检查 | `3.16.4` 及以后还要求 em dash 标题、与标题日期一致的发布行、`发布说明`／`Release notes` 为末条 bullet 的首个链接，以及句末标点。 |
| 测试 | 新增 10 个用例，覆盖历史／现行夹具、重复与乱序版本、日期顺序、顶部版本不匹配、缺少发布链接、中英 bullet 漂移，以及三条未来严格规则。 |
| 文档 | CONTRIBUTING 与 AGENTS 链接模板；中文 H1 使用 `变更日志`；发布索引改用“简明版本摘要”／“concise version summaries”。 |
| 历史 | 更早的变更日志条目保持冻结；模板从 `3.16.4` 起对未来条目生效。 |
