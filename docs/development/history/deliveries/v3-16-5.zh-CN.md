# v3.16.5 宿主兼容性与恢复交付

[English](v3-16-5.md) | **简体中文**

本次 2026-11-21 功能交付将稳定版 3.16.5 发布至 npm 与 GitHub，并将源码和发布标签同步至 Gitee。本版本修复内置插件集成、Native 控件和影响规划。

## 变更

| 范围 | 结果 |
| --- | --- |
| Claude 插件集成 | 按本地目录验证两个自有插件，对市场执行严格验证。重试时刷新 Claude 旧缓存，允许 3.16.5 管理器完成已中断的 3.16.4 事务。[Issue #292](https://github.com/fbincon/claude-code-statusline/issues/292) |
| Native 控件 | 按终端列宽分配标题、间距、按钮装饰和翻译文案。窄窗格使用紧凑控件，重试时保留草稿。[Issue #287](https://github.com/fbincon/claude-code-statusline/issues/287) |
| 影响规划 | 完成包比较后再调度分范围任务。运行时包有差异时进入产品路线，等价包仍须满足维护任务的预算。[Issue #288](https://github.com/fbincon/claude-code-statusline/issues/288) |
