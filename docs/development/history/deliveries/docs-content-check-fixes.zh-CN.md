## 边界与交付

静态读取器只识别已登记的文档和源码形式，不解释任意说明文字或 shell 程序。源码结构变化时需要明确更新读取器，不回退到旧值。检查不执行所解析的安装测试或 Mod hook，不代表已安装产品、物理编辑器、终端、实时服务或付费模型验收。既有六项 issue #96 缺口仍未验证。

本次维护不创建产品版本、tag、Release 或 npm 发布。GitHub 仍是主仓库；最终 head 验收及 main 晋级核验通过后，以显式 refspec 将已验证 main 提交同步到 Gitee，并核对远端 SHA。
