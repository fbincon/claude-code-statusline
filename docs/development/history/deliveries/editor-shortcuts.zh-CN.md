# 自定义编辑器快捷键

[English](editor-shortcuts.md) | **简体中文**

本次 2026-11-27 功能交付增加 Claude Code 内置编辑器与外部终端编辑器共享的快捷键设置。可在「设置 → 快捷键」暂存改绑，在保存前恢复单项或全部预设。本次不创建产品版本、标签、Release 或 npm 发布。[PR #301](https://github.com/fbincon/claude-code-statusline/pull/301)

## 变更

| 范围 | 结果 |
| --- | --- |
| 编辑器命令 | 共享动作表覆盖主编辑器及其子面板，按两个编辑器的使用场景检查冲突。固定的文字编辑、导航和故障恢复键仍可使用，命令提示随当前绑定更新。 |
| 共享偏好 | 两端通过编辑器协议 33 使用 schema 1 的 `statusline-shortcuts.json`。保存后当前端应用暂存的绑定，另一端重开或选择「读取已保存」即可读取。修订检查保护并发修改。 |
| 文档和语言 | 中英文指南同步说明录入、恢复、解决冲突和重新读取。新增界面文案已完成两种 A 类语言验收，其余语言包的新文案使用既有开发回退。 |
