## 内容与归属

- 快速开始紧随目录，采用安装包 → setup 预演 → setup → 重启 Claude → doctor 的流程，明确平台前提与 Windows `.cmd` 入口。详细安装、首次设置事务和恢复留在对应指南。
- 归属排查段仅将预演用于 preset/import；apply/set 不支持 `--dry-run`。
- 新编辑器专题集中维护打开条件、键位、页面／底部提示／分页、输入、查找、格式、导入审阅、预览及保存，区分接受到草稿、保存显示、核对未知保存结果及独立 Claude Apply。
- USER_GUIDE 保留常用操作与排障，Unicode 规则由组件与布局维护。Native 开发页保留实现、原始观察与验收记录，用户操作章节改为指向编辑器专题。
- 两种语言的文档中心和相关专题均提供新指南入口；原路径的标题及显式锚点保留，并指向相关说明。
