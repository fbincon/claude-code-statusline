# 发布说明索引、导航与模板

[English](docs-releases-organization.md) | **简体中文**

本次 2026-11-13 维护将 `docs/releases` 整理为一个带注释的索引、统一的语言入口和单一现行发布说明模板。产品行为、公共接口、存储格式及已发布的 GitHub／Gitee Release 正文均未改变。本次不创建版本、标签、Release 或 npm 发布。

## 变更

| 轮次 | 结果 |
| --- | --- |
| 索引与语言入口 | 重建两个索引：当前稳定版提示、取自 CHANGELOG 的日期、Latest／Stable／Preview 状态、一行摘要和可点击语言链接。为 38 篇历史页增加顶部语言导航及可见的 `english`／`简体中文` 锚点；v3.9.0 保留可见中文标题。为 7 篇中文摘要加标识，并补充最小状态说明。 |
| 现行页模板 | 将 v3.10.0–v3.16.3 中英配对统一为固定块顺序：日期与交付记录、摘要、变更 bullets、兼容性／安装、平台、#96 与已知限制、决策／流程链接。源 SHA、成本、请求／回放及验收脚本细节移入既有交付记录；修复三处翻译偏差。 |
| 治理 | 在 RELEASING（中英）加入发布说明模板，在 CONTRIBUTING 和 AGENTS 加指引，在 `tools/checks/docs.ts` 新增 `checkReleases` 及十四项测试。 |
