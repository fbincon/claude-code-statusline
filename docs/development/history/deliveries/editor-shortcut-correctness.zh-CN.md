# 共享编辑器快捷键修复

[English](editor-shortcut-correctness.md) | **简体中文**

本次 2026-11-28 维护交付使两种编辑器的提示与实际按键一致，并根据事务状态确认快捷键保存。变更经 [PR #306](https://github.com/fbincon/claude-code-statusline/pull/306) 按普通维护流程交付。本次不创建产品版本、标签或 Release，也不发布 npm 包。

## 变更

| 范围 | 结果 |
| --- | --- |
| 当前按键 | 内置编辑器在加载预设及 Claude 偏好待处理时显示当前键。两端颜色面板显示应用与返回键。外部编辑器录制时尝试 Ctrl+C 会保留两个草稿。 |
| 翻页与兼容 | 来源的已保存检查详情使用方向键翻页。旧的来源刷新方向键恢复为 R，旧的仅事件刷新 Enter 恢复为 E。兼容读取保留可用改绑，并提示跳过的键。 |
| 保存回读 | 快捷键读取核对既有安装锁和文件事务。尚未确认时，已打开的面板保留原绑定和当前修改。事务已提交但仍有日志时，可以在核验后确认。 |
| 语言 | 十二种语言各有 2,468 条已接受文案。中英文编辑器指南、CLI 参考及开发契约同步说明当前行为。 |
