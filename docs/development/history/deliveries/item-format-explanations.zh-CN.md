# 两种编辑器的项目格式说明

[English](item-format-explanations.md) | **简体中文**

本次 2026-11-28 功能交付重排内置和外部编辑器中 Ctrl+E 的两个只读说明页。交付内容为 GitHub 和 Gitee 上的源码与文档。工程候选包用于隔离验收。

## 变更

| 范围 | 结果 |
| --- | --- |
| 配置与示例说明 | 先展示选中组件的参考示例，再说明草稿状态、当前场景和列宽、逐实例结果及本机已知条件。下方预览使用当前草稿。 |
| 来源与启用条件 | 按来源与范围、显示条件、可能的原因、字段与版本、设置命令分组。各组按组件的实际情况显示，命令保留原文。 |
| 布局与翻页 | 两端共用按字素换行的说明行，标题加粗，示例缩进。内置编辑器为章节间距预留一行，滚动按实际可见行数计算，Ctrl+G 返回原选中位置。 |
