# 两种编辑器的原位输入光标

[English](editor-input-caret.md) | **简体中文**

本次 2026-11-28 功能交付让内置与外部编辑器的光标在输入字段中移动时保持正文列位置。交付内容为 GitHub 和 Gitee 上的源码与文档。工程候选包用于隔离验收。

## 变更

| 范围 | 结果 |
| --- | --- |
| 光标与视口 | 光标在下一个完整字素簇的原有单元格上反显。空字段、值末尾、视口容不下下一个字素簇时，反显一格空白。 |
| 字段与表单 | 两种编辑器共用光标范围。本地化标签为活动输入留出空间，只有获得焦点的可编辑字段显示光标。 |
