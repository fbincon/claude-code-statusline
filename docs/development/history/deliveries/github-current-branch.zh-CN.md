# GitHub 来源跟随当前分支

[English](github-current-branch.md) | **简体中文**

本次 2026-11-19 的功能交付让同一个 GitHub 来源及其绑定能随工作树切换分支，读取对应的 PR 和 CI。本次不创建产品版本、标签或 Release，也不发布 npm。 [Issue #227](https://github.com/fbincon/claude-code-statusline/issues/227)

## 变更

| 领域 | 结果 |
| --- | --- |
| 分支选择 | 新来源默认跟随当前检出。在来源定义中使用 `branch: null`，或将编辑器的「PR 源分支」留空。填写分支名可固定到该 PR 源分支。 |
| 固定分支诊断 | 固定来源在首次刷新前就能报告分支不符，并显示所配置的分支。`source diagnose` 返回 `branch_mismatch` 及配置分支和当前分支的名称。 |
| 刷新身份 | 工作进程在已审核的仓库中校验 PR 的准确源分支及提交。任务和观测按检出身份隔离。刷新期间本地分支或 HEAD 改变时，取消过时任务并保留原观测和该身份的调度状态。 |
| 兼容性 | 首次保存跟随来源时将来源注册表升级至 v4。软件包审核按注册表读取范围拦截不兼容的降级。两个编辑器使用协议 v32。已有分支名继续按固定分支解释。 |
