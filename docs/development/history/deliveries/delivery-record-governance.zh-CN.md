# 交付记录模板与检查

[English](delivery-record-governance.md) | **简体中文**

本次 2026-11-14 的文档与检查维护在开发历史索引中加入交付记录模板、带边界的结构检查，以及自 3.16.4 起变更日志条目必须包含交付记录页脚的规则。同时从发布指南、贡献指南和仓库代理指南链接该模板。产品行为、命令、公开接口、存储格式及已发布版本均不变；不创建版本、tag、Release 或 npm 发布。

## 变更

| 领域 | 结果 |
| --- | --- |
| 模板 | `docs/development/history/README.zh-CN.md#交付记录模板` 及英文版定义带日期的引言、必需标题结构、可选章节、`#final-release` 规则及 2026-11-14 边界。 |
| 检查 | `checkDeliveryRecords` 校验边界记录、双语文引言日期、标题顺序及历史索引登记；更早或无日期的记录继续豁免。 |
| 变更日志 | `checkChangelog` 现在要求未来条目的页脚包含带 `#final-release` 的交付记录链接，同时保持发布说明为第一个链接。 |
| 文档 | 发布指南、贡献指南和 `AGENTS.md` 链接该模板。 |
| 历史 | 既有交付记录保持冻结；模板从 2026-11-14 起前瞻性生效。 |
