# 终端设置快捷键

[English](terminal-settings-shortcuts.md) | **简体中文**

本次 2026-11-27 交付将终端设置页的操作统一到编辑器的草稿流程。没有创建产品版本、标签或 Release，也没有发布 npm 包。[PR #304](https://github.com/fbincon/claude-code-statusline/pull/304)

## 变更

| 范围 | 结果 |
| --- | --- |
| 操作设置项 | Enter 切换开关、推进选项，并打开预填当前值的数值输入框。 |
| 刷新间隔 | 在输入框中按 Enter 将秒数或 `event` 确认到草稿。当前保存键提交草稿并退出。仅事件刷新预设用 E，可改绑到其他可用键。快捷键录入和保存校验在刷新行保留 Enter。 |
| 快捷键提示 | 设置页提示当前选中行的操作和仅事件刷新的实际绑定。快捷键面板显示各编辑器的保存键。 |
