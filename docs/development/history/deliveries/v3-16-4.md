The [original OIDC job](https://github.com/fbincon/claude-code-statusline/actions/runs/44858270452/attempts/1) uploaded 3.16.4 and generated [Sigstore provenance](https://search.sigstore.dev/?logIndex=4030974639). Its registry visibility check timed out. The version and `latest` subsequently became visible while the tarball still returned HTTP 404. Once the download converged, the registry bytes matched the CI tarball, with SHA-512 integrity `sha512-vawjoe1c9c5+pBmQsElnNcMVgddFdT6Rh6Mp44weUlm/wPbbv+bZJ6iDwD/ppXYNrvRKMCuwK3VHkwehpq+mGA==`. `latest` pointed to 3.16.4 and `beta` remained 3.0.0-beta.1. The [verification retry](https://github.com/fbincon/claude-code-statusline/actions/runs/44858270452/attempts/2) passed with `already-published` and made no new upload.

The [immutable GitHub Release](https://github.com/fbincon/claude-code-statusline/releases/tag/v3.16.4) became the latest stable release at 03:06:09 UTC. On Linux, separate empty-cache sessions from the public npm registry reached the first review and setup for both `3.16.4` and `latest`. Esc exited each session before any settings write.

The [release-triggered download run](https://github.com/fbincon/claude-code-statusline/actions/runs/44859364288) failed because the test shared a configuration directory with `config show`, which had already created runtime state. Windows also compared a short temporary path with its expanded npm prefix. [PR #290](https://github.com/fbincon/claude-code-statusline/pull/290) isolated the dry-run directory and canonicalized the temporary root. It merged as `9181f393822b93abdc9406f0741314bfd23610de`.

The [read-only public verification](https://github.com/fbincon/claude-code-statusline/actions/runs/44859664205) used verifier `5cbab8917dad45749abec34c4901ca492b90e054` and the original v3.16.4 tag source. The six download jobs passed on Linux x64, Windows x64 and macOS arm64 with Node 22.23.5 and 24.22.3. Every job matched the anonymous GitHub assets and npm tarball, installed both selectors and checked each first-entry review with an empty cache and lifecycle scripts enabled. The [signature job](https://github.com/fbincon/claude-code-statusline/actions/runs/44859664205/job/136709896662) matched the package provenance to the original OIDC invocation and verified the six signed public dependencies and four bundled workspace manifests.

The [Gitee Release](https://gitee.com/fbincon/claude-code-statusline/releases/tag/v3.16.4) used the same annotated tag and a verified mirror of main at `9181f393822b93abdc9406f0741314bfd23610de`. Its bilingual notes link the original GitHub publication and Gitee attachments. All four attachments were downloaded anonymously and matched the original files byte for byte, including the sizes and SHA-256 digests above.
