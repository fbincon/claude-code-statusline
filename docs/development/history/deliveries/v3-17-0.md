# v3.17.0 AgentRow and editor delivery

**English** | [简体中文](v3-17-0.zh-CN.md)

This 2026-11-28 feature delivery published stable 3.17.0 on npm, GitHub and Gitee. It combines the updated editor layout and longer Claude-launched external sessions with the AgentRow, editor shortcut and runtime changes merged since 3.16.5.

## Changes

| Area | Result |
| --- | --- |
| Subagent rows | AgentRow and the legacy callback share the configured subagent renderer. Installation selects the supported route and preserves ownership during handover and recovery. [AgentRow delivery](agent-row-compatibility.md) · [PR #308](https://github.com/fbincon/claude-code-statusline/pull/308) |
| Editor navigation and examples | Layout precedes Settings in both editors. A selected external editor component shows its example after its description. The Claude Code external launcher allows up to 30 minutes for editing. |
| Shortcuts | The editors share preferences, use consistent component-list controls and verify shortcut writes before showing them as saved. [Shortcut delivery](editor-shortcuts.md) · [List controls](editor-list-shortcuts.md) · [Settings activation](terminal-settings-shortcuts.md) · [Correctness](editor-shortcut-correctness.md) |
| External refresh | The external editor follows visible task reports, source results and package progress, and rereads the profile and source lists when relevant. [External refresh delivery](external-editor-live-refresh.md) |
| Runtime state | Prompt ownership keeps timing, status and tool activity attached to the current task while observation updates arrive. [Runtime delivery](runtime-prompt-ownership.md) |
| Gitee release assets | The mirror attaches the manifest and checksums and links to the version-pinned GitHub package and source archive. [PR #298](https://github.com/fbincon/claude-code-statusline/pull/298) |
