## 定向内容检查

[开发指南](../../README.zh-CN.md#documentation-content-checks)说明本地入口。测试从实际 Markdown 读取带标记示例，以生产解析器验证来源／显示 JSON，对照 core 检查指标数量／ID、语言、预设、显示 schema 与编辑器协议。无效／缺失示例、重复字段、非有限数、数量／ID 变化和过时接口声明均有负例。

CLI 流程使用含空格和中文的隔离目录，执行文档中的注册、审阅、启用、绑定、刷新和诊断参数，渲染结果，并在拒绝时断言实际状态／原因及文件字节／模式保留。Node 实际输出 `42`；GitHub 响应通过既有提供者 runner 注入，不使用凭据或网络。结构案例覆盖两份指南、准确接受、旧修订、Q／Escape 取消、接受及撤销。

[页面登记](../../../../tools/checks/impact-documentation.ts)在 `docs` 之外选择现有 `checks` 测试族，保留三平台工具执行。登记进入不可变政策摘要，覆盖删除／重命名。早于本测试的历史源码保留原有义务，既有 PR #181 回归仍通过。`docs:check` 保持轻量。
