# 双编辑器快捷键可靠性

[English](editor-shortcut-reliability.md) | **简体中文**

本次 2026-11-27 维护修复内置与外部编辑器的按键可达性、恢复和导航。两端通过编辑器协议 33 共享 schema 1 快捷键偏好。本次不创建产品版本、标签、Release 或 npm 发布。[快捷键设置](../../../EDITORS.zh-CN.md#customize-keyboard-shortcuts)

## 变更

| 范围 | 结果 |
| --- | --- |
| 宿主保留键 | Ctrl+D、Ctrl+X 和 Ctrl+Z 可用于外部编辑器专属动作。内置编辑器用 D、X 和 Ctrl+/ 执行复制、移除和撤销。 |
| 偏好兼容 | 读取原本有效的偏好时，保留可用绑定并提示跳过的键。显式清理沿用修订检查、备份和事务。相同警告也会出现在 `doctor` 的输出里。 |
| 外部控制 | Esc 和自定义关闭键都进入带草稿保护的退出流程。当前搜索键进入文本框，已绑定的字符也可在其中搜索。 |
| 快捷键面板 | 两端支持按名称或 ID 筛选动作，翻页按实际可见行数计算。已打开的面板可在 32×12 下使用。中英文文案按语言流程完成验收。 |
