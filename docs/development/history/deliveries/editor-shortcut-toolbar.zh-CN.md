# 快捷键操作区与固定详情

[English](editor-shortcut-toolbar.md) | **简体中文**

本次 2026-11-28 功能交付优化内置和外部编辑器的快捷键面板。交付范围为 GitHub 和 Gitee 上的源码及文档。工程候选包用于隔离验证。

## 变更

| 领域 | 结果 |
| --- | --- |
| 按钮与焦点 | 保存快捷键、恢复全部预设和读取已保存位于列表上方。32×12 使用短标签同时显示三个按钮。Tab 提示写明焦点去向，当前按钮使用焦点标记和主题高亮。 |
| 列表与详情 | 筛选和切换焦点按 ID 保留选中项。当前键和预设键固定在下沿。两端绘制和键盘翻页共用行预算。 |
| 按键提示 | 当前提示能容纳时用一行，窄屏最多两行。恢复指引可以使用原本为键位详情预留的空间。 |
