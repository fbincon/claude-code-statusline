# v3.17.0 AgentRow 与编辑器交付

[English](v3-17-0.md) | **简体中文**

本次 2026-11-28 的功能交付为在 npm、GitHub 和 Gitee 发布稳定版 3.17.0 做准备。本版包含编辑器布局与 Claude Code 外部编辑会话时长调整，以及 3.16.5 之后已合并的 AgentRow、编辑器快捷键和运行时改进。

## 变更

| 领域 | 结果 |
| --- | --- |
| 子代理状态行 | AgentRow 与旧版回调共享子代理渲染配置。安装时选择宿主支持的接入方式，并在切换及恢复时保留归属判断。 [AgentRow 交付](agent-row-compatibility.zh-CN.md) · [PR #308](https://github.com/fbincon/claude-code-statusline/pull/308) |
| 编辑器导航与示例 | 两种编辑器的「布局」均位于「设置」之前。外部编辑器在所选组件的说明后展示示例，从 Claude Code 打开时可编辑至多 30 分钟。 |
| 快捷键 | 两种编辑器共享快捷键偏好，统一组件列表操作，并在显示保存成功前确认写入。 [快捷键交付](editor-shortcuts.zh-CN.md) · [列表操作](editor-list-shortcuts.zh-CN.md) · [打开设置项](terminal-settings-shortcuts.zh-CN.md) · [保存与按键修复](editor-shortcut-correctness.zh-CN.md) |
| 外部编辑器刷新 | 外部编辑器跟踪当前显示的任务报告、来源结果和包作业进度，并在相关操作时重读配置方案及来源列表。 [外部刷新交付](external-editor-live-refresh.zh-CN.md) |
| 运行状态 | 在观测更新过程中，按提示词归属将计时、状态和工具活动关联到当前任务。 [运行时交付](runtime-prompt-ownership.zh-CN.md) |
