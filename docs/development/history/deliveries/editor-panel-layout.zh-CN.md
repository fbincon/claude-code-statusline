# 版本与快捷键面板

[English](editor-panel-layout.md) | **简体中文**

本次 2026-11-28 源码交付整理内置和外部编辑器的版本与快捷键面板。交付范围为 GitHub 和 Gitee 的源码及文档。工程候选包用于本地验证。

## 变更

| 领域 | 结果 |
| --- | --- |
| 版本与安装 | 首页采用与设置页相同的分组横线。每个标题占一行，方向键跳过标题。 |
| 快捷键 | 六组动作放入内容框，底部固定操作菜单，按键提示位于框外。宽度达到 80 列时展开为「选项」「当前键」「默认键」。紧凑面板支持 32×12。 |
| 导航 | 翻页计算分隔行所占空间。筛选和缩放时尽量保留选中动作。选中项的详情列出适用编辑器的当前键和默认键。 |
