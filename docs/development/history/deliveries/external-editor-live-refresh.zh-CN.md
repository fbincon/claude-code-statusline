# 外部编辑器刷新

[English](external-editor-live-refresh.md) | **简体中文**

本次 2026-11-27 功能交付覆盖外部终端编辑器中的任务报告、包与来源作业进度，以及列表重读。本次不创建产品版本、标签或 Release，也不发布 npm 包。[PR #305](https://github.com/fbincon/claude-code-statusline/pull/305)

## 变更

| 领域 | 结果 |
| --- | --- |
| 任务报告 | 设置页和独立 `task view` 每 2 秒查看运行中任务，空闲或已完成时每 10 秒查看一次。读取失败后保留上次报告，刷新键可立即读取。原生窗格按需读取。 |
| 包与来源作业 | 可见页面跟踪选中的作业，输入或确认期间暂停自动读取。包执行交接后仍通过原来的控制入口查询，查看来源进度不会重复运行提供程序。 |
| 列表与布局 | 打开、返回或手动重读时更新已保存的方案和来源定义。内嵌任务与版本页面使用通常分配给样例预览的区域。 |
