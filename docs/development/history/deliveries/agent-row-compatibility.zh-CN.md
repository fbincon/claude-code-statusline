# AgentRow 与旧版子代理行兼容

[English](agent-row-compatibility.md) | **简体中文**

本次 2026-11-28 的功能交付新增 Claude Code AgentRow Mod，并继续支持原有的子代理状态栏命令。两种接入共用同一份显示配置。本次不创建产品版本、标签、Release 或 npm 发布。

## 变更

| 领域 | 结果 |
| --- | --- |
| 安装 | `install --subagent-renderer auto\|mod\|legacy` 保存本机偏好。自动模式在 Claude Code 2.1.205–2.1.322 上使用命令，从 2.1.326 起优先使用独立 Mod。2.1.323–2.1.325 显示内置行。[宿主要求](../../../USER_GUIDE.zh-CN.md#运行要求) |
| 渲染 | 两种接入共用 17 种子代理组件、项目方案、颜色及按行顺序适配宽度的规则。Mod 按每行的嵌套层级扣除缩进，在整个面板上统一应用行数上限。[渲染规则](../../rendering.zh-CN.md) |
| 交接与恢复 | 安装时若已有本工具的旧命令，会保留该命令，直至 Mod 在实际会话中验证首批适用行。交接前重新核对归属。`doctor` 分别显示磁盘安装、会话加载和首批行证据。降级软件包时，恢复程序先撤下本工具的子代理行插件，再移交旧版安装器。[软件包管理](../../../PACKAGE_MANAGEMENT.zh-CN.md) |
