# v3.16.5 host compatibility and recovery delivery

**English** | [简体中文](v3-16-5.zh-CN.md)

This 2026-11-21 feature delivery publishes stable 3.16.5 to npm and GitHub and synchronizes the source and release tag to Gitee. It repairs bundled plugin integration, Native controls and impact planning.

## Changes

| Area | Result |
| --- | --- |
| Claude plugin integration | Validate both owned plugins as local directories and validate the marketplace in strict mode. Refresh a stale Claude cache on retry, and allow the 3.16.5 manager to finish an interrupted 3.16.4 transaction. [Issue #292](https://github.com/fbincon/claude-code-statusline/issues/292) |
| Native controls | Budget the title, gaps, button decorations and translated labels in terminal cells. Use compact controls on narrow panes and preserve the draft through Retry. [Issue #287](https://github.com/fbincon/claude-code-statusline/issues/287) |
| Impact planning | Resolve package comparison before scheduling scoped tasks. A runtime package difference selects the product route; an equivalent package still needs to fit the scoped maintenance budgets. [Issue #288](https://github.com/fbincon/claude-code-statusline/issues/288) |
