# 发布物模板与检查

[English](release-artifact-governance.md) | **简体中文**

本次 2026-11-14 的文档与检查维护新增审批决定模板及检出内容校验，扩展 3.16.4 及以后版本的发布说明模板检查，并新增发布索引行与当前稳定版检查。同时从发布数据策略链接审批模板。产品行为、命令、公开接口、存储格式及已发布版本均不变；不创建版本、tag、Release 或 npm 发布。

## 变更

| 领域 | 结果 |
| --- | --- |
| 审批模板 | `docs/RELEASING.zh-CN.md#审批决定模板` 及英文版记录决定 JSON、登记行、v3.0.0 历史路径及六项既有缺口。 |

| 发布说明 | `checkReleases` 对 3.16.4 及以后版本新增 issue #96 链接、Node 22/24 块、交付记录链接、发布指南链接、兼容性说明及摘要要求。 |

| 历史 | 更早发布页、审批 registry 顺序及既有决定保持冻结。 |
