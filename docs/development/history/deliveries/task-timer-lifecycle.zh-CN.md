# 任务计时生命周期修复

[English](task-timer-lifecycle.md) | **简体中文**

本次 2026-11-19 功能交付只修复 [issue #223](https://github.com/fbincon/claude-code-statusline/issues/223) 的任务计时生命周期。不创建产品版本、标签、Release 或 npm 发布。

## 变更

| 范围 | 结果 |
| --- | --- |
| 本地编辑器 | 返回阻止决定前，将匹配的 `/statusline-configure` 回合标记为忽略，不结束上一个人类任务。 |
| Agent 与完成判定 | 区分活跃工作、待交付后台报告和实际交付。读取排队命令附件，对账归属并清理只由旧快照支持的活动。仅在新的、可归属的续跑证据出现时重开已完成任务。 |
| 诊断与存储 | 只读报告等待原因、计数和最近可用的结束证据。保留 schema-1 镜像、lifecycle v4 与公开协议。 |
