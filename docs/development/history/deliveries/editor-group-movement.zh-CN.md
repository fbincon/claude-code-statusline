# 编辑器组件分组移动

[English](editor-group-movement.md) | **简体中文**

本次 2026-11-20 功能交付修复两个编辑器中的组件排序问题，关联 [issue #224](https://github.com/fbincon/claude-code-statusline/issues/224)。交付限于源码和文档，未新增版本、标签、Release 或 npm 发布。

## 变更

| 领域 | 结果 |
| --- | --- |
| 主栏与子代理列表 | 每按一次左／右方向键，选中的组件或整组就与相邻的组件或整组交换。编辑器保留当前选中的成员，分组保留成员顺序和设置。 |
| 主栏显式行 | 相邻两行的两个移动单位互换所在行。每行长度可以随换入的单位调整，行数保持不变。 |
| 草稿校验 | 有效移动只产生一条撤销记录，受影响的对齐关系进入结构审阅。拆开分组的候选显示分组校验提示，留白冲突显示布局校验提示。 |
