## 共同设计约定

- **保持定位：**状态栏负责清楚呈现任务、代理、项目和用量；详情与解释使用既有按需入口。保留真实零值及缺失、过期、部分、不支持等不同状态，不推断没有证据的任务结果。
- **共享实现：**core 保存纯配置、目录、Unicode、布局与解释规则；platform 负责文件、进程和终端；cli 编排服务；tui 与原生 Mod 适配交互。复用既有事务和任务存储。[当前架构](architecture.zh-CN.md)。
- **配置边界：**界面语言立即保存，显示语言和外观随显示 Save 保存，Claude 宿主偏好独立 Apply。预览、导入审阅和方案选择只产生候选草稿。用户级默认、命名方案和项目编辑目标始终可辨认。[方案语义](../PROFILES.zh-CN.md)。
- **兼容：**当前显示 schema 10、编辑器协议 17、runtime 2、lifecycle 4、portable 1、UI preferences 1、方案集合／导出 1 独立演进。先列明新增字段和旧数据解释，再决定具体版本；旧文件读取不静默写回，实际迁移沿用备份和恢复机制。
- **扩展授权：**默认使用宿主输入及本地状态。外部文件源、联网提供方和命令分别启用，按用户配置登记。显示方案可以引用来源，但导入、预设选择和项目绑定不能授予执行或联网能力。
- **范围界限：**先完成选定工作包的具体流程。进度条由用户明确选择，首版不自动切换表示方式。每日预算、时间游标、渐变、跨行对齐、选择性导入／合并、命令自动执行和其他提供方分别决定范围，见[候选边界](#candidate-boundaries)。
- **未来接口：**先写清配置意图、数据流与兼容，再分配未来 schema／协议版本或公开命令名称。复用组件能力目录及生成的编辑器资源；新增选项须贯穿预览、保存／重开、方案选择、导入导出与冲突处理，读取旧配置不会开启新行为。

## GIT-01 Git 调用核查与必要防护

**状态：NOT_STARTED。** 独立维护；静态比较发现防护差异，尚未复现为漏洞。

**问题与目标。** 以字面参数调用 Git，不足以决定 Git 是否会按仓库配置启动其他程序。核实当前采集实际执行的行为，在不改变指标含义、不修改用户仓库的前提下修正已证实缺口。

**范围与流程。** 清点直接 Git 调用及提供方工具间接调用的 Git，核查 fsmonitor、local／worktree 过滤器命令与向上发现裸仓库的行为。在隔离夹具中比较当前行为和拟议调用策略，记录是否需要修改，再实施必要防护。通过明确兼容表保留正常 Git LFS 及其他支持的用户过滤器，不笼统关闭所有 global／system 设置，不放宽 Git 所有权检查。

**数据与模块。** 从 [GitCollector](../../packages/cli/src/runtime/git.ts)、cli 来源上下文／提供方编排及 platform 进程适配开始。受影响入口共用调用策略，解析和指标渲染继续留在 core。诊断明确不可用／被阻止结果，不暴露凭据、不在真实仓库运行测试程序、不改写 `.git/config`。

**接口与兼容。** 保留既有显示项 ID、状态含义和来源身份，不预设需要新用户命令或显示 schema。修正前说明仓库本地／用户级配置、已知过滤器兼容及间接 Git 环境的处理。按选定策略无法采集时保留明确不可用原因，不显示成正常零值或干净状态。

**实施切片。** 清点与隔离复现 → 行为／兼容表 → 必要时实现共享策略及调用点调整 → 回归和诊断说明。认定无需修改时也须保留复现及理由。

**功能验收。** 覆盖仓库控制的 fsmonitor／过滤器、local／worktree 与 global／system 设置、已知过滤器、间接提供方调用、裸仓库及 linked worktree、中文空格路径、调用失败和普通干净／有修改仓库。证明选定策略阻止非预期程序执行、保持支持的指标语义且不修改仓库／用户配置。核查结论与实际修复的缺陷分别记录。

## APPEARANCE-03 上下文与额度图形指标

**状态：NOT_STARTED。** 产品顺序第一项；复用既有观测，不开启采集。

**问题与目标。** 让用户直观看到上下文与额度水平，保留原有数字显示及指标定义。

**范围与流程。** 为主栏 context-used／context-remaining、五小时／周／开销额度百分比，以及子代理 context-used／context-remaining 提供明确选择的短进度条。用户选择适用实例，设置数字或进度条表示及条宽，预览、保存、重开；默认仍为数字。已用／剩余方向有明确标签并遵守既有选择，不表示经过时间、任务完成率或预算预测。时间游标及表示方式自动切换保留为候选。

**数据与模块。** core 使用既有指标和条件显示所依赖的同一原始有效百分比。共享能力目录／编辑字段仅暴露适用选项，cli、外部 TUI 与原生 Mod 消费同一草稿；终端处理复用既有颜色／字符回退。样例保持固定，不读取外部来源。

**接口与兼容。** 规划逐实例的表示／宽度选项，共享 CLI／编辑器校验、持久化、导入审阅和解释；具体字段及 schema／协议变化记录在实施兼容说明中。既有配置、实例 ID 和数字输出保持原义。提供 Unicode／ASCII 进度条、标签及百分比，沿用不可用状态处理，不把缺失值画成零条。适配／裁切包含进度条、标签与数字，保持完整字素。

**实施切片。** 适用组件与表示契约 → 纯格式化及宽度／回退 → 双编辑器／CLI 与配置往返 → 样例及功能说明。

**功能验收。** 覆盖零、满值、小数百分比、已用／剩余方向、异常／缺失／过期观测和子代理独立数值。核对默认数字输出不变、条件使用原始值、重复实例可选不同表示、40／80／120 列、Powerline／spacer、无色、ASCII 及组合 emoji／CJK 标签。保存、重开、复制、项目方案绑定和导入导出在六种界面／输出语言中保留选项。

## COMPOSITION-02 组件分组与联动隐藏

**状态：NOT_STARTED。** 产品顺序第二项，不依赖 APPEARANCE-03。

**问题与目标。** 指标消失后不留下孤立文字／图标，让相关实例可共享 Powerline 色块，同时保持各自数据范围。

**范围与流程。** 用户在同一作用域内选择连续实例，指定一个指标为主实例，选择装饰联动隐藏及可选的共享 Powerline 表示。首版单层分组，不跨显式行边界或 spacer，不嵌套；自动布局将组作为整体。装饰文字跟随主指标最终可见性，包括被布局省略的情形；未知数据沿用主指标原来的可见／不可用行为。其他指标成员保留各自条件，不为主指标补造值。

**数据与模块。** core 负责组引用、校验、可见性解析及普通／Powerline 绘制。共享色块使用主指标背景；成员前景与阈值色继续有效，成员背景选项保留，关闭共享后恢复使用。cli 配置／方案服务保存草稿，两个编辑器共用创建／编辑／解组规则，不增加采集或来源授权。

**接口与兼容。** 增加明确的组与实例引用及共享编辑器／CLI 操作，实施前记录实际传输字段与版本变化。无分组旧配置保持原输出。整组复制生成新身份并重映射引用；删除主指标时解组，保留其他实例及选项。跨行／spacer、非连续或嵌套的非法移动直接拒绝并保留草稿。普通分隔、共享色块与窄行省略／裁切均不留下孤立装饰。便携导出只包含显示分组，不授予来源访问权。

**实施切片。** 分组引用与主指标可见性契约 → 纯校验和布局 → 双编辑器／CLI 与方案／导入操作 → 示例及诊断解释。

**功能验收。** 覆盖主指标因条件、无数据或布局隐藏，未知／部分状态仍可见，成员禁用、多指标及整组隐藏。核对共享／独立色块、颜色重置、自动／显式行、spacer 边界、窄行和独立代理组。复制／删除／解组、拒绝非法排序、保存冲突、导入导出和方案绑定保留身份或明确报告非法引用；六语言预览与实际输出遵循同一规则。

## WORKFLOW-02 可选 GitHub PR／CI 自动刷新

**状态：NOT_STARTED。** 产品顺序第三项，依赖已交付 EXTENSIONS-01、WORKFLOW-01。

**问题与目标。** 活跃会话中保持已启用 GitHub 来源的结果更新，减少重复打开手动刷新的操作。

**范围与流程。** 首版仅 GitHub PR／CI，既有来源默认仍手动。审查并启用源后，用户另行选择自动刷新，审阅周期和活跃项目／会话，再保存本机策略。拟议默认周期沿用该源已配置的有效期，用户可明确调整。活跃会话生命周期事件通过独立任务安排到期刷新，不安装常驻系统服务；缺少受支持生命周期证据的上下文保持手动并说明原因。关联上下文结束后不再发起自动任务。关闭自动刷新会取消其自动工作，保留手动刷新与缓存观测；源停用／编辑／删除继续遵守既有取消及重新审查规则。

**数据与模块。** cli 编排生命周期条件、到期任务及既有来源任务，platform 负责进程取消与上下文身份。core 提供策略／状态／解释，双编辑器及 CLI 提供配置、查看和停止操作。渲染读取已发布观测，不运行 `gh` 或发起网络查询；预览、方案导入和项目绑定不派发任务。命令与 JSON 源不会因此获得自动执行能力。

**接口与兼容。** 自动策略保存在本机来源管理中，与可分享显示方案分开；启用来源不等于启用重复执行。分配传输版本前明确策略修订、活跃上下文关联及任务来源信息。复用源／主机／账号／仓库／分支／HEAD 与认证身份校验，同一源／上下文的并发尝试去重，策略／上下文变化后拒绝迟到结果。只按既有新鲜度／错误标记保留最后有效值，不显示旧身份的结果。保留无 PR／无检查／等待／失败／未知等区别，凭据仍留在 `gh` 认证中。

**实施切片。** 策略与生命周期／停止契约 → 独立任务派发和取消 → 双编辑器／CLI 与诊断 → 隔离生命周期流程及授权范围内的提供方验证。

**功能验收。** 覆盖默认手动、明确开启、首次／到期刷新、并发会话、自动运行期间手动刷新、策略变化、源编辑／停用／删除、会话退出及不支持宿主。仓库／worktree／分支／HEAD／账号切换和迟到结果不能串用身份。覆盖认证／网络失败、无 PR、歧义 PR 和混合检查。未保存就关闭策略编辑不会开启重复执行；导入／预览不查询；停止自动工作后手动刷新仍可用。使用隔离夹具，真实查询须符合后续具体任务的授权范围。

## METRICS-01 会话费用速率

**状态：NOT_STARTED。** 产品顺序第四项，不依赖自动刷新。

**问题与目标。** 用明确的分母将现有会话费用表达为每小时速率，不虚构账单或任务测量。

**范围与流程。** 增加默认未选中的主栏费用速率组件。在实例详情选择会话时间（默认）或 API 累计耗时，预览、保存、重开。使用对应官方会话字段计算 `total_cost_usd / (duration_ms / 3600000)`，明确标出所选分母；API 时间不等于 `task-active-timer`。所选耗时至少为 60,000 毫秒，过短／缺失／异常时速率不可用；充分观测时长上的有效零费用显示零速率。

**数据与模块。** core 校验及格式化既有 `cost.total_cost_usd`、`cost.total_duration_ms`、`cost.total_api_duration_ms`，能力目录、固定样例和解释共用定义。cli 与双编辑器复用实例选择、格式及保存，不增加采集器、模型价格表、transcript 估算或联网来源。

**接口与兼容。** 规划一个新增主栏指标及逐实例分母选项，贯穿 CLI、双编辑器、导入导出与方案。编码前在实施记录确认最终 ID、选项及 schema／协议影响，不改变会话费用、会话／API 耗时或任务计时语义。标签说明它是基于会话字段的折算估算，不是账单或未来开销预测。每日预算与额度节奏留在候选池。

**实施切片。** 定义／分母及可用性契约 → 纯计算、样例和解释 → 双编辑器／CLI 与配置往返 → 指标指南及验收示例。

**功能验收。** 覆盖两种分母、一分钟边界、零费用、缺失／负数／非有限值、零耗时和字段不完整。用已知输入核对公式、独立配置的重复实例及明确的六语言标签。选择、取消、保存／重开、导入导出和项目方案保留所选分母，不开启采集、不改变已有指标。

## SETUP-01 首次使用与配置入口

**已在 v3.5.0 交付 — DONE。** 本节保留历史范围与验收意图；当前使用方式见[首次设置](../SETUP.zh-CN.md)，已验证行为与限制见[交付证据](setup-appearance.zh-CN.md)。

**问题与目标。** 当前已有快速配置，但软件包安装、Claude 接入、检查与打开编辑器是多个步骤。新用户需要从“软件包已可运行”走到“接入结果明确，并知道怎样配置和验证”。已有 `install`、`doctor`、`configure` 和配置 CLI 保持用途。

**范围与流程。** 已交付交互入口 `claude-statusline setup`：检查 Node／Claude／配置目录与既有接入 → 选择保留当前显示或使用场景方案 → 调用共享 Quick setup 预览 → 审阅显示与接入变化 → 明确应用 → 检查已写入资源并显示下一步。新用户以用户默认配置为目标；已有项目绑定时说明目标，默认保留绑定和方案内容。

**数据与模块。** 环境和资源状态来自既有 [doctor](../../packages/cli/src/integration/doctor.ts)、[install](../../packages/cli/src/integration/install.ts) 和 [配置服务](../../packages/cli/src/config/service.ts)。交互复用 [Quick setup](../../packages/core/src/editor/quick-setup.ts)、[外部编辑器](../../packages/cli/src/integration/configure.ts)及其共享草稿；具体落点为 cli/integration、core/editor、tui，原生入口继续使用现有配置编辑能力。

**接口与提交语义。** `setup --dry-run` 已提供只读检查和步骤清单；没有用户选择时不伪造候选配置。非 TTY 的普通入口说明如何使用现有分步命令并以退出码 2 结束。软件包下载、自动升级、字体安装和账号登录不进入首版。显示保存、接入写入和独立宿主操作分别标明提交点，复用既有 journal／备份／revision；取消后必须说清哪些动作已提交。选择方案不会打开采集，现有关闭偏好继续生效。

**原实施切片。**

1. 固定新安装、已有安装、损坏配置与接入冲突的流程和提交边界。
2. 实现只读检查、草稿编排及终端交互。
3. 接入现有保存／安装／恢复服务。
4. 补齐六语言、CLI 帮助和首次使用指南。每一切片有独立可检查结果，完整流程通过后工作包才完成。

**原验收标准。** 新安装、重复执行、已有自定义方案、项目绑定、缺少 Claude、未知／不兼容宿主、非 TTY、中文空格路径、损坏文件、他人接入资源、保存冲突及中途失败都有确定结果。应用前取消不改显示配置或接入；界面语言仍遵守既有即时保存规则。应用后取消不声称回滚。重启 Claude 后才能确认的真实显示，标为待验证；固定样例不能充当运行成功证据。证据包括流程用例、事务故障用例、六语言终端走查和受支持宿主的实际结果。

## APPEARANCE-01 成套显示方案

**已在 v3.5.0 交付 — DONE。** 本节保留历史范围与验收意图；当前使用方式见[显示方案](../SCHEMES.zh-CN.md)，已验证行为与限制见[交付证据](setup-appearance.zh-CN.md)。

**问题与目标。** 六种预设与命名方案已经存在，用户仍需自行组合外观和主／子代理布局。提供三套可以直接预览、微调、保存和分享的完整方案。

| 场景 | 主状态栏 | 子代理与缺失数据处理 | 交付样例 |
| --- | --- | --- | --- |
| 日常开发 | 模型／effort、目录、Git、上下文、任务计时；费用可放第二行 | 使用现有代理模板，不要求开启额外采集 | 80／120 列；浅色、深色、终端色 |
| 多代理任务 | 保留主任务、上下文和仓库摘要 | 突出名称、状态、模型、上下文和任务；保持失败可见，区分主任务与代理耗时 | 无代理、运行中、已完成与失败 |
| 额度监控 | 上下文、五小时／周额度与重置时间；按来源补充支出和缓存 | 缺失和过期不能转成零；来源条件在选择时可见 | 完整观测、字段缺失、窗口到期 |

**范围与交互。** 为每套方案定义布局、标签、数字格式、颜色、隐藏条件、优先级和主／子代理搭配；同一方案提供适合深色、浅色或终端色的选择。保持六个已有预设 ID；新方案通过现有候选草稿和命名方案机制提供。用户先预览，再选择保存到当前目标或另存；共享方案被多个项目引用时说明影响范围。

**数据与模块。** 复用 [预设](../../packages/core/src/config/presets.ts)、[显示实例](../../packages/core/src/config/instances.ts)、[方案服务](../../packages/cli/src/config/profiles.ts)、[预览](../../packages/core/src/rendering/preview.ts)和[六语言资源](../../packages/core/resources/i18n)。样例由固定 payload 驱动，真实显示使用原有指标来源；不新增统计公式。

**接口与兼容。** 已使用显示 schema 9 表达方案；内置方案元数据与用户保存的配置分开。更新内置方案不覆盖已保存副本或自动改变现有默认。方案导出不携带项目路径、采集开关、宿主偏好或外部能力授权。首版分享以现有单方案 JSON 和说明为单位。

**原实施切片。**

1. 确定三种场景与主／子代理样例。
2. 用现有配置机制实现方案和外观选项。
3. 接入 Quick setup、方案预览与另存。
4. 补齐可分享文件、说明和安装成品截图。

**原验收标准。** 两个编辑器得到等价草稿；80／120 列有明确展示，40 列保持正确裁切与隐藏。六种语言、组合 emoji、低色彩、无颜色和缺少 Powerline 字体均可阅读。导入、导出、重开、复制方案和项目绑定保留实例身份与选项；取消不改变已保存方案。导入不能启用采集或扩展。证据包含配置往返、渲染样例、双编辑器操作和成品捕获。

## EXTENSIONS-01 本地 JSON 数据基础

**已在 v3.6.0 交付 — DONE。** 本节保留历史范围与验收意图；当前使用方式见[扩展指南](../EXTENSIONS.zh-CN.md)，已验证行为与限制见[交付证据](extensions.zh-CN.md)。

**问题与目标。** 用户希望显示其他工具已有的本地结果。先定义独立的数据来源与展示契约，让后续联网和命令组件复用相同的可用性说明。

**首版范围与交互。** 用户在本机登记来源 ID、明确文件位置、字段选择和作用域后显式启用；编辑器添加引用该来源的组件。选择器和诊断说明来源、观测时间及适用项目／会话。文件可以由用户自己的工具产生，本项目的预览、导入和显示不运行文件内的代码或指令。

**历史契约草案。** 定义独立版本的来源描述及观测封装，包含 `source_id`、项目／会话范围、`observed_at`、结果状态、标量值和可选单位。状态明确区分有效、缺失、过期、部分、错误与不支持；无时间戳时新鲜度未知。字段选择采用受限路径规则，不执行表达式。源身份、观测时间和类型不能由显示标签替换，也不能混入官方任务或费用累计。

**模块与配置。** core 增加纯观测解析和展示约定，platform 负责显式文件读取，cli 管理用户侧来源登记，目录／解释／两个编辑器复用共享定义。参考 [渲染环境](../../packages/core/src/rendering/context.ts)、[诊断服务](../../packages/cli/src/diagnostics/service.ts)与[实例配置](../../packages/core/src/config/instances.ts)。来源开关和本机路径独立于可分享方案；分享只保留组件意图，导入后提示重新绑定来源。

**原实施切片。**

1. 固定来源、作用域、值类型、失效语义和迁移约定。
2. 实现本地 JSON 读取、诊断及明确失败结果。
3. 接入独立组件、双编辑器和 CLI。
4. 验证导入导出、禁用与删除来源后的表现。

**原验收标准。** 覆盖不存在／不可读／写入未完成的文件、非法 JSON、未知版本、类型错误、缺失字段、显式零值、未知／过期时间和作用域不匹配。错误不得转成正常零值或覆盖宿主指标；预览使用标明的固定数据。关闭来源、导入方案和项目切换都不能隐式启用外部读取或其他能力。证据包含来源契约用例、文件失败案例、配置往返、来源诊断和双编辑器展示。

## WORKFLOW-01 可选 GitHub PR 与 CI 查询

**已在 v3.6.0 交付 — DONE。** 本节保留历史范围与验收意图；当前使用方式见[扩展指南](../EXTENSIONS.zh-CN.md)，已验证行为与限制见[交付证据](extensions.zh-CN.md)。

**首版范围。** 仅支持 GitHub，复用用户已有 `gh` 登录状态，读取当前明确仓库和分支对应的 PR 及检查汇总。联网提供方默认关闭，用户可在本机启用或停用。GitLab／Gitee 产品数据提供方和多提供方自动猜测留到后续；Gitee 仓库同步与产品提供方支持分别管理。

**模块与接口。** provider 编排属于 cli，命令与凭据环境使用 platform 的既有进程适配；core 负责状态映射、目录和解释，双编辑器提供显示及来源说明。明确仓库、账号／host、分支和 HEAD 身份绑定。凭据留在已有工具的凭据存储，配置／导出／诊断不保存凭据。LINKS-01 可增加点击，但不是查询正确性的前提。

**原实施切片。**

1. 固定仓库识别、来源优先和 PR／检查状态表。
2. 实现显式启用、刷新与来源诊断。
3. 接入补充 PR／CI 显示和可选链接。

**原验收标准。** 覆盖非仓库、无 remote、detached HEAD、worktree、SSH 别名、缺少 gh、未登录、无权限、网络失败、无 PR、多个 PR、检查缺失与混合状态。切换仓库／分支／账号后不能显示前一对象的结果；禁用后不再发起查询。证据包含提供方响应夹具、身份隔离用例、授权范围内的查询验证和用户说明。

## COMMAND-01 用户显式配置的命令组件

**已在 v3.6.0 交付 — DONE。** 本节保留历史范围与验收意图；当前使用方式见[扩展指南](../EXTENSIONS.zh-CN.md)，已验证行为与限制见[交付证据](extensions.zh-CN.md)。

**问题与目标。** 本地 JSON 之外，用户可能希望调用自己维护的工具生成展示值。命令结果仍进入统一来源契约，不改变官方指标。

**首版范围。** 使用明确的可执行文件、参数数组、工作目录和输入字段映射；默认不通过 Shell 解释。由独立刷新调用执行并发布观测，主／子状态栏只读取结果；预览不启动程序。支持约定的 JSON 输出或净化后的单行文字。通用 Shell、脚本下载和自动安装工具属于后续候选。

**启用与交互。** 本机来源配置展示完整程序、参数、工作目录和将提供的输入字段；用户明确启用后生效。默认输入只包含所选结构化字段，不自动传递会话正文、transcript 内容或凭据。导入的显示方案只能留下未绑定引用，不能引入已启用命令；修改程序／参数／输入范围后重新审阅。用户可以单独停用或删除来源。

**模块与接口。** 依赖 EXTENSIONS-01。platform 的 [进程适配](../../packages/platform/src/command.ts)处理参数字面量、结束与取消，cli 处理执行和观测发布，core 处理输出类型及终端文字净化。固定执行截止、输出边界和子进程结束语义，明确终止与非零退出结果；不直接复用任意 Shell 拼接。执行配置独立于可分享显示配置。

**原实施切片。**

1. 固定输入／输出和本机启用契约。
2. 实现进程、取消、失败与观测发布。
3. 接入来源审阅、诊断和组件配置。
4. 验证跨平台参数、导入和禁用流程。

**原验收标准。** 空格／中文／引号及特殊字符按字面量传递；缺少程序、非零退出、非法输出、超量输出、截止终止、后代进程保留管道、刷新取消和禁用都有明确结果。终端控制字符不能改变界面结构；旧来源结果不冒充当前成功。证据包含隔离进程用例、授权启停／导入用例和六语言错误展示。
