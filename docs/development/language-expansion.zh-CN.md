# 十二语言界面与状态栏支持

[English](language-expansion.md) | **简体中文**

v3.16.0 在原有六种选择项之后新增西班牙语（`es`）、法语（`fr`）、德语（`de`）、巴西葡萄牙语（`pt-BR`）、俄语（`ru`）和印度尼西亚语（`id`）。发布及本机验证于 **2026-10-30** 完成，原始源码、发布身份及实际结果见下文。

## 资源与兼容

十二种语言完整覆盖 CLI、双编辑器、帮助、恢复、预览及主／子代理状态栏。新语言沿用现有 B 类策略：开发时允许当前英文回退，所有公开发行版必须完整验收 A/B 资源。规范译文及显式验证／验收遵循[翻译指南](i18n.zh-CN.md)，记录区分代理上下文复核与母语审阅。

生成器统一维护共享语言类型、有效 Node／Native 字典、状态栏模块和安装向导列表。Node 字典显式标注语言／消息键类型，避免语言包增长触发 TypeScript 声明序列化限制。Native 按语言分割模块，每个小于 1 MiB；字典和翻译历史不传入 Client。

编辑器协议 31 拒绝旧前端并显示既有重新安装提示。显示 schema 17、界面偏好 1、便携／方案格式及运行协议保持原格式，受管协议 30 资源可升级。读取保留文件字节；界面语言立即保存，输出语言随显示 Save／Cancel，Claude 偏好仍单独 Apply。`zh-Hant` 继续作为映射到 `zh-TW` 的输入别名；新代码不新增别名或自动语言识别。

## 验收要求

- 全部 144 组独立界面／输出组合，以及保存／取消／重开、失败、导入导出、升级和包内准确有效资源。
- 有明确含义的本地化 CLI／渲染预期，以及重音、组合字符、西里尔字母、CJK 和 emoji 共享搜索夹具；保留命令、ID、数字、技术单位和用户标签。
- 保留原有 283 个容量场景，每个新语言新增五个，共 313 个实际宿主用例。夹具向生产预览渲染器注入所选输出语言的消息，原有场景身份可核查。
- props、外层 Pane 和 Client 绘制树分别执行 48,000 字符、10,000 values、深度 16 的预算，计入非 ASCII 转义膨胀。保留选中内容、分页、完整字素、预览颜色及已保存／待处理／未知结果恢复语义。
- Native 32×12、TUI 64×18 最小尺寸，常见、高窗格及缩放尺寸，40／80／120 列输出、明暗背景和支持的颜色回退。

语言注册、生成类型及协议变更走产品路线：最终 PR 完整验收八个安装目标、32 项 Node 和十六个固定宿主。main 集成及 tag 晋升核验保留不可变原始证据；后续专项文档维护按其影响检查执行。

扩展后的官方测试按源测试文件放入准确源码的临时副本分别运行，十二个生成的语言入口覆盖全部 144 组组合。每项测试保留 30 秒上限，每次官方调用保留 180 秒期限。副本保留 hooks 和支持模块；回执绑定完整有序文件清单、源码哈希、通过数量、耗时及保留日志。发布验证将清单与不可变源码归档比较并核验实际日志，拒绝遗漏、重复、篡改或跳过的执行。

容量套件的七个生成入口也使用相同的串行机制。每个案例保留 20 秒上限，每次容量调用保留 300 秒期限。发布验证从不可变 Native 归档重建准确的容量源码清单，包括测试注册 hooks 和入口范围，并要求全部 313 项成功及每个批次的保留日志。
