## IMPORT-01

正在实施。协议 22 为既有导入操作增加可选精确选择键；显示 schema 保持 13，portable／单方案外层格式保持 1。共享选择及差异逻辑由 core 生成到原生编辑器。完整作用域保留内部身份和引用，主区与子代理 ID 命名空间独立；不进行任意组件拼接或 host 授权转移。

CLI 和双编辑器支持全局项、完整分区两个切片；方案及项目保存复用版本校验事务，保留身份和绑定。安装验收在原有二十类之外新增四个选择性导入场景。参见[使用与目标规则](../PROFILES.zh-CN.md#选择性导入)。

本地源码检查通过 1,218 项，明确跳过 5 项；生成资源、文档链接和迁移清单检查通过。本机官方原生 Mod 测试通过 133 项。回滚修复前的 21 类安装验收全部通过；修复后的安装包已在固定 Claude Code 2.1.296 下通过真实 npm 3.7.0／当前版本往返、进程中断恢复和显式配置恢复。最终功能 CI 矩阵待完成，尚未公开发布。

固定宿主矩阵发现了回滚缺陷：旧版所有权读取器不识别新版编辑器协议，官方插件更新还可能保留较新的缓存。当前包现先校验并暂存目标版本的真实 Mod 资源，降级时重装已确认归属的缓存，保留显式禁用及无关设置，再通过独立进程运行目标安装器。资源摘要、后端绑定与 doctor 结果仍为必要条件。这是新增自动化失败的修复，不属于六项已接受历史缺口。
